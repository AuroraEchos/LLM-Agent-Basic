## 我的答案

Embedding 检索效果由三层共同决定：**训练目标定义哪些文本应该接近，Pooling 决定如何把 token 表示压成一个向量，归一化决定相似度同时比较方向还是还受模长影响**。推理实现必须与模型训练配置一致。

### 一、训练目标决定向量空间

最常见的是对比学习。对 query \(q_i\)、正文档 \(d_i^+\) 和 batch 内负样本，InfoNCE 可写为：

\[
\mathcal L_i=-\log
\frac{\exp(s(q_i,d_i^+)/\tau)}
{\sum_j\exp(s(q_i,d_j)/\tau)}
\]

温度 \(\tau\) 控制分布尖锐度。训练数据和负样本决定模型学到什么：

- 随机负样本太容易，只教会粗主题分类；
- BM25/dense 挖出的 hard negatives 能训练细粒度区分；
- false negative 会错误推远本来相关的段落；
- 只有对称相似句数据，未必适合非对称“短 query → 长 document”检索；
- 多语言平行数据决定跨语言空间是否对齐；
- 教师 reranker 分数可用于蒸馏更细的排序关系。

有些模型用 query/document 不同 prefix 或双塔参数，让非对称角色更明确；漏掉 prefix 会产生训练—推理不一致。

### 二、Pooling 决定压缩方式

Transformer 输出 token states \(h_1,\ldots,h_T\)，需聚合为固定向量。

#### Mean Pooling

\[
e=\frac{\sum_t m_t h_t}{\sum_t m_t}
\]

其中 \(m_t\) 是 attention mask。它利用所有有效 token，通常稳定，但长文本多个主题会被平均；实现若把 padding 算进去会污染向量。

#### CLS Pooling

\[
e=h_{[CLS]}
\]

计算简单，但只有模型训练时专门让 CLS 聚合语义才可靠；不能因 BERT 有 CLS 就默认使用。

#### Last-token / EOS Pooling

常用于 decoder 型 embedding 模型，取最后一个有效 token。必须处理 left/right padding，取“最后非 padding token”而非张量最后一列。

#### Max / Weighted / Multi-vector

Max pooling 强调各维强响应；attention-weighted pooling 学习 token 权重；multi-vector 方法保留多个 token/片段表示，通过 late interaction 匹配，细粒度更强但索引与查询成本高。

Pooling 是模型定义的一部分，不能在没有重新验证时任意互换。

### 三、向量归一化与距离

L2 归一化：

\[
\hat e=\frac{e}{\|e\|_2}
\]

归一化后点积等于 cosine similarity：

\[
\hat q^\top\hat d=\cos(q,d)
\]

而单位向量的平方欧氏距离满足：

\[
\|\hat q-\hat d\|_2^2=2-2\cos(q,d)
\]

所以三种排序在严格归一化后等价。好处是消除模长影响、阈值较易解释，也适合按 inner product 建 ANN。

未归一化点积为：

\[
q^\top d=\|q\|\|d\|\cos(q,d)
\]

此时模长也参与评分。若模型训练时有意把置信度/流行度编码进 norm，强行归一化可能损失信息；反过来，模型预期 cosine 却忘记归一化，会让大 norm 文档无故占优。因此要遵循 model card，并检查向量库配置。

### 四、常见工程错误

- query 用新模型、索引用旧模型，空间不兼容；
- 文档加 prefix 而 query 忘记，或两者模板颠倒；
- pooling 包含 padding/special token，last-token 取错位置；
- 离线向量归一化、在线 query 未归一化；
- 使用 cosine 却把“distance 越小”和“similarity 越大”排序方向写反；
- float/量化和 ANN 近似造成阈值漂移，却沿用旧阈值；
- chunk 超长被截断，但没有记录 truncation rate。

可用少量固定文本做 golden vector test：验证维度、norm、相似度矩阵和最近邻在每次部署中一致。

### 五、如何评估影响

除了 Recall@k/MRR，应按短 query、长文档、hard negative、多语言和领域实体切片。对比训练目标时保持 chunker 与 ANN 不变；对比 pooling/归一化时确保模型允许该变体，并同时测 exact search，避免把 ANN 参数误认为表示质量差异。

### 面试简答版

训练目标定义“谁应靠近谁”：对比学习用正对和 in-batch/hard negatives 学排序，负样本质量、query-document 非对称格式和温度直接影响空间。Pooling 把 token states 压成向量，mean 要排除 padding，CLS 或 last-token 只有在模型按该方式训练时才合理，multi-vector 更精细但更贵。L2 归一化后 dot product 等于 cosine，且与 L2 距离单调等价；未归一化点积还受向量模长影响。生产中必须固定 prefix、pooling、normalization、distance metric 和模型版本，否则索引与查询向量会失配。
