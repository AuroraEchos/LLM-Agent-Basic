## 我的答案

文档解析的真正目标不是“抽出一串文本”，而是保留**阅读顺序、层级、表格对应关系、视觉语义和出处坐标**。PDF、网页、表格与扫描件的错误模式不同，不能用同一个纯文本 extractor 处理后就直接 embedding。

### 一、PDF：视觉版面不等于逻辑结构

PDF 通常保存的是页面坐标和绘制指令，不一定保存语义阅读顺序。主要难点包括：

- 双栏/多栏内容交错，正文、脚注和侧栏顺序错误；
- 页眉页脚、页码和水印在每页重复，污染检索；
- 断行、连字符和 ligature 导致单词被拆开；
- 标题层级、列表、公式、图片 caption 丢失；
- 跨页表格表头缺失，单元格被当成无序文本；
- 同一文件可能混合数字文本层和扫描图片；
- 字体编码异常，复制出的字符与视觉内容不一致。

处理时应结合版面检测和文本坐标，先识别区域类型，再恢复栏顺序与章节树；去除重复页眉页脚时保留页码元数据。每个 chunk 最好记录文档 ID、页码和 bounding box，便于引用原页。公式与复杂图表可转为结构化表示或单独走多模态解析，并设置置信度与人工回退。

### 二、网页：模板噪声和动态内容

网页的 DOM 有一定结构，但正文常被导航、Cookie 弹窗、推荐区、评论和广告包围：

- 单页应用内容由 JavaScript 动态渲染，直接抓 HTML 得到空壳；
- 响应式布局、折叠区和分页导致可见内容不完整；
- 导航/版权模板在全站重复，造成大量近重复 chunk；
- canonical URL、重定向、查询参数产生重复页面；
- 代码块、表格、链接锚文本和标题层级在转纯文本时丢失；
- robots、登录权限、许可、PII 和更新频率有治理要求；
- 页面可能包含针对 RAG/Agent 的 prompt injection。

应优先用站点 API、RSS 或语义 DOM，必要时在受控浏览器渲染；抽取 main content，保留标题、列表、代码、链接目标、发布时间与 canonical URL。用正文 hash 和模板检测去重，并明确把网页内容标为“不可信数据”，不能允许其中的指令覆盖系统规则。

### 三、表格：语义存在于二维关系

表格如果按行拼成普通句子，容易失去“某值属于哪个行键、列名和单位”。难点有：

- 多级表头、合并单元格、空白继承与跨页续表；
- 单位、币种、时间范围藏在标题或脚注；
- 同一列混合文本、百分比和缺失值；
- 宽表超过上下文窗口，纵向切块后表头丢失；
- PDF 表格靠视觉对齐，没有真实 cell 边界；
- 数据库表还涉及主外键、join 与权限。

理想做法是保存结构化 schema：表名、caption、header path、row key、cell value、unit 和 footnote。小表可整体序列化；长表按行组切块但给每块重复完整表头；分析型问题可直接导入 SQL/数据框工具，让模型生成查询而不是从向量片段中做算术。抽取后要校验行列数、类型、总计与原图区域。

### 四、扫描文档：OCR 只是第一步

扫描件没有可靠文本层，还会有倾斜、旋转、阴影、低分辨率、污点、手写、印章和复杂背景：

- OCR 混淆 `0/O`、`1/l`、小数点、负号和罕见字符；
- 中文分词、竖排文字、多语言混排更难；
- 版面区域和阅读顺序需视觉模型恢复；
- 表格线、公式和手写签名不能靠普通 OCR 准确表示；
- OCR confidence 高也不保证数字、姓名等关键字段正确。

管线通常为图像矫正/去噪/旋转检测 → layout detection → 分区 OCR/表格/公式识别 → 阅读顺序恢复 → 词典与规则后校验。重要数字可双 OCR 引擎比对或人工复核；保留原图坐标和 OCR 置信度，使回答能回到截图证据，而不是把低置信文本当真值。

### 五、共同的清洗原则

1. **清噪不清语义**：删除模板和重复页眉，但保留标题、单位、否定词、代码缩进和脚注。
2. **先结构化再切块**：不要先 flatten 再猜结构；标题树、表格和页码一旦丢失很难恢复。
3. **可追溯**：每个片段保留 source、版本、页/DOM/坐标、解析器版本和内容 hash。
4. **置信度传播**：OCR/解析低置信应进入检索和回答层，可触发回看原图或拒答。
5. **按权限去重**：跨权限域的相似内容不能因去重而错误继承 ACL。
6. **建立 golden set**：覆盖多栏 PDF、跨页表、多语言扫描和动态网页，分别评估文本、结构与字段准确率。

### 面试简答版

PDF 的难点是坐标式版面造成多栏阅读顺序、页眉页脚、公式和跨页表格丢失；网页主要是动态渲染、导航广告模板、重复 URL、权限及不可信指令；表格语义依赖二维行列、表头、单位和脚注，不能简单展平；扫描件还要处理图像质量、OCR 字符错误、版面和手写。通用原则是先恢复结构再清洗和切块，保留来源页码/坐标、表头、权限和解析置信度，复杂表格优先结构化查询，低置信关键字段回看原图或人工复核。
