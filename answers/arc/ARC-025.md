> **问题：** Cross-Attention 与 Self-Attention 的输入、缓存方式和使用场景有何区别？
>
> **分类：** Transformer 与模型架构
>
> **来源：** [INTERVIEW_QUESTIONS_AGENT_HARNESS_EXPANDED.md](../../INTERVIEW_QUESTIONS_AGENT_HARNESS_EXPANDED.md)

## 我的答案

Self-Attention 的 Q、K、V 来自同一序列，用于序列内部信息交互；Cross-Attention 的 Q 来自当前正在更新的目标序列，K、V 来自另一个源序列或模态，用于将外部条件注入目标表示。

### 输入和形状

设目标序列 $X\in\mathbb{R}^{B\times T\times d_x}$，源序列 $C\in\mathbb{R}^{B\times S\times d_c}$。

Self-Attention：

$$
Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V
$$

$$
\operatorname{SelfAttn}(X)
=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_h}}+M\right)V
$$

Cross-Attention：

$$
Q=XW_Q,\qquad K=CW_K,\qquad V=CW_V
$$

$$
\operatorname{CrossAttn}(X,C)
=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_h}}+M_C\right)V
$$

Cross-Attention 的 logits 形状是 $[B,H,T,S]$：每个目标 Query 对所有源 Key 分配权重。$d_x$ 和 $d_c$ 可以不同，只要 $W_Q,W_K,W_V$ 将它们投影到兼容的 head dimension。

### Mask 的区别

- Decoder Self-Attention 通常需要 Causal Mask，阻止目标 token 看到未来目标 token，并可叠加 Padding Mask。
- Encoder Self-Attention 通常是双向的，只需要 Padding/结构 Mask。
- 标准 Encoder-Decoder Cross-Attention 不需要下三角 Causal Mask，因为整个源序列在生成前已经可见；它需要屏蔽源序列的 Padding 位置。

### 推理时的缓存方式

#### Decoder Self-Attention Cache

每生成一个新 token，都会产生新的 $K_t,V_t$，并追加到历史 Cache：

$$
K_{self}^{(t)}=[K_{self}^{(t-1)};K_t]
$$

Self-Attention KV Cache 长度因此随已生成 token 数线性增长。当前 Query 只有一个或一小块，但需读取所有历史 K/V。

#### Cross-Attention Cache

源序列 $C$ 在整个解码过程中不变，因此每个 Decoder 层所需的：

$$
K_C=CW_K,\qquad V_C=CW_V
$$

可在 Encoder 完成后或首个解码步骤计算一次，后续每个 token 复用。Cross-Attention Cache 的序列长度固定为 $S$，不会随生成长度增长。

不同 Decoder 层的 Cross-Attention $W_K,W_V$ 通常不同，所以需要每层各自的投影 Cache，除非架构显式共享参数或采用其他压缩设计。Beam Search 中同一样本的 Cross-Attention Cache 在 beam 之间逻辑上相同，应尽量共享或通过 view/索引复用，而不是物理复制多份。

### 计算复杂度

只看 Attention 点积和 Value 聚合：

- 长度 $T$ 的 Self-Attention：$O(T^2d)$；
- 目标长度 $T$、源长度 $S$ 的 Cross-Attention：$O(TSd)$。

带 Cache 单 token 解码时，Self-Attention 对当前历史长度为线性读取，Cross-Attention 对源长度 $S$ 为线性读取。两者都可能在 Decode 阶段受内存带宽限制。

### 使用场景

- **Self-Attention**：Encoder 内部的双向文本理解，Decoder 内部的因果建模，视觉/音频 token 内部交互。
- **Cross-Attention**：机器翻译和摘要中连接 Encoder/Decoder；图像或音频 Encoder 向文本 Decoder 注入感知特征；扩散模型注入文本条件；某些架构中读取检索记忆或外部潜向量。

Cross-Attention 与“将所有模态 token 直接拼接后做 Self-Attention”是两种不同融合方式。前者保留源/目标边界并可预计算源 K/V，后者结构更统一，但所有 token 共享同一 Self-Attention 序列和 Mask 设计。

### 面试简答版

Self-Attention 的 Q、K、V 来自同一序列，用于序列内信息交互；Cross-Attention 的 Q 来自目标序列，K、V 来自源序列，logits 形状为 $[B,H,T,S]$，用于条件生成和跨模态融合。Decoder Self-Attention 的 KV Cache 需随每个新 token 追加，长度持续增长；Cross-Attention 的源 K/V 在源序列编码完成后即固定，可每层投影一次后全程复用。Decoder Self-Attention 通常需 Causal Mask，标准 Cross-Attention 则通常只需源端 Padding Mask。
