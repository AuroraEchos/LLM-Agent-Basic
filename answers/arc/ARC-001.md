## 我的答案

原始 Transformer 是 Encoder-Decoder 架构，原论文中 Encoder 和 Decoder 通常各堆叠 $N=6$ 个 Block。

**Encoder 数据流：**

原始文本序列首先经过分词器（Tokenizer）转换为 token ID 序列，再经过 Embedding 层映射为稠密向量，再与 Positional Encoding 相加，得到包含位置信息的稠密向量序列。随后进入 $N$ 个相同的 Encoder Block。每个 Encoder Block 包含两个子层：

1. Multi-Head Self-Attention：序列内部计算注意力，使每个 token 能够关注源序列中的其他 token，捕捉全局依赖；
2. Position-wise Feed-Forward Network：对每个位置独立做两层全连接非线性变换，原论文使用 ReLU 激活。

每个子层都使用残差连接和 Layer Normalization，即 `Add & Norm`。Encoder 最终输出每个源位置的上下文表示，供 Decoder 的 Cross-Attention 使用。

**Decoder 数据流：**

训练时使用 teacher forcing：目标序列右移一位，通常以 `<BOS>` 开头，再经过 Embedding 和 Positional Encoding，进入 $N$ 个相同的 Decoder Block。每个 Decoder Block 包含三个子层：

1. Masked Multi-Head Self-Attention：通过 causal mask 阻止当前位置关注未来 token，保证生成时只依赖已知前文；
2. Multi-Head Cross-Attention：Q 来自 Decoder 当前层 Masked Self-Attention 后的中间表示，K 和 V 来自 Encoder 最终输出，使 Decoder 能够关注源序列中的相关信息；
3. Position-wise Feed-Forward Network：对融合后的特征做进一步非线性变换。

每个子层同样使用残差连接和 Layer Normalization。

**输出层：**

Decoder 最后一层输出经过线性层映射到词表大小，再经过 Softmax，得到每个位置预测下一个 token 的概率分布。训练时可以并行计算整个目标序列；推理时采用自回归生成，每次将新预测出的 token 加入 Decoder 输入，直到生成 `<EOS>`。

### 更精确的数据流与形状

设源序列长度为 $S$，目标序列长度为 $T$，hidden size 为 $d$：

$$
X_{src}\in\mathbb{R}^{B\times S\times d}
\xrightarrow{Encoder}
H_{enc}\in\mathbb{R}^{B\times S\times d}
$$

$$
X_{tgt}\in\mathbb{R}^{B\times T\times d}
\xrightarrow{Decoder(H_{enc})}
H_{dec}\in\mathbb{R}^{B\times T\times d}
$$

Decoder Cross-Attention 中：

$$
Q=H_{dec}W_Q,qquad K=H_{enc}W_K,qquad V=H_{enc}W_V
$$

因此 Cross-Attention 权重的形状是 $[B,H,T,S]$，表示每个目标 token 对每个源 token 的对齐关系。Decoder 输出经 LM Head 后 logits 形状为 $[B,T,V]$。

源端和目标端都需屏蔽 Padding token；Decoder Self-Attention 还需 Causal Mask。Cross-Attention 通常只屏蔽源端 Padding，不用下三角 Mask，因为整个源序列已经可见。

### 原始 Transformer 的细节

- 使用固定正弦/余弦位置编码。
- Embedding 乘以 $\sqrt{d_{model}}$ 后再加位置编码。
- Encoder/Decoder 各 6 层，$d_{model}=512$，8 个 Attention head，FFN 中间维度 2048。
- FFN 为两层线性变换 + ReLU。
- 使用 Post-Norm：$\operatorname{LayerNorm}(x+\operatorname{Sublayer}(x))$，并在多处使用 dropout。
- 输入 Embedding、目标 Embedding 与 pre-softmax 线性变换可以共享权重，具体依实现而定。

### 训练与推理的区别

训练时目标序列右移，Teacher Forcing 为每个位置提供真实历史 token。虽然有 Causal Mask，所有目标位置仍能在一次前向中并行计算。

推理时 Decoder 必须逐 token 执行。工程上可缓存：

- 每层 Decoder Self-Attention 的历史 K/V，新 token 逐步追加；
- 每层 Cross-Attention 对 $H_{enc}$ 的 K/V 投影，整个解码过程固定复用。

原始论文的生成常使用 Beam Search；Greedy 或 Sampling 也可以用于自回归解码。

### 面试简答版

原始 Transformer 是 Encoder-Decoder 架构。Encoder 将源 token Embedding 与位置编码相加，经过 6 层“双向 Multi-Head Self-Attention + Position-wise FFN”，每个子层使用残差和 Post-LayerNorm，得到完整源序列表示。Decoder 的目标输入右移，每层依次做 Causal Self-Attention、对 Encoder 输出的 Cross-Attention 和 FFN。最后用 LM Head + Softmax 预测下一 token。训练时使用 Teacher Forcing 并行计算所有目标位置；推理时逐 token 生成，并可缓存 Decoder 历史 K/V 和固定的 Cross-Attention K/V。
