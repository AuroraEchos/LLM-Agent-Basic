> **问题：** Attention 中为什么通常对 logits 做 Softmax，可以替换成哪些函数？

## 我的答案

Attention 对 logits 使用 Softmax，是因为它可以把任意实数相似度转换成**非负、归一化、可微且能强调高分项的加权分布**。但 Softmax 不是 Attention 的数学必要条件，可以根据稀疏性、线性复杂度或数值特性使用其他映射。

### Softmax 做了什么

对一个 Query 与所有 Key 的 logits $z_j$：

$$
a_j=\frac{\exp(z_j)}{\sum_k\exp(z_k)},qquad
o=\sum_j a_jv_j
$$

其中 $a_j>0$ 且 $\sum_j a_j=1$，因此输出是 Value 的凸组合。这个形式有几个优势：

1. **竞争与归一化**：一个 Key 权重上升会相对压低其他 Key，不同序列长度下输出尺度相对可控。
2. **强调高分项**：指数映射会放大 logits 差异，让模型可以形成较尖锐的信息选择。
3. **平移不变性**：$\operatorname{softmax}(z+c)=\operatorname{softmax}(z)$，因此可以先减去最大 logit 进行数值稳定化。
4. **容易应用 Mask**：将不允许的位置设为 $-\infty$，其 Softmax 权重就为 0。
5. **可微且工程成熟**：有稳定的 online Softmax、FlashAttention 和各类 fused kernel 实现。

Softmax 的代价是权重通常稠密，极端 logits 会导致饱和和小梯度，并且归一化需要看到所有可见 Key，不能直接用简单结合律将 $QK^T$ 的二次计算重排为线性计算。

### 可以替换成什么

#### Sparsemax

Sparsemax 将 logits 欧氏投影到概率单纯形：

$$
\operatorname{sparsemax}(z)
=\arg\min_{p\in\Delta}\|p-z\|^2
$$

它可以产生精确为 0 的权重，可解释性和稀疏性更强。缺点是映射分段线性，在支持集切换边界处不光滑，并且“权重为 0”并不代表实现会在计算前知道哪些项为 0，因此不一定自动带来加速。

#### Entmax

Entmax 是 Softmax 与 Sparsemax 之间的可调族，通过参数 $\alpha$ 控制分布的平滑性和稀疏性；$\alpha=1$ 对应 Softmax，$\alpha=2$ 对应 Sparsemax。它能在可微性和稀疏选择之间折中，但计算与 kernel 生态不如 Softmax 成熟。

#### Sigmoid Attention

可以使用 $a_j=\sigma(z_j)$ 让每个 Key 独立通过一个门。它不强制权重之和为 1，因此多个 Key 可以同时获得高权重，但输出尺度会随有效 Key 数量变化，通常需额外归一化、偏置初始化或尺度校正。

#### ReLU/平方 ReLU 归一化

一类方法使用非负函数 $f$，例如 $\operatorname{ReLU}(z)^2$：

$$
a_j=\frac{f(z_j)}{\sum_k f(z_k)+\epsilon}
$$

这可以减少指数计算并引入一定稀疏性，但负 logit 区域可能没有梯度，且归一化和稳定性需要重新设计。

#### Kernelized Linear Attention

线性注意力不一定是将已得到的 logits 逐元素换一个函数，而是选择可分解的非负特征映射：

$$
\operatorname{sim}(q,k)=\phi(q)^T\phi(k)
$$

利用结合律先计算 $\phi(K)^TV$，避免物化 $N\times N$ 注意力矩阵，将序列长度复杂度从二次降到线性。代价是相似度不再精确等于 Softmax Attention，需要处理分母稳定性、因果前缀累积和长程检索质量。

### 选择时的工程边界

- 替换归一化函数后，$1/\sqrt{d_h}$ 的最优缩放、初始化和学习率可能都要重新调整。
- 必须验证 Causal/Padding Mask、全屏蔽行和混合精度下的数值稳定性。
- 理论 FLOPs 更少不代表端到端更快；Softmax Attention 有非常成熟的硬件 kernel，新算子可能受内存访问和 kernel launch 限制。
- 应同时比较预训练 loss、长上下文检索、生成质量、吞吐和显存，不能只看注意力图是否稀疏。

### 面试简答版

Softmax 将 Attention logits 转为非负且和为 1 的权重，让 Value 聚合尺度可控；指数还会放大高分项，其平移不变性便于减最大值做稳定计算，$-\infty$ 也容易实现 Mask。可替换为产生精确稀疏权重的 Sparsemax/Entmax、独立门控的 Sigmoid、归一化 ReLU 变体，或用可分解 kernel 构造线性注意力。但替换后需重新验证尺度、梯度、Mask、数值稳定性和真实 kernel 效率，不一定会同时提升质量和速度。
