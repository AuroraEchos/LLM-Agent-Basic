## 我的答案

估算一个大模型的参数量，本质上是根据模型结构配置计算每一层中可训练矩阵的数量，然后累加。

对于现代 Decoder-only Transformer（GPT、LLaMA、Qwen、DeepSeek 等），参数量主要由以下几部分组成：

1. Embedding 参数
2. Attention 参数
3. FFN（MLP）参数
4. LayerNorm 参数
5. 输出层参数（LM Head）

其中 Attention 和 FFN 占绝大多数参数。

### 首先确定模型基本配置

通常需要知道：

| 参数       | 含义                |
| -------- | ----------------- |
| $L$      | Transformer 层数    |
| $d$      | hidden size（隐藏维度） |
| $V$      | vocab size（词表大小）  |
| $d_{ff}$ | FFN 中间维度          |
| $h$      | attention head 数  |
| $d_k$    | 每个 head 维度        |

### Embedding 参数

输入 token embedding：

$$
W_e \in R^{V \times d}
$$

参数量：

$$
N_{embed} = Vd
$$
