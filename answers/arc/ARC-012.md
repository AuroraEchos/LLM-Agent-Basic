## 我的答案

位置编码要解决的核心问题是：Self-Attention 本身对输入顺序没有感知，如果不额外提供位置信息，模型无法区分“我喜欢你”和“你喜欢我”的顺序。

### 绝对位置编码

绝对位置编码为每个位置 $p$ 生成向量 $e_p$，并通常与 token embedding 相加：

$$
h_p=x_p+e_p
$$

它可以是固定的正弦/余弦编码，也可以是可学习的 position embedding。

优点是结构简单、容易实现，可直接为每个 token 注入全局位置。缺点是 Attention 要自己从两个绝对向量中学出相对距离；可学习编码的长度通常固定，超出训练范围时没有学过对应位置向量。正弦编码可按公式外推，但长度外推效果也不一定稳定。

### 相对位置编码

相对位置方法不只告诉模型 token 在哪个绝对位置，而是根据 Query 位置 $i$ 与 Key 位置 $j$ 的差 $i-j$ 修改 Attention score 或 Value 聚合。典型形式是：

$$
S_{i,j}=\frac{q_i^Tk_j}{\sqrt{d_h}}+b_{i-j}
$$

优点是直接建模 token 间距离，对平移更自然，并容易引入局部性。缺点是具体实现很多，有的需生成 $L\times L$ 的位置偏置，有的会将距离截断或分桶，对未见过的超长距离仍可能外推不好。

### ALiBi

ALiBi（Attention with Linear Biases）不向 embedding 加位置向量，而是根据 Query-Key 距离向 Attention logits 加线性负偏置。对因果注意力可概括为：

$$
S_{i,j}=\frac{q_i^Tk_j}{\sqrt{d_h}}-m_h(i-j),\qquad j\le i
$$

不同 head 使用不同斜率 $m_h$，使一些 head 更关注局部，另一些 head 对长距离惩罚更弱。

优点是非常简单、不需位置 embedding 参数，偏置可直接计算到更长序列。缺点是线性距离先验较强，对远距离 token 持续施加惩罚；它主要改变 Attention score，位置表达的形式没有 RoPE 丰富。

### RoPE

RoPE 根据绝对位置旋转 Query 和 Key 的二维子空间：

$$
q_i'=R_iq_i,\qquad k_j'=R_jk_j
$$

由于 $R_i^TR_j=R_{j-i}$，所以 QK 点积中自然包含相对位置 $j-i$。

优点是不需学习位置表，不改变向量范数，能将相对位置自然融入点积，也容易与 FlashAttention 和 KV Cache 结合。缺点是直接超出训练长度时可能发生相位分布外推问题，通常需要 Position Interpolation、NTK-aware Scaling 或 YaRN 等方法扩展上下文。

### 综合对比

| 方法 | 注入位置 | 主要优点 | 主要局限 |
|---|---|---|---|
| 绝对编码 | 与 token embedding 相加 | 直观、实现简单 | 相对距离需自行学习，长度外推弱 |
| 相对编码 | Attention score 或 Value | 直接建模 token 间距离 | 实现多样，可能增加计算或缓存 |
| ALiBi | logits 上的线性距离偏置 | 简单、无额外位置参数、可直接延长 | 线性先验较强，长距离被惩罚 |
| RoPE | 旋转 Q 和 K | 在点积中自然得到相对位置 | 超训练长度时需处理频率外推 |

### 面试简答版

绝对位置编码直接告诉模型每个 token 在哪里，简单但相对距离需模型自己学习，且长度外推通常较弱。相对位置编码直接根据 $i-j$ 修改 Attention，建模距离更自然。ALiBi 为 Attention logits 加与距离成比例的线性惩罚，简单且容易延长。RoPE 根据绝对位置旋转 Q、K，利用 $R_i^TR_j=R_{j-i}$ 在点积中引入相对位置，是现代生成式 LLM 中很常见的方案，但超长上下文时通常需频率缩放。
