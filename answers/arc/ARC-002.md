> **问题：** Transformer 相比 RNN、LSTM 的主要优势和代价是什么？

## 我的答案

Transformer 的核心改变是用 Self-Attention 替代 RNN/LSTM 沿时间步递归的主要信息交互方式。它带来训练并行、短长程路径和易扩展性，代价是标准 Attention 的二次序列开销、更弱的序列先验，以及自回归生成仍然无法完全并行。

### 训练并行性

RNN/LSTM 的状态递推为：

$$
h_t=f(x_t,h_{t-1})
$$

$h_t$ 必须等 $h_{t-1}$ 计算完成，所以时间维上有 $O(N)$ 的串行依赖。Transformer 训练时可以同时计算所有 token 的 Q、K、V 和 FFN，Causal Mask 只限制信息可见性，不阻止对整个训练序列做并行矩阵运算。这与 GPU/TPU 擅长的大规模矩阵乘高度匹配。

但自回归推理时，第 $t$ 个 token 仍依赖前面已生成 token，所以 Transformer 只能用 KV Cache 减少重复计算，不能直接将未知的所有输出 token 完全并行生成。

### 长距离依赖

在理论计算图中，两个距离很远的 token 可在一层全局 Self-Attention 中直接交互，最短路径长度是 $O(1)$。RNN 中信息需经过 $O(N)$ 次状态传递，即使 LSTM 用门控缓解梯度消失，远距离信息仍可能在反复压缩中损失。

Attention 的短路径不等于模型必然能正确利用任意长上下文；实际还受位置编码、训练长度、数据和注意力检索能力影响。

### 表达和扩展优势

- Multi-Head Attention 可在同一层学习多种独立的信息路由。
- Transformer block 结构规则，容易扩展宽度、深度，并使用数据、张量、流水线和序列并行。
- 每层的大矩阵乘计算密集，更容易获得高硬件利用率。
- 同一架构可统一处理文本、图像、音频和多模态 token。

### 主要代价

#### 二次 Attention 开销

标准 Self-Attention 的点积计算约为 $O(N^2d)$，朴素实现还需 $O(N^2)$ 中间注意力空间。RNN 每层随序列长度的计算通常是线性的，且流式推理可将历史压缩到固定大小 hidden state。Transformer 虽可用 FlashAttention 降低中间显存，但不会消除标准 Attention 的理论二次 FLOPs。

#### KV Cache 与内存带宽

自回归解码需为每层保存历史 K/V，缓存随层数、序列长度和并发数线性增长。Decode 阶段常需为一个 token 读取大量权重和 KV Cache，受显存带宽限制。

#### 归纳偏置较弱

RNN 天然包含时间顺序和状态递归先验，CNN 包含局部性和平移不变先验。Transformer 需显式位置编码，且更多地从数据中学习顺序与局部结构，往往需更大数据和计算规模。

### 对比总结

| 维度 | Transformer | RNN/LSTM |
|---|---|---|
| 训练时间维 | 可并行 | 必须递归 |
| 长距离路径 | 全局 Attention 中 $O(1)$ | $O(N)$ |
| 长序列开销 | 标准 Attention 二次 | 计算随长度线性，但串行 |
| 流式状态 | KV Cache 随长度增长 | hidden/cell state 可固定大小 |
| 归纳偏置 | 较弱，需位置编码 | 天然时序递归 |
| 硬件扩展 | 适合大矩阵和多种并行 | 时间步串行限制吞吐 |

### 面试简答版

Transformer 相比 RNN/LSTM 最大的优势是训练时可在序列维并行，并且任意两个 token 可在一层全局 Attention 中直接交互，长距离信息路径比递归网络短。规则的大矩阵 block 也更适合 GPU 和分布式扩展。代价是标准 Attention 有 $O(N^2d)$ 计算，自回归推理的 KV Cache 随上下文增长，而且 Transformer 的时序和局部归纳偏置较弱，需更多数据学习。同时要注意，Transformer 只是训练可并行，自回归生成仍需逐 token 进行。
