> **问题：** MHA、MQA、GQA 和 MLA 在参数、计算和 KV Cache 上有什么区别？
>
> **分类：** LLM 与 Transformer 基础

> **来源：** [CORE_INTERVIEW_QUESTIONS.md](../../CORE_INTERVIEW_QUESTIONS.md)

## 我的答案

MHA、MQA 和 GQA 的核心区别是：**Query head 与 Key/Value head 的数量关系不同**。MLA 则进一步改变了 KV 的表示方式，先将上下文压缩到低维潜变量，用它来降低 KV Cache 开销。

设 Query head 数为 $h_q$、KV head 数为 $h_{kv}$、每个 head 维度为 $d_h$。

### MHA：Multi-Head Attention

MHA 中每个 Query head 都有自己对应的 Key head 和 Value head：

$$
h_{kv}=h_q
$$

优点是不同 head 可以保留独立的 Q、K、V 表示，表达能力强；缺点是 K、V 头数多，自回归解码时 KV Cache 很大，读取它也会消耗大量显存带宽。

### MQA：Multi-Query Attention

MQA 保留多个 Query head，但所有 Query head 共享同一组 Key 和 Value：

$$
h_{kv}=1
$$

它可将 KV Cache 约缩小为 MHA 的 $1/h_q$，非常适合对带宽敏感的自回归解码。代价是所有 Query head 都只能使用同一组 K、V 表示，压缩较激进，可能造成一定效果损失。

### GQA：Grouped-Query Attention

GQA 介于 MHA 和 MQA 之间：

$$
1<h_{kv}<h_q,\qquad g=\frac{h_q}{h_{kv}}
$$

$h_q$ 个 Query head 被分成 $h_{kv}$ 组，每 $g$ 个 Query head 共享一个 Key head 和 Value head。GQA 通过适度共享 K、V 换取显著的缓存与带宽收益，通常比 MQA 更容易保持 MHA 的质量。MHA 可视为 $h_{kv}=h_q$ 的 GQA，MQA 可视为 $h_{kv}=1$ 的特殊 GQA。

### MLA：Multi-Head Latent Attention

MLA 不只是减少 KV head 数，而是将每个 token 的上下文表示下投影到低维潜变量：

$$
c_t^{KV}=x_tW^{DKV}
$$

需要参与注意力计算时，再由潜变量恢复或等价地吸收出各个 head 需要的 Key 和 Value：

$$
K_t=c_t^{KV}W^{UK},\qquad V_t=c_t^{KV}W^{UV}
$$

带 RoPE 的 MLA 通常还需缓存一小部分与位置相关的 Key。因此缓存的主体从“所有 K/V head”变成“压缩潜向量加少量位置信息”。MLA 的结构和高效实现更复杂，上投影仍会带来参数和计算，所以不能把缓存压缩比例直接等同于总参数或总计算的压缩比例。

### KV Cache 定量对比

设 Batch Size 为 $B$、序列长度为 $S$、每个元素占 $s$ 字节。传统 MHA/MQA/GQA 在每一层的 KV Cache 大小约为：

$$
M_{KV}=2BSh_{kv}d_hs
$$

前面的 $2$ 表示同时保存 Key 和 Value。

| 结构 | KV head 数 | 每层 KV Cache 元素数 | 主要特点 |
|---|---:|---:|---|
| MHA | $h_q$ | $2BSh_qd_h$ | 质量与独立性好，缓存最大 |
| GQA | $h_{kv}$ | $2BSh_{kv}d_h$ | 质量和效率的折中 |
| MQA | $1$ | $2BSd_h$ | 缓存最小，K/V 共享最强 |
| MLA | 不按常规 KV head 缓存 | 约 $BS(d_c+d_r)$ | 缓存 KV 潜向量及位置分量 |

$d_c$ 是 KV 压缩潜空间维度，$d_r$ 是需单独缓存的位置相关维度；MLA 的精确开销取决于具体实现。计算整个模型时，还要乘以层数 $L$。

### 参数量与计算量

在常规 MHA/MQA/GQA 中，Query 和输出投影通常变化不大，主要节省来自 Key/Value 投影：

$$
N_{K,V}\approx 2d_{model}h_{kv}d_h
$$

所以 GQA/MQA 会减少 K/V 投影参数和当前 token 的 K/V 投影计算。但每个 Query head 仍需与对应 Key 计算注意力，因此 Attention 点积的理论计算量不会按 $h_{kv}$ 的比例同步减少。它们在 Decode 阶段最明显的收益通常是减少 KV Cache 读取量和显存带宽压力。

### 面试简答版

MHA 中 Q、K、V head 一一对应，表达能力强，但 KV Cache 最大。MQA 让所有 Query head 共享一组 K、V，缓存最小，但共享较激进。GQA 让一组 Query head 共享一组 K、V，是质量和效率的折中。三者的每层 KV Cache 均可写成 $2BSh_{kv}d_h$。MLA 则缓存压缩后的 KV 潜向量和少量位置分量，可进一步降低长上下文推理的缓存与带宽开销。
