> **问题：** 局部注意力、滑动窗口注意力、稀疏注意力和线性注意力分别解决什么问题？

## 我的答案

这些方法都在解决标准 Attention 随序列长度 $N$ 二次增长的计算和显存问题，但路线不同：**局部/滑动窗口注意力限制可见距离，稀疏注意力设计少量长程连边，线性注意力则改写相似度函数和计算顺序，避免生成完整 $N\times N$ 矩阵。**

### 局部注意力

局部注意力让每个 Query 只关注附近的 $w$ 个 Key，例如对称窗口 $[i-w,i+w]$ 或同一分块内的 token。复杂度从：

$$
O(N^2d)
$$

降为约：

$$
O(Nwd)
$$

它利用了语言、图像和时间序列中“局部相关性最强”的先验，适合局部模式建模。缺点是一层无法直接连接距离超过窗口的 token，远距离信息要通过多层逐步传递。

### 滑动窗口注意力

滑动窗口是局部注意力的具体形式。在因果 Decoder 中，位置 $i$ 只关注最近 $w$ 个 token：

$$
j\in[\max(0,i-w+1),i]
$$

训练时每行只计算一条带状区域；解码时只需保留最近 $w$ 个 token 的 KV Cache，因此缓存不必随总生成长度无界增长。

局限是窗口之外的精确信息会被丢弃。可通过交错使用全局层、扩大部分层的窗口、保留 attention sink/global token 或使用层级摘要来弥补。

### 稀疏注意力

稀疏注意力是更广义的概念：每个 Query 只与 $N$ 个 Key 中的一个子集连边。稀疏图案可组合：

- 局部窗口或 block sparse；
- 固定间隔的 strided/dilated 连接；
- 少量所有 token 都能读写的 global token；
- 随机连边；
- 根据内容路由到 Top-K Key 或 cluster。

设每个 Query 只连接 $k$ 个 Key，理论复杂度可降为 $O(Nkd)$。局部边建模近邻，全局/跳连边则缩短长距离信息传播路径。

最大的工程陷阱是：如果仍先计算稠密 $QK^T$ 再用 Mask 置零，就没有节省主要计算和显存。真正加速需要 block-sparse 或专用路由 kernel，而非只改注意力 Mask。不规则稀疏访存还可能导致 GPU 利用率很低。

### 线性注意力

标准 Softmax Attention 需要先形成所有 Query-Key 对。线性注意力使用可分解特征映射：

$$
\operatorname{sim}(q,k)=\phi(q)^T\phi(k)
$$

利用结合律重排：

$$
\phi(Q)(\phi(K)^TV)
$$

而不是：

$$
(\phi(Q)\phi(K)^T)V
$$

设特征维度为 $r$、Value 维度为 $d_v$，主要计算约为 $O(Nrd_v)$，对序列长度 $N$ 是线性的。因果生成中可维护前缀状态：

$$
S_t=S_{t-1}+\phi(k_t)v_t^T
$$

并用 $\phi(q_t)^TS_t$ 产生当前输出，因而不必保存全部历史 K/V。完整归一化形式还需同时维护 $\sum_{j\le t}\phi(k_j)$ 作为分母。

代价是它通常只是近似或替换 Softmax 相似度，固定大小状态会压缩全部历史，精确检索特定早期 token 的能力可能下降。分母、状态累积和混合精度也需要稳定化设计。

### 综合对比

| 方法 | 主要思路 | 序列复杂度 | 主要风险 |
|---|---|---:|---|
| 局部注意力 | 只看附近区域 | $O(Nwd)$ | 长距离需多层传递 |
| 滑动窗口 | 固定移动窗口 | $O(Nwd)$ | 窗口外历史丢失 |
| 稀疏注意力 | 局部 + 少量长程连边 | $O(Nkd)$ | 稀疏图和 kernel 设计困难 |
| 线性注意力 | kernel 分解与重排 | $O(Nrd_v)$ | 不再是精确 Softmax，状态压缩可丢信息 |

这些方法并不互斥：模型可以在大部分层用滑动窗口，周期性插入全局 Attention；也可以将局部稀疏结构与状态空间或线性递归模块混合。

### 面试简答版

局部注意力将每个 Query 的 Key 数限制在 $w$，把复杂度从 $O(N^2d)$ 降到 $O(Nwd)$；滑动窗口是因果场景下只保留最近 $w$ 个 token 的具体形式。稀疏注意力还可结合 global、strided、random 或内容路由连边，在少量边上保留长程交互，但必须有真正稀疏 kernel 才能加速。线性注意力用可分解的 $\phi(q)^T\phi(k)$ 和结合律先聚合 $K^TV$，避免 $N\times N$ 矩阵，但改变了 Softmax Attention 的表达，可能损失精确长程检索能力。
