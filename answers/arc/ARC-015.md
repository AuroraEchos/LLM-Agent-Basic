## 我的答案

LayerNorm（LN）和 BatchNorm（BN）的核心差异不是公式外观，而是**统计均值和方差的维度不同**：BN 对同一特征通道跨样本统计，LN 对每个样本/token 的特征维统计。

### LayerNorm

对 Transformer 中一个 token 的隐状态 $x\in\mathbb{R}^{d}$：

$$
\mu=\frac1d\sum_{j=1}^{d}x_j,qquad
\sigma^2=\frac1d\sum_{j=1}^{d}(x_j-\mu)^2
$$

$$
\operatorname{LN}(x)_j=gamma_j\frac{x_j-\mu}{\sqrt{\sigma^2+\epsilon}}+\beta_j
$$

对形状 $[B,T,D]$ 的输入，LN 通常沿最后的 $D$ 维对每个 token 独立归一化。它不依赖 Batch 中其他样本，也不维护运行均值和方差，因此训练与推理的统计行为相同。

### BatchNorm

对全连接输入 $[B,C]$ 或卷积输入 $[B,C,H,W]$，BN 通常对每个通道 $C$ 分别统计：全连接时沿 Batch 维，卷积时沿 $B,H,W$ 维计算均值和方差。

训练时 BN 使用当前 mini-batch 统计量，并更新 running mean/variance；推理时通常使用训练期间累积的运行统计量。因此 `train` 和 `eval` 模式的行为不同，小 Batch、数据分布变化或分布式各卡 Batch 过小时，统计量可能不稳定。

### 关键对比

| 维度 | BatchNorm | LayerNorm |
|---|---|---|
| 归一化对象 | 同一通道的多个样本/空间位置 | 单个样本或 token 的特征维 |
| 依赖 Batch Size | 是 | 否 |
| 训练/推理 | 使用不同统计量 | 计算方式相同 |
| 运行统计 | 需要 | 不需要 |
| 序列长度 | Padding 和长度会干扰跨位置统计 | 每个 token 独立，自然支持变长 |
| 常见场景 | CNN、大 Batch 视觉训练 | Transformer、RNN、LLM |

### Transformer 为什么更适合 LayerNorm

1. 文本是变长序列，Padding 位置不应影响有效 token 的统计量。
2. LLM 训练常因显存限制使用较小 micro-batch，BN 统计可能噪声很大。
3. 自回归推理逐 token 进行，不能让一个 token 的结果依赖同 Batch 中恰好有哪些其他请求。
4. Tensor Parallel 中 LN 只需对当前 token 的 hidden 维度汇总，其语义不依赖全局 Batch 分组。

BN 并非不能用在任何序列模型中，但需明确 Mask、时间维和运行统计如何处理。在 CNN 中，BN 利用 Batch 与空间位置的大量样本统计，仍然非常有效。

### 面试简答版

BatchNorm 对每个特征通道跨 Batch 统计均值和方差，训练时用 mini-batch 统计并更新 running statistics，推理时用运行统计，所以它依赖 Batch Size 且训练/推理行为不同。LayerNorm 对每个样本或 token 的 hidden 维度独立归一化，不依赖其他样本，训练和推理计算方式相同。因此 LN 更适合变长、小 Batch 和逐 token 推理的 Transformer。
