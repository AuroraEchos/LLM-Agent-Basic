> **问题：** 如何校准 Judge，并测量其与人工标注的一致性？
>
> **分类：** 评估、幻觉与安全
>
> **来源：** [CORE_INTERVIEW_QUESTIONS.md](../../CORE_INTERVIEW_QUESTIONS.md)
<!-- AUTO-QUESTION:END -->

## 我的答案

Judge 校准不是调整 Prompt 直到“看起来合理”，而是在代表性人工 gold set 上测其可靠性、偏差和阈值，并将 Judge 版本冻结。人工标注本身也需先建立一致的 rubric 和质量控制。

### 一、建立 Gold Set

按任务、语言、长度、质量、风险和模型来源分层抽样，加入 tie、事实细微错误、风格诱饵、位置交换和 Prompt Injection。每例至少双人独立标注，专家仲裁；记录分歧而非只保留最终标签。

### 二、人工一致性

分类可用 Cohen/Fleiss κ，排序/等级可用 weighted κ、Spearman/Kendall；二元也报告 raw agreement，因为 κ 受类别不平衡影响。人工之间一致性是 Judge 可达到的现实参照，而非默认 100%。

### 三、Judge 指标

- Pointwise：accuracy、macro-F1、各等级 confusion、MAE/Spearman；
- Pairwise：win/tie accuracy、swap consistency、与人类偏好的 Kendall/相关；
- 概率输出：Brier、log loss、Expected Calibration Error；
- 偏差：长度斜率、位置翻转、自家族偏好和分组误差；
- Repeatability：相同输入多次判断的一致率。

### 四、阈值与概率校准

在 validation set 上用 temperature scaling、isotonic 等校准置信度，选择满足目标 precision/recall 的 accept/reject/abstain 阈值。低置信、位置翻转、Judge 分歧和高风险样本转人工，不强制自动结论。

### 五、改进与防过拟合

修改 rubric、增加 anchor examples、拆 claim、统一格式，并重新评估完整 challenge set。不能在最终 test 上反复调 Prompt。Judge model/Prompt/template/temperature/version 任一变化都视为新评委，需要重新校准。

### 六、线上漂移

周期性人工抽样，监控 Judge 分数分布、abstain、分组误差和与用户/环境真值偏离。保留一组长期 canary；Judge 只用于它校准过的任务域，不外推到新语言/领域。

### 面试简答版

先构建按任务、语言、长度、风险分层的人工 gold set，由多人盲标并仲裁，先报告人工自身 κ/一致率。Judge 对 pointwise 看 accuracy、macro-F1、混淆和相关；pairwise 看胜负/tie、swap consistency；置信度看 Brier/ECE，并专测长度、位置、自偏好与重复性。用 validation set 校准概率和 accept/abstain 阈值，低置信或高风险交人工。Judge 模型、Prompt、模板或版本变化都要重新校准，线上持续用人工抽样和 canary 监控漂移。
