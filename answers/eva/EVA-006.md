## 我的答案

这些指标比较的是不同对象：Pass@k 看多次采样是否至少一次成功；Exact Match 看规范化后完全一致；F1 看 token/标签集合重叠；BLEU 偏精确 n-gram；ROUGE 偏参考内容召回；语义相似度看表示层含义接近。指标必须与任务成功条件一致。

### 一、Pass@k

适合代码、数学证明候选或可由 verifier 判断成败的生成任务。从 \(n\) 个样本中有 \(c\) 个通过时，常用无偏估计：

\[
pass@k=1-\frac{\binom{n-c}{k}}{\binom nk}
\]

它反映给用户/搜索器 k 次机会的解决率。比较时固定温度、n、k 和总 token；pass@k 高而 pass@1 低说明需较多采样成本。没有可靠 verifier 时不适用。

### 二、Exact Match

\[
EM=\mathbf1[normalize(\hat y)=normalize(y)]
\]

适合短答案、分类、ID、结构化字段和数学规范结果。优点是确定、可复现；缺点是对同义、顺序无关集合和等价公式过严。Normalization 必须预先定义，不能看到结果后随意放宽。

### 三、F1

\[
P=\frac{|pred\cap gold|}{|pred|},\quad
R=\frac{|pred\cap gold|}{|gold|},\quad
F1=\frac{2PR}{P+R}
\]

适合抽取式 QA、NER、多标签和答案 token 部分重叠。需说明 micro/macro、分词和多 gold 处理；它不理解词序、否定和事实逻辑。

### 四、BLEU

基于 1～N-gram precision 的几何平均并带 brevity penalty，传统上适合机器翻译、与多个 reference 比较。语料级更稳定；对开放生成、单 reference 和语义等价改写相关性弱，通常不适合作为聊天质量主指标。

### 五、ROUGE

ROUGE-N 看 n-gram overlap，ROUGE-L 看最长公共子序列，常用于摘要的内容覆盖/召回。它能衡量是否覆盖参考措辞，却会奖励复制，不保证事实一致、无幻觉或摘要可读；需搭配 faithfulness 和人工/Judge。

### 六、语义相似度

用 embedding cosine、BERTScore 或 learned metric 比较语义，适合 paraphrase、开放 QA 和多种等价表达。它可能把主题相近但结论相反、数字错误的文本判得很近，也受模型/语言/领域影响。关键实体、数字、否定需规则或 claim verifier 补充。

### 七、组合原则

代码用 tests + pass@k；短事实用 EM/F1 + claim correctness；翻译可 BLEU/semantic + 人工；摘要用 ROUGE + coverage + faithfulness；开放对话用 rubric/Judge/人工和真实任务成功。报告 corpus/sample aggregation 与置信区间。

### 面试简答版

Pass@k 适合代码等可验证任务，表示 k 个候选至少一个通过；EM 适合短答案和结构化字段，但对等价表述过严；F1 适合抽取、NER 和多标签的部分重叠；BLEU 以 n-gram precision 为主，传统上用于翻译；ROUGE 偏参考内容召回，常用于摘要；语义相似度适合改写和开放答案，却可能忽略数字、否定和事实冲突。生产评测通常组合确定性 verifier、重叠/语义指标和人工/Judge，不能用单一指标包打天下。
