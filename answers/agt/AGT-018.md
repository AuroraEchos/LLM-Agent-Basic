> **问题：** Agent 的工作记忆、短期记忆、长期记忆和外部知识如何划分？

## 我的答案

划分依据是**生命周期、用途和权威来源**。工作记忆用于当前一步计算，短期记忆维持当前会话，长期记忆跨会话保存用户/Agent 可复用信息，外部知识则是独立于某个用户经历的权威语料或系统状态。

### 一、工作记忆

当前模型调用和执行循环直接需要的状态：目标、当前步骤、工具观察、局部变量、剩余预算。它通常在 context/state store 中，粒度最细、更新频繁，任务结束即可清理或压缩。

工作记忆不等于把完整 chain-of-thought 永久保存；应保留可审计 decision、action、observation 和任务状态。

### 二、短期记忆

覆盖一次会话或任务的多轮历史：用户刚提到的实体、已澄清约束、阶段性摘要、已完成步骤和临时文件。它帮助处理指代和恢复中断，有 session TTL；任务完成后只把经筛选的信息晋升长期记忆。

### 三、长期记忆

跨会话可复用：明确用户偏好、经验证的稳定用户事实、历史事件摘要和成功策略。它应结构化存储并带 `owner、type、source、created/valid time、confidence、ACL、TTL`，可查、可更正、可删除。

长期记忆不是聊天日志垃圾场。敏感数据需要同意，推断性偏好不得冒充用户声明，过期事实必须失效。

### 四、外部知识

产品手册、组织政策、数据库、知识图谱和 Web 等独立知识源，通常由 RAG/工具按需读取。它可能比长期记忆更权威、更常更新，并有自己的版本、权限和 provenance。

“用户上次说喜欢窗口位”是个人长期记忆；“航班行李政策”应查当前外部知识；“订单正在退款”是实时业务状态，不应写成永久事实。

### 五、状态流转

```text
外部知识/用户输入 → 当前 observation
→ 工作/短期状态
→ 验证、去敏、获同意、判断复用价值
→ 晋升长期记忆
```

检索时先按 owner/ACL/type/time 过滤，再按相关性和新鲜度排序。冲突优先实时权威源和用户最新明确陈述，并保留旧值的有效区间，而非直接覆盖历史。

### 面试简答版

工作记忆是当前 Agent step 的目标、变量和 observation；短期记忆覆盖当前会话的约束、阶段摘要和任务进度；长期记忆跨会话保存经验证、获同意且可复用的用户偏好、事实或经验；外部知识是手册、数据库、知识图谱等独立权威源。任务状态和实时订单不应伪装成长期事实，聊天日志也不应全部持久化。信息只有经来源验证、隐私检查、TTL/ACL 和用户同意后才从短期晋升长期，查询时仍以最新权威源为准。
