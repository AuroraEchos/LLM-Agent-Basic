> **问题：** 多 Agent 如何通过投票、辩论、仲裁或置信度解决冲突？

## 我的答案

多 Agent 冲突不能默认“少数服从多数”。如果 Agents 共享同一模型、Prompt 和错误来源，它们的错误高度相关；三票一致不等于三份独立证据。仲裁应优先可验证事实，其次才是聚合意见。

### 一、投票

对封闭、答案可归一化的任务可多数票或加权票：

\[
\hat y=\arg\max_y\sum_i w_i\mathbf1[y_i=y]
\]

权重由该领域历史校准、证据质量和独立性决定，不由 Agent 自称专家决定。投票适合分类、计算候选；不适合价值判断、开放文本和一个正确少数派对抗同源错误。

### 二、辩论

各 Agent 提交 claim、证据和反驳，有限轮交换后修订。它能暴露假设、遗漏和证据矛盾，但也会造成说服性偏差、群体趋同、token 增长，甚至把错误传播给原本正确的 Agent。采用角色/证据隔离、固定轮数和结构化论点。

### 三、仲裁

独立 Arbiter 根据原问题、候选答案、可验证证据和 rubric 选择或合成。高质量做法是隐藏作者身份/顺序、随机交换位置，并要求逐 claim 引用。Arbiter 不应只是同一模型看一遍；可用规则、测试、权威工具或人类处理高风险分歧。

### 四、置信度

模型自报 0.9 往往未校准。应基于历史 calibration、工具证据、测试覆盖、来源独立性和任务分布计算。可用 Brier/ECE 校准，并将“答案置信”和“证据充分性”分开。

### 五、推荐决策顺序

```text
确定性 verifier/权威数据
→ 证据一致且可追溯的候选
→ 校准加权投票或独立仲裁
→ 无法消解且高风险：用户/专家确认
```

冲突记录不应被汇总器静默删除。最终输出说明分歧、适用条件和不确定性。

### 面试简答版

可验证任务先用测试、数据库或规则裁决，而不是投票。封闭答案可做校准加权投票，但同模型同 Prompt 的票错误相关，不能当独立样本；开放问题可有限轮辩论以暴露证据和假设，再由隐藏身份/顺序的独立仲裁器按 rubric 与引用判断。模型自报置信度需用历史准确率、证据质量和 ECE/Brier 校准。高风险且证据仍冲突时交给用户或专家，答案应保留分歧而不是静默拼接。
