## 我的答案

Transformer 用 Attention 让当前 token 直接按内容访问历史 token；State Space Model（SSM）把历史压缩进一个递归状态。离散形式可写成：

$$h_t=\bar A_t h_{t-1}+\bar B_t x_t,\qquad y_t=C_t h_t+D x_t$$

传统线性时不变 SSM 的参数不随 token 改变，难以按内容选择保留/遗忘。Mamba 的 selective SSM 让步长及 $B,C$ 等由输入决定，使模型能根据当前 token 选择性写入、读取状态，并用 hardware-aware scan 并行训练。

| 维度 | Transformer Attention | Selective SSM |
|---|---|---|
| 长度计算 | full attention 约 $O(L^2)$ | scan 通常随 $L$ 线性 |
| 自回归状态 | KV Cache 随历史长度增长 | 固定大小 recurrent state |
| 历史访问 | 可直接内容寻址任意旧 token | 历史被压缩进状态，可能遗失细节 |
| 训练并行 | 矩阵乘生态成熟 | 需专用 scan/kernel，硬件实现很关键 |
| 推理 | 长上下文 KV 带宽昂贵 | 每步更新固定状态，流式场景有优势 |

SSM 的线性复杂度不等于对所有长程任务都更强。要求精确复制远处随机字符串、任意位置检索或在大量细节间比较时，固定状态可能成为信息瓶颈；Attention 虽贵，却提供显式内容寻址。反过来，音频、时间序列、基因和持续流式输入可能更适合状态递推。

因此实际架构常做 hybrid：局部/稀疏 Attention 保留精确检索能力，SSM/卷积承担大部分长程混合。比较时要控制参数、训练 tokens 和硬件，并同时测 perplexity、真实长程任务、prefill/decode 吞吐、内存及 kernel 成熟度，不能只比较渐进复杂度。

### 面试简答版

Transformer 保存历史 K/V并通过 Attention 直接内容寻址，full attention 计算随长度近二次、cache 随长度增长；SSM 把历史递归压到固定状态，训练 scan 和推理更新可随长度线性。Mamba 用输入相关参数实现选择性记忆/遗忘，改善传统 SSM 的内容选择能力。但固定状态可能丢失精确远处细节，所以它不是无条件替代 Attention，hybrid 往往在流式效率与精确检索间更稳妥。
