## 我的答案

World Model 的核心是学习环境在动作作用下如何演化，使 Agent 能在内部“想象未来”并据此规划。一个简化形式是学习：

$$p(s_{t+1},o_{t+1},r_t\mid s_t,a_t)$$

其中 $s_t$ 是潜在状态，$o_t$ 是观测，$a_t$ 是动作，$r_t$ 是奖励/代价。实际系统通常包含表示模型（观测→状态）、transition/dynamics、reward/termination，以及在模型中 rollout 的 policy/planner。Dreamer 一类方法就在学习到的 latent dynamics 中想象轨迹来改进策略，从而减少昂贵真实环境交互。

### 与语言模型、多模态模型的关系

语言模型学习的是 token 条件分布 $p(x_{t+1}\mid x_{\le t})$。文本包含大量世界知识，因此 LM 可以表现出某种预测和规划能力；但它通常没有显式 action-conditioned environment state、奖励、物理一致性和闭环校正，所以“预测下一个 token”不能自动等同于可靠 world model。

多模态模型把图像、视频、音频、动作或传感器统一编码，提供构建 world model 所需的观测与生成能力；但仅能描述视频也不代表理解干预。World Model 特别强调：给定动作会发生什么、状态中哪些量持续存在、如何估计不确定性，并把预测用于控制。它可以用 Transformer、SSM、diffusion 或其他架构实现，概念不绑定某一种网络。

### 关键难点

- 部分可观测下要从历史推断隐状态；
- 长时 rollout 会累积误差，策略还会寻找模型不准确处“钻空子”；
- 随机/多模态未来不能只用单一均值预测；
- 训练数据覆盖不了所有干预和安全边界；
- 高保真像素生成不一定保留决策所需的因果变量。

因此部署需做 uncertainty-aware planning、短 horizon 重规划、真实环境校正、out-of-distribution 检测和安全约束。评价不只看重建/视频观感，而要看多步预测校准、反事实/干预、下游控制回报和真实环境安全。

### 面试简答版

World Model 学习“状态 + 动作 → 下一状态/观测/奖励”，让 Agent 在潜在空间想象未来并规划。语言模型从文本预测下一个 token，可能隐含世界知识，但缺少显式动作、闭环状态和物理校正；多模态模型提供视频/传感器表示，也不必然具备可干预的动力学。真正难点是部分可观测、长 rollout 误差、随机未来和 model exploitation，因此要用不确定性、短程重规划及真实环境反馈约束。
