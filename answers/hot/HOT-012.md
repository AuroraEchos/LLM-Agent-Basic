## 我的答案

DeepSeek-R1 系列最重要的结论不是“RL 从零创造推理”，而是：预训练模型已有大量潜在能力，在可验证任务、有效奖励和足够 rollout 计算下，RL 能强化长思考、反思和多路径探索等行为。

### R1-Zero：先验证纯 RL 路径

R1-Zero 从 DeepSeek-V3 Base 出发，不先做 reasoning SFT，直接使用 GRPO。对每个问题采样一组输出，以组内相对 reward 构造 advantage，从而不依赖 PPO 式的同规模 critic。训练信号主要是：

- 可验证的 accuracy reward，例如数学答案、代码测试和逻辑结果；
- format reward，要求推理与最终答案采用指定结构。

随着训练进行，论文观察到响应变长，并出现重新检查、反思和探索替代方案等模式。这说明奖励选择能让已有策略分布中的有效行为被持续放大；所谓“aha moment”是训练轨迹中的行为变化，不应神秘化为突然获得通用智能，也不能仅凭输出更长就证明推理更强。

R1-Zero 的局限也很明确：可读性较差、会中英混杂，而且规则奖励主要覆盖容易验证的数学、代码和逻辑任务。若 verifier 有漏洞，模型还可能 reward hacking；开放式写作和真实软件工程很难获得同样便宜可靠的奖励。

### R1：多阶段提高可用性和通用性

DeepSeek-R1 使用更完整的流程：少量高质量 cold-start reasoning 数据进行 SFT → 第一阶段 reasoning-oriented RL，并加入语言一致性约束 → 对该 checkpoint 生成结果做 rejection sampling，与非推理数据混合再 SFT → 最终 RL，同时兼顾推理准确性以及 helpfulness/harmlessness 等偏好。

这条路线保留了 R1-Zero 证明的 RL 增益，又用 cold start、SFT 和通用数据改善格式、语言一致性与非推理能力。随后还把 R1 生成的推理数据蒸馏到多个较小 dense 模型，说明行为模式可迁移；但蒸馏学生受自身容量、数据覆盖和 teacher 错误限制，并不等于复制 teacher 的全部能力。

### 面试简答版

R1-Zero 从预训练 base 直接用 GRPO，在数学/代码等可验证任务上依靠 accuracy 和 format reward，训练中逐渐强化长思考、反思和替代路径；这更像挖掘并放大预训练潜力，而不是 RL 凭空创造推理。它有可读性、语言混合和 reward hacking/任务覆盖限制。R1 因此加入 cold-start SFT、推理 RL、rejection sampling 加通用数据 SFT及最终偏好 RL，在能力和可用性之间取得更完整平衡。
