## 我的答案

GRPO 对每个 Prompt 采样 \(G\) 个候选，用组内均值/标准差构造优势：

\[
\hat A_i=\frac{r_i-\bar r}{s_r+\epsilon}
\]

组大小同时决定 baseline 估计质量、获得差异化奖励的概率、每步 rollout 成本，以及固定预算下能覆盖多少不同 Prompt。

### 一、G 太小时

- \(G=1\) 时组均值就是自身 reward，中心化后 advantage 为 0，无法形成相对学习信号；
- \(G=2\) 可以比较，但均值和标准差由两个点决定，单个 reward 噪声会直接翻转方向；
- 候选多样性低，二元 verifier 很容易“全错”或“全对”，整组无信号；
- baseline 对单次采样很敏感，梯度方差大。

小 G 的优势是 rollout token 少，可在相同预算下覆盖更多 Prompt，适合 reward 连续、候选差异本来就丰富的场景。

### 二、增大 G 的收益

若每次采样成功率近似为 \(p\)，至少获得一个成功回答的概率为：

\[
P(\text{at least one success})=1-(1-p)^G
\]

G 增大可：

- 更稳定估计同一 Prompt 下的 reward 均值和方差；
- 更容易同时出现正/负样本，为二元 reward 产生排序信号；
- 覆盖多种推理路径，发现稀有正确轨迹；
- 让组内相对难度 baseline 更可靠。

对 Bernoulli reward，全组相同的概率为：

\[
P(\text{no signal})=p^G+(1-p)^G
\]

当 \(p\) 很接近 0 或 1 时，即使 G 增大也可能经常全同，说明 prompt 难度或 reward 粒度需要调整。

### 三、增大 G 的成本

Rollout 成本近似：

\[
C_{rollout}\propto
G\cdot \mathbb E[|o|]
\]

长推理 Decode 往往是 RL 训练的主要成本。固定总 token budget 下，G 越大，能采到的独立 Prompt 越少；baseline 方差降低，却可能增加 Prompt 分布估计方差和过拟合少数题目。

此外同组样本共享 Prompt、优势相互依赖，不等价于 G 个独立训练样本。显存还要保存更多 token、old log-prob 与 mask，过大的 G 可能降低并行效率或导致长尾等待。

### 四、方差与标准化的细节

样本均值误差通常随 \(G\) 增大而下降，但 GRPO 又除以组内标准差。若真实方差很小，极小噪声会被放大；G 大并不能自动修复 reward 本身的不可靠。

可采用：

- 标准差 floor / 较大 \(\epsilon\)；
- 方差低于阈值时跳过该组；
- 只中心化不除标准差，或用跨 batch 的稳健 scale；
- reward clipping、rank-based advantage；
- 去重候选，避免重复文本虚增 G。

这些都会改变估计器，要用独立质量验证，不能只看训练稳定。

### 五、如何选择 G

1. 先测 SFT policy 在目标题集上的单样本成功率和 reward variance；
2. 估算不同 G 下 mixed-reward group 比例与每个有效梯度组的 rollout tokens；
3. 在固定总 rollout token 下比较 G，而不是固定 Prompt 数；
4. 同时看成功率、reward std、无信号组比例、KL、吞吐和题目覆盖；
5. 可按难度自适应：简单/困难题用更少或先做 curriculum，中等难度题用足够 G；但自适应采样要记录 propensity，避免无意改变训练分布。

典型最优值取决于模型、任务成功率、硬件和生成长度，不存在通用的 8 或 16。G 增大到有效信号率收益趋平、却显著减少独立 Prompt 覆盖时，应停止。

### 面试简答版

GRPO 的组大小 G 决定组内 baseline 质量。G 太小，均值/方差噪声大，G=1 甚至中心化后无信号；增大 G 能提高至少采到一个正确轨迹的概率 \(1-(1-p)^G\)，并稳定相对优势。但 rollout 成本与 \(G\times\)输出长度近似线性增长，固定 token 预算下会减少独立 Prompt 覆盖。二元奖励全同概率为 \(p^G+(1-p)^G\)，p 极端时单纯增 G 也无效。应按固定 rollout token 比较有效组比例、reward std、正确率和吞吐，并对近零方差组设 floor 或跳过。
