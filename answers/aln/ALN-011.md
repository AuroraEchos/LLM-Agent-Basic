> **问题：** DPO 中 Reference Model 和 \(\beta\) 分别起什么作用？

## 我的答案

DPO 的核心 margin 是：

\[
m_\theta=
\left(\log\pi_\theta(y_w|x)-\log\pi_{ref}(y_w|x)\right)
-\left(\log\pi_\theta(y_l|x)-\log\pi_{ref}(y_l|x)\right)
\]

损失为：

\[
\mathcal L_{DPO}=-\log\sigma(\beta m_\theta)
\]

Reference Model 决定“相对哪个行为起点衡量变化”，\(\beta\) 来自 KL 正则化强度并同时充当偏好 logit 的尺度。

### 一、Reference Model 的作用

从 KL 正则化 RL 的最优策略：

\[
\pi^*(y|x)\propto
\pi_{ref}(y|x)\exp(r(x,y)/\beta)
\]

可见 reference 是策略先验。DPO 不直接在 loss 中写一个逐样本 KL，但通过 policy/reference log-ratio 隐式保留同一锚点。

它有几项作用：

1. **定义隐式奖励**：
   \[
   r_\theta(x,y)=\beta\log\frac{\pi_\theta(y|x)}{\pi_{ref}(y|x)}+C(x)
   \]
2. **抵消基础难度**：一个回答本来就被 SFT 模型高概率生成，不应仅因绝对 log-prob 高就被视为获得了巨大偏好提升；DPO 看相对变化。
3. **保留能力与语言先验**：reference 通常取 SFT 初始化，避免只靠有限 pair 重塑整个输出分布。
4. **提供可复现坐标系**：reference 一旦更换，隐式 reward 和同一 pair 的 margin 都改变，实验不可直接比较。

Reference 必须冻结且与 policy 使用相同 tokenizer、Chat Template、response mask 和序列 log-prob 计算。可预计算数据集中 chosen/rejected 的 reference log-prob 以节省训练显存，但数据或模板变化后必须重算。

### 二、Reference 应如何选择

通常选择 DPO 开始前的 SFT checkpoint：质量尚可、对偏好数据有支持、与 policy 初始化一致。若 reference 太弱，锚点不能保留所需行为；太强或与当前任务分布不匹配，log-ratio 标尺也可能奇怪。

将不同 base、tokenizer 或量化误差明显的模型作为 reference，会让概率比不再是干净的“从同一起点改变多少”。PEFT 训练可隐式使用未挂 adapter 的同一 base 作为 reference，但要保证 dropout/eval mode 和量化计算一致。

### 三、\(\beta\) 的理论含义

在 RL 目标：

\[
\max_\pi \mathbb E[r]-\beta KL(\pi\|\pi_{ref})
\]

对固定真实 reward，较大 \(\beta\) 表示更强的 KL 代价，理论最优策略更接近 reference；较小 \(\beta\) 允许用更大分布变化追逐 reward。

### 四、\(\beta\) 在 DPO 优化中的作用

DPO 中 \(\beta\) 又直接缩放分类 logit \(\beta m_\theta\)。在初始化 \(\pi_\theta=\pi_{ref}\)、\(m=0\) 时，梯度尺度与 \(\beta\) 成正比。因此在有限模型、固定学习率与有限 epoch 下，“增大 beta 一定让实际模型更靠近 reference”并不总是单调成立；它还改变 loss 饱和速度和有效步长。

所以要同时理解：

- 理论上 \(\beta\) 是 KL regularization coefficient；
- 实现中它也是偏好分类 temperature/scale，与学习率、epoch、batch 和数据可分性耦合。

### 五、如何调参与监控

对数尺度搜索多个 \(\beta\)，固定数据、token budget 和学习率搜索预算，报告：

- held-out pair accuracy/loss；
- chosen/rejected policy 与 reference log-ratio；
- reward margin \(\beta m\)；
- policy-reference KL、entropy、回答长度；
- 独立人评、任务正确率、通用与安全回归。

若训练 pair margin 无限增大、rejected log-prob 崩塌而 held-out 质量不升，应 early stop、提高数据噪声建模/正则，不能只靠调 beta。最终选择 Pareto 点，而非 DPO train loss 最低点。

### 面试简答版

Reference Model 是冻结的 SFT 行为锚点，DPO 用 \(\log\pi_\theta-log\pi_{ref}\) 定义隐式 reward，衡量策略相对起点对 chosen 和 rejected 改了多少，并保留基础能力。它必须与 policy 的 tokenizer、模板和 mask 完全一致。\(\beta\) 在 KL 正则化 RL 中表示偏离 reference 的代价，理论上越大越保守；但在 DPO loss 中它也缩放偏好 logit和梯度，与学习率、epoch 耦合，所以实际 KL 未必简单单调。调参要看 held-out 偏好、policy-reference KL、概率轨迹、长度和独立质量。
