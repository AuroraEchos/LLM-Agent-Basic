> **问题：** PPO 的 Probability Ratio、Clipped Objective 和 Advantage 分别是什么？

## 我的答案

PPO 的目标是复用一批旧策略采样的数据做多次更新，同时防止新策略一次改变太大。Probability Ratio 衡量 sampled action 的概率变化，Advantage 指示这个 action 比 baseline 好还是坏，Clipped Objective 限制从同一批数据中获得的过度乐观收益。原始定义见 [PPO 论文](https://arxiv.org/abs/1707.06347)。

### 一、LLM 中的概率比

对 token \(a_t=y_t\)，状态 \(s_t=(x,y_{<t})\)。rollout 由 \(\pi_{old}\) 采样，更新中的 Actor 为 \(\pi_\theta\)：

\[
\rho_t(\theta)=
\frac{\pi_\theta(a_t|s_t)}{\pi_{old}(a_t|s_t)}
=\exp\left(\log\pi_\theta(a_t|s_t)-\log\pi_{old}(a_t|s_t)\right)
\]

这里用 \(\rho\) 避免与 reward \(r_t\) 混淆。\(\rho_t>1\) 表示新策略提高该 token 概率，\(<1\) 表示降低。通常按 token 计算 ratio 和 loss；若把整条长序列的概率直接相乘，数值与方差都会很不稳定。

### 二、Advantage

\[
A_t=Q(s_t,a_t)-V(s_t)
\]

- \(A_t>0\)：该 token 后续回报高于 Critic 对当前前缀的预期，应提高概率；
- \(A_t<0\)：结果低于预期，应降低概率；
- value baseline 不改变理想 policy-gradient 的期望，但能降低方差。

LLM 中 RM 常只在序列末端给奖励，逐 token KL 提供 dense reward，再用 GAE 把未来回报分配给每个生成 token。

### 三、未裁剪目标与风险

\[
L^{PG}(\theta)=\mathbb E_t[\rho_t(\theta)A_t]
\]

同一 rollout 训练多个 epoch 后，当前策略逐渐偏离 old policy，ratio 可能变得极端，使 noisy advantage 产生过大更新。

### 四、Clipped Objective

PPO-Clip 最大化：

\[
L^{clip}(\theta)=
\mathbb E_t\left[
\min\left(
\rho_tA_t,
\operatorname{clip}(\rho_t,1-\epsilon,1+\epsilon)A_t
\right)
\right]
\]

分情况理解：

- \(A_t>0\) 时，提高 token 概率是好方向，但 \(\rho_t>1+\epsilon\) 后收益截平；
- \(A_t<0\) 时，降低 token 概率是好方向，但 \(\rho_t<1-\epsilon\) 后收益截平；
- 对朝坏方向的变化，`min` 不会替策略兜底，仍会产生纠正梯度。

实现通常最小化负的 \(L^{clip}\)，且只在非 padding 的 response token 上计算。

### 五、完整 PPO Loss

常见形式还包含 Critic 和 entropy：

\[
\mathcal L=-L^{clip}
+c_v\mathcal L_{value}
-c_e\mathcal H(\pi_\theta)
\]

此外 RLHF reward 通常已有相对 Reference 的 KL penalty。要区分：

- PPO clip/old-policy KL：限制一次 optimization epoch 相对本轮采样策略的变化；
- reference KL：限制长期 Actor 相对 SFT reference 的漂移。

### 六、Clip 不是硬 Trust Region

clip 只截断 surrogate objective 的部分激励，不保证所有 ratio 都在区间，也不保证真实 KL 小。应监控 approximate KL、reference KL、clip fraction、ratio 极值、entropy、梯度范数、RM reward、回答长度和独立质量。

若 KL 突增，可减少 PPO epoch、学习率或 clip range，提前停止当前更新，或调大 reference KL 系数。Advantage whitening、mask 和长度归一化也会显著改变实际步长。

### 面试简答版

对 LLM，每个前缀是 state、下一个 token 是 action。Probability Ratio \(\rho_t=\pi_\theta(a_t|s_t)/\pi_{old}(a_t|s_t)\) 衡量新策略对已采样 token 概率的改变；Advantage \(A_t=Q-V\) 表示该动作比 Critic 预期好还是坏。PPO 最大化 \(\min(\rho_tA_t,\operatorname{clip}(\rho_t,1-\epsilon,1+\epsilon)A_t)\)：正优势时限制过度增大概率，负优势时限制过度降低概率。clip 不是硬 KL 约束，还要监控 old-policy KL、reference KL、clip fraction 和 ratio。
