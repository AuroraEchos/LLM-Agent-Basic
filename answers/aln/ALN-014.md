> **问题：** IPO、KTO、ORPO、SimPO 和 CPO 分别对 DPO 做了什么改动？
>
> **分类：** RLHF、偏好优化与推理强化学习

> **来源：** [INTERVIEW_QUESTIONS_AGENT_HARNESS_EXPANDED.md](../../INTERVIEW_QUESTIONS_AGENT_HARNESS_EXPANDED.md)

## 我的答案

这些方法都试图降低 PPO 的复杂度或修正 DPO 的某个缺陷，但需要的数据、是否使用 Reference、是否包含 SFT/BC 项和长度处理不同。名称 CPO 在文献中存在复用；这里按常见语境指 [Contrastive Preference Optimization](https://arxiv.org/abs/2401.08417)。

先定义 DPO 的相对 margin：

\[
h_\pi=
\log\frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)}
-\log\frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)}
\]

\[
\mathcal L_{DPO}=-\log\sigma(\beta h_\pi)
\]

### 一、IPO：给 Margin 一个有限目标

Identity Preference Optimization 来自 \(\Psi\)PO 框架，针对 DPO 在确定性/有限偏好数据上可能把 margin 推向无穷、发生过训练的问题。其实用形式可写为：

\[
\mathcal L_{IPO}=
\left(h_\pi-\frac{1}{2\beta}\right)^2
\]

它不再用 logistic loss 无止境扩大可分 pair 的 margin，而把相对 log-ratio 差拉向有限目标，从而提供更显式的正则。它仍需要 paired preference 和 reference。参见 [IPO/\(\Psi\)PO 论文](https://arxiv.org/abs/2310.12036)。

### 二、KTO：只需要 Desirable / Undesirable 标签

Kahneman–Tversky Optimization 不要求同一 Prompt 下成对比较，只需单条：

```text
(x, y, desirable) 或 (x, y, undesirable)
```

它定义相对 reference 的隐式 reward：

\[
r_\theta(x,y)=log\frac{\pi_\theta(y|x)}{\pi_{ref}(y|x)}
\]

再以策略与 reference 的平均 KL 作为参考点，使用前景理论风格、对收益与损失不对称的 sigmoid utility：desirable 输出应高于 reference point，undesirable 应低于它，并可给两类不同权重。

优势是现实数据常只有点赞/点踩或 accept/reject，无需昂贵 pair；风险是二元标签的基准随用户变化、正负样本比例和 KL reference point 估计会影响训练。它仍通常需要 Reference。参见 [KTO 论文](https://arxiv.org/abs/2402.01306)。

### 三、ORPO：把 SFT 与偏好合成一个阶段

ORPO 是 reference-free 的单阶段目标：

\[
\mathcal L_{ORPO}=
\mathcal L_{NLL}(y_w)
+\lambda\mathcal L_{OR}
\]

令序列概率 \(p_\theta(y|x)\) 的 odds 为：

\[
\operatorname{odds}_\theta(y|x)=
\frac{p_\theta(y|x)}{1-p_\theta(y|x)}
\]

偏好项提升 winner 相对 loser 的 log-odds ratio。chosen NLL 负责强适配和保持生成能力，odds-ratio 项对 rejected 施加较弱惩罚。因此可不先单独 SFT 再 DPO，也不加载 reference。边界是超长序列概率极小，实际实现的数值稳定、mask 与概率聚合非常关键。参见 [ORPO 论文](https://arxiv.org/abs/2403.07691)。

### 四、SimPO：Reference-Free + 平均 Log-Prob + Margin

SimPO 把隐式 reward 定义为长度归一化后的策略 log-prob：

\[
r_{SimPO}(x,y)=
\frac{\beta}{|y|}\log\pi_\theta(y|x)
\]

目标为：

\[
\mathcal L_{SimPO}=-\log\sigma\left(
\frac{\beta}{|y_w|}\log\pi_\theta(y_w|x)
-\frac{\beta}{|y_l|}\log\pi_\theta(y_l|x)
-\gamma
\right)
\]

它去掉 Reference 以节省显存/计算，用 average log-prob 缓解序列长度累积，并要求 winner 超过 loser 一个目标 margin \(\gamma\)。但长度平均本身改变了偏好归纳偏置，且没有 reference 锚点时要靠数据、margin、早停和独立 KL 监控防漂移。参见 [SimPO 论文](https://arxiv.org/abs/2405.14734)。

### 五、CPO：Reference-Free Contrastive Loss + BC

本题所指 CPO 用 policy 自身的 winner/loser 概率做 contrastive preference：

\[
\mathcal L_{pref}=
-\log\sigma\left(
\beta[\log\pi_\theta(y_w|x)-\log\pi_\theta(y_l|x)]
\right)
\]

再加入 winner 的 behavior cloning/NLL regularizer：

\[
\mathcal L_{CPO}=\mathcal L_{pref}
+\lambda\mathcal L_{NLL}(y_w)
\]

它不需要 reference，BC 项防止只通过压低 loser 来满足偏好，并让 chosen 保持较高 likelihood。它最初在机器翻译偏好优化中提出；迁移到通用对话时仍需重新验证长度、风格与安全。

### 六、总结对比

| 方法 | 数据 | Reference | 关键改动 |
|---|---|---:|---|
| DPO | winner/loser pair | 是 | logistic 相对 log-ratio |
| IPO | pair | 是 | 平方损失，有限目标 margin |
| KTO | 单条好/坏标签 | 是 | 前景理论 utility 与 KL 参考点 |
| ORPO | pair | 否 | chosen NLL + odds-ratio，一阶段 SFT+对齐 |
| SimPO | pair | 否 | 平均 log-prob + target margin |
| CPO | pair | 否 | contrastive preference + chosen BC/NLL |

没有哪个目标普遍最好。应在相同数据、token budget、超参数搜索预算和模板下比较 held-out 偏好、chosen/rejected likelihood、reference KL、长度、通用能力与实际生成，而不是只复制论文中的单一 benchmark 排名。

### 面试简答版

IPO 把 DPO 的无限增大 margin 改为平方损失的有限目标，减少过训练；KTO 只需单条 desirable/undesirable 标签，用相对 reference 与 KL 参考点构造前景理论 utility；ORPO 不用 reference，把 chosen SFT NLL 和 winner/loser odds-ratio 合成单阶段训练；SimPO 用长度平均 log-prob 作为 reference-free reward，并加入目标 margin；CPO 用 policy 自身的 contrastive preference loss，再加 chosen 的 BC/NLL 防止只压低 loser。它们的数据与正则假设不同，必须同预算评估概率轨迹、KL、长度和独立质量。
