## 我的答案

DPO 的核心是：KL 正则化 RL 目标的最优策略与 reward 存在闭式关系，因此可以用策略相对 reference 的 log-ratio 直接参数化隐式 reward，再代入 Bradley–Terry 偏好概率，配分函数会在同一 Prompt 的分差中消掉。原始推导见 [DPO 论文](https://arxiv.org/abs/2305.18290)。

### 一、从 KL 正则化 RL 目标开始

对固定 prompt \(x\)，优化：

\[
\max_{\pi}\;
\mathbb E_{y\sim\pi(y|x)}[r(x,y)]
-\beta D_{KL}(\pi(y|x)\|\pi_{ref}(y|x))
\]

加上归一化约束 \(\sum_y\pi(y|x)=1\)，写 Lagrangian 并对 \(\pi(y|x)\) 求导，可得：

\[
r(x,y)-\beta\left(
\log\frac{\pi(y|x)}{\pi_{ref}(y|x)}+1
\right)+\lambda=0
\]

整理并归一化：

\[
\pi^*(y|x)=
\frac{1}{Z(x)}\pi_{ref}(y|x)
\exp\left(\frac{r(x,y)}{\beta}\right)
\]

其中：

\[
Z(x)=\sum_y\pi_{ref}(y|x)
\exp\left(\frac{r(x,y)}{\beta}\right)
\]

### 二、反解隐式 Reward

对上式取对数：

\[
r(x,y)=
\beta\log\frac{\pi^*(y|x)}{\pi_{ref}(y|x)}
+\beta\log Z(x)
\]

用可训练策略 \(\pi_\theta\) 代替未知最优策略，定义隐式 reward：

\[
r_\theta(x,y)=
\beta\log\frac{\pi_\theta(y|x)}{\pi_{ref}(y|x)}
+\beta\log Z(x)
\]

### 三、代入 Bradley–Terry

偏好数据有 winner \(y_w\) 和 loser \(y_l\)：

\[
P(y_w\succ y_l|x)=
\sigma(r(x,y_w)-r(x,y_l))
\]

因为二者共享同一个 \(x\)，\(\beta\log Z(x)\) 相减消失：

\[
r_\theta(x,y_w)-r_\theta(x,y_l)
=\beta\left[
\log\frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)}
-\log\frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)}
\right]
\]

于是 DPO 损失为：

\[
\mathcal L_{DPO}=
-\mathbb E_{(x,y_w,y_l)}
\log\sigma\left(
\beta\left[
\log\frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)}
-\log\frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)}
\right]
\right)
\]

它直接鼓励 winner 相对 reference 的 log-prob 增幅大于 loser。

### 四、序列 Log-Probability

\[
\log\pi_\theta(y|x)=
\sum_{t=1}^{T}
\log\pi_\theta(y_t|x,y_{<t})
\]

只对 response token 求和，prompt/padding mask 掉。默认序列求和与 Bradley–Terry 推导一致；改成长度平均会改变偏好模型和长度归纳偏置，虽然工程上可能有用，但应视为算法变体而非无害实现细节。

### 五、为什么省掉 RM 和 PPO

DPO 直接以 pair 数据对 \(\pi_\theta\) 做类似分类的离线训练，因此不需要：

- 显式训练/部署 scalar Reward Model；
- 在线 Actor rollout；
- Critic、GAE、PPO ratio 和 value loss；
- PPO 训练中的多模型同步。

Reference log-prob 可预计算，或训练时用冻结 reference 计算。因此实现和资源显著简化。

### 六、\(\beta\) 的含义

\(\beta\) 来自 KL 正则强度，也缩放 DPO logit。较大的 \(\beta\) 让同一 log-ratio 差产生更陡的分类信号，但它与实际策略偏移的关系还受学习率、epoch、数据可分性和模型容量影响，不能简单说“beta 越大就越接近 reference”而忽略优化过程。应直接监控 policy-reference KL、winner/loser reward margin 和独立质量。

### 七、假设与边界

- 假设 pairwise preference 可由 Bradley–Terry 单标量 reward 表达；
- reference 对偏好回答应有非零且足够的支持；离线数据覆盖不到的行为，DPO 不会主动探索；
- winner/loser 的模板、截断和长度偏差会直接进入序列 log-prob；
- 固定偏好数据可能过拟合，DPO 也会过度优化，并非天然免疫 reward hacking；
- 理论闭式最优是在策略分布可自由优化时得到，有限参数模型和 SGD 只近似实现。

工程上要检查 chosen/rejected 使用相同 prompt，response boundary 与 label mask 正确，reference 与 policy 的 tokenizer/template 完全一致，并按多个 checkpoint 监控 KL、准确率、长度和独立人评。

### 面试简答版

KL 正则化 RL 的最优策略满足 \(\pi^*(y|x)=\pi_{ref}(y|x)e^{r(x,y)/\beta}/Z(x)\)，所以可反解 \(r=\beta\log(\pi^*/\pi_{ref})+\beta\log Z(x)\)。把它代入 Bradley–Terry 的 winner/loser 概率，同一 Prompt 的 \(\log Z(x)\) 相消，得到 DPO 损失：最大化 winner 相对 reference 的 log-ratio 与 loser 相对 reference 的 log-ratio之差。这样无需显式 RM、在线 rollout、Critic 和 PPO，但依赖离线 pair 覆盖、固定 reference 和偏好模型假设，也要防长度偏差与过度优化。
