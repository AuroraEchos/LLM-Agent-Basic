## 我的答案

Reward Model 的 pair accuracy 只能回答“多数比较是否排对”，不能回答置信度是否可信、面对新策略是否仍泛化、何时应该拒绝打分。评估应分为校准、分布外切片和不确定性/选择性预测三部分。

### 一、先明确 RM 输出含义

Bradley–Terry RM 给 scalar \(r(x,y)\)，pair probability 为：

\[
\hat p=P(y_a\succ y_b)=\sigma(r_a-r_b)
\]

单个 reward 的加性常数不可识别，因此不能把 `reward=7` 解释成 70% 好，也不能直接比较不同 RM checkpoint 的原始均值。可校准的是 pair preference probability，或在额外 pointwise 标签下校准任务成功概率。

### 二、校准评估

在未参与训练/调参的 pair 集上按预测概率分桶，比较预测与真实 winner 频率。常用指标：

- Negative Log-Likelihood；
- Brier Score：
  \[
  \frac1N\sum_i(\hat p_i-y_i)^2
  \]
- ECE / reliability diagram；
- accuracy/AUROC 作为排序指标；
- tie、标注员分歧与 soft-label calibration；
- 不同 margin、长度和任务桶的校准。

可做 temperature scaling 或 isotonic regression，但校准器必须在独立 calibration split 上拟合。它只能校准已覆盖分布，不能修复 OOD 错误排序。

### 三、分布外泛化设计

Test 不应只是从同一批随机切 pair，而要沿实际部署漂移维度隔离：

- 新 Prompt source、领域、语言和时间；
- 新 Policy checkpoint、不同模型家族与更高 KL 输出；
- 更长/更短回答、不同 Chat Template 和工具格式；
- 对抗性、拒答、安全和罕见群体；
- 人类写作、AI 写作与多种解码 temperature；
- 高 reward 尾部和训练中 Actor 主动找到的样本。

画性能随 policy-reference KL、长度和时间的曲线。随机 IID accuracy 很高但新 Policy 上下降，说明 RM 不适合继续被优化。

### 四、不确定性的来源

- **Aleatoric**：问题本身主观，标注员偏好真实分歧；
- **Epistemic**：数据没覆盖，模型不知道；
- **Reward misspecification**：所有模型一致地学错代理，普通 ensemble 也可能不分歧。

可用：

- 不同 seed/data bootstrap/model 的 RM ensemble；
- annotator/group-specific models 或分层 Bradley–Terry；
- MC dropout / Bayesian head 等近似方法；
- pair 顺序翻转、自洽与扰动稳定性；
- 与规则 verifier、独立大模型 judge 和人类的 disagreement；
- embedding distance/OOD detector 作为辅助。

Ensemble variance 主要捕获模型分歧，不能证明共同偏差不存在。

### 五、选择性预测与主动学习

允许 RM 在高不确定样本上 abstain：只对置信度高或 ensemble 一致的样本自动打分，其余送人评/更强 verifier。报告 risk-coverage curve：覆盖率降低时，保留样本错误率是否下降。

优先标注：

- 当前 Actor 高 reward 且 RM 分歧大的输出；
- 预测概率接近 0.5 的边界 pair；
- OOD detector 高、业务风险高的样本；
- RM 与 verifier/人类冲突的样本。

这比继续随机标大量容易 pair 更能扩展决策边界。

### 六、训练期监控

Actor 优化会主动把输出推到 RM 高分且可能不确定的区域。每轮记录 proxy RM、holdout RM、ensemble disagreement、人评、KL、长度和 reward tail；若 proxy 上升而 gold/人评下降，应停止并刷新偏好数据。不能用正在被优化的同一 RM 作为唯一验收者。

### 面试简答版

Bradley–Terry RM 的绝对 scalar 不可直接解释，应该校准 \(\sigma(r_w-r_l)\) 的 pair 概率，用 NLL、Brier、ECE 和 reliability diagram，而不只看 accuracy。OOD 要按新 Prompt 来源、语言、时间、Policy checkpoint、KL、长度和安全类型隔离测试。用 RM ensemble、标注员分歧、扰动一致性和独立 verifier 估计不确定性，但 ensemble 不能发现共同偏差。高不确定样本应 abstain/送人评，并用 risk-coverage 和主动学习评估；Actor 训练中必须比较 proxy reward 与独立 gold/human score。
