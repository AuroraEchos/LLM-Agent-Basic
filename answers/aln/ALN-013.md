> **问题：** DPO 为什么可能出现过拟合偏好、概率质量下降或长度偏置？

## 我的答案

DPO loss 只要求“chosen 相对 reference 的提升”大于“rejected 相对 reference 的提升”，并不单独保证 chosen 的绝对似然上升，也不约束未观察到的其他回答。因此有限 pair 上的分类目标可能通过不理想的概率重分配被满足。

### 一、偏好过拟合

\[
\mathcal L=-\log\sigma(\beta m),
\quad
m=\log\frac{\pi_\theta(y_w)}{\pi_{ref}(y_w)}
-\log\frac{\pi_\theta(y_l)}{\pi_{ref}(y_l)}
\]

对可分的确定性偏好数据，不断增大 \(m\) 会持续降低交叉熵，理论上没有有限的最佳 margin。模型可记住训练 pair 的独特 token，使 train preference accuracy 接近 100%，而新 Prompt 不提升。

Reference log-ratio 是锚点，但 DPO loss 不是逐样本硬 KL constraint；训练 epoch、学习率和模型容量足够大时仍可显著漂移。标签噪声和相互矛盾 pair 还会让模型学习错误或脆弱边界。

### 二、概率质量下降 / Likelihood Displacement

增大 margin 有两条路径：

1. 提高 \(\log\pi_\theta(y_w)\)；
2. 降低 \(\log\pi_\theta(y_l)\)。

DPO 梯度常同时作用，但 softmax 归一化和参数共享意味着它可能主要把 rejected 概率压得极低，而 chosen 概率也下降，只是下降得更少。被移出的概率质量会流向数据中未观察的其他序列，其中不一定有更高质量回答。

因此 pair accuracy 或 reward margin 上升，不代表生成质量上升。必须分别记录：

- policy/reference chosen log-ratio；
- policy/reference rejected log-ratio；
- chosen 和 rejected 的绝对 sequence log-prob；
- policy entropy、reference KL、实际采样输出。

### 三、长度偏置从哪里来

序列 log-prob 是 token 求和：

\[
\log\pi(y|x)=\sum_{t=1}^{|y|}\log\pi(y_t|x,y_{<t})
\]

每项通常为负，长序列绝对 log-prob 更小；policy-reference log-ratio也会随 token 数累积。若 winner 系统性更长，DPO 会把“更长”与“更优”绑定，并给长回答更多 token 级梯度机会；若 loser 更长，也可能学到相反的过短偏置。

此外偏好标注员/teacher 本身可能偏爱详细回答，模板中的 EOS、截断和 padding mask 错误也会产生假长度信号。

### 四、如何发现

- Train/Validation pair loss 和 margin；若 train 继续下降而 held-out/人评饱和即预警；
- chosen/rejected 绝对与相对 log-prob 四条曲线；
- KL、entropy、EOS、长度、重复率和生成多样性；
- 在长度匹配 pair、相同内容扩写/压缩反事实上评测；
- 按 Prompt family 隔离的测试，而不是模板随机切分；
- 审计高 margin 但人评差的样本。

### 五、缓解

- early stopping、较小学习率/epoch、weight decay 或 PEFT 限制更新；
- 高质量、多样、语义隔离的 pair，保留 ties/不确定性而非全部硬标签；
- 长度匹配采样、长度切片和反事实 hard negatives；
- 加 chosen NLL/BC 项，防止只压 rejected；
- label smoothing、Conservative DPO，或用 IPO 设有限目标 margin；
- 采用 reference-free/长度归一化方法时仍做独立回归，因为改目标会带来其他偏置；
- 根据独立任务、人评和生成样本选 checkpoint，而非最低 DPO loss。

### 六、工程边界

直接把 sequence log-prob 除以长度不是纯修 bug，而是改变隐式 reward 定义；它可能减少长度偏置，也可能让重复低信息 token 的平均概率表现异常。应与 sum 版本做等预算消融，并同时报告 length-controlled 与原始人评。

### 面试简答版

DPO 只优化 winner 相对 reference 的 log-ratio差大于 loser，没有保证 winner 绝对概率上升。模型可通过把 rejected 概率压到极低来降低 loss，概率质量却流向未观察序列；确定性有限 pair 还会让 margin 不断增大并过拟合。序列 log-prob 按 token 求和，winner/loser 长度分布和人类冗长偏好会形成长度偏置。排查要分别画 chosen/rejected 的绝对与相对 log-prob、KL、entropy 和长度；缓解用早停、长度平衡 pair、chosen NLL、软标签/IPO 和独立生成评测。
