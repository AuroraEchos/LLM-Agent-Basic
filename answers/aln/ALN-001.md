> **问题：** 经典 RLHF 的 SFT、Reward Model 和 Policy Optimization 三个阶段如何衔接？
>
> **分类：** 训练、微调与对齐

> **来源：** [CORE_INTERVIEW_QUESTIONS.md](../../CORE_INTERVIEW_QUESTIONS.md)

## 我的答案

经典 RLHF 将“人类想要什么”逐步变成可优化信号：先用高质量示范得到可用策略，再用偏好比较学习 Reward Model（RM），最后让策略在不偏离参考模型太远的约束下最大化奖励。代表性流程可见 [InstructGPT 论文](https://arxiv.org/abs/2203.02155)。

### 一、阶段 1：SFT 建立初始策略

收集 prompt \(x\) 与标注员写出的理想回答 \(y\)，用 teacher forcing 最大化回答似然：

\[
\mathcal L_{SFT}=-\sum_t m_t\log \pi_{SFT}(y_t|x,y_{<t})
\]

SFT 让预训练模型进入可用的指令分布，学会角色、格式和基本行为，也为后续偏好候选、PPO Actor 与 Reference Model 提供质量尚可的初始化。若直接从预训练模型做 RL，探索空间过大，输出也更容易落到 RM 训练分布之外。

### 二、阶段 2：从偏好比较训练 Reward Model

对同一 prompt 从 SFT 模型或多个 checkpoint 采样多个回答，请标注员排序，形成 \((x,y_w,y_l)\)。Reward Model 输入 prompt+response，输出标量 \(r_\phi(x,y)\)。常用 Bradley–Terry 概率：

\[
P(y_w\succ y_l|x)=
\sigma(r_\phi(x,y_w)-r_\phi(x,y_l))
\]

对应损失：

\[
\mathcal L_{RM}=-\log\sigma(r_w-r_l)
\]

RM 学到的是标注分布中的相对偏好代理，而不是真实世界的绝对效用。它通常由语言模型 backbone 加 scalar head 构成，并在回答末端输出 sequence-level reward。

### 三、阶段 3：Policy Optimization

复制 SFT 模型得到可训练策略 \(\pi_\theta\)（Actor）与冻结参考策略 \(\pi_{ref}\)，另用 Critic 估计 token 前缀的 value。Actor 对 prompt 在线采样回答，RM 给完整回答打分。为防止策略钻 RM 漏洞或远离自然语言分布，加入相对 reference 的 KL 惩罚：

\[
R(x,y)=r_\phi(x,y)
-\beta\sum_t\log\frac{
\pi_\theta(y_t|x,y_{<t})
}{
\pi_{ref}(y_t|x,y_{<t})
}
\]

然后用 PPO 等算法提高高优势 token 的概率、降低低优势 token 的概率。实践中 KL 可作为逐 token reward，RM 分数通常加在终止位置，再由 GAE 向前传播。

### 四、三个阶段如何衔接

```text
人工示范 → SFT policy
              ├─ 生成候选 → 人类偏好 → Reward Model
              ├─ 冻结副本 → Reference Model
              └─ 可训练副本 → Actor ──PPO/RM/KL──→ 对齐策略
```

- SFT 太弱，候选质量低且 RM 数据覆盖差，PPO 探索困难；
- RM 排序错误或数据偏置会被 Actor 放大，产生 reward hacking；
- KL 太强，策略几乎不离开 SFT；太弱，策略进入 RM 未覆盖区域；
- Policy 更新后分布变化，固定 RM 的外推风险上升，可能需要重新采样、人工标注和迭代 RM。

### 五、数据与评估边界

SFT demonstration、偏好训练集和最终评估集应按 prompt/语义隔离。RM 不能只看 held-out pair accuracy，还要测跨长度、领域、安全类型和新策略 checkpoint 的泛化。Policy Optimization 也不能只报告 RM reward，必须用独立人工偏好、可验证任务、通用能力和安全红队确认没有过度优化代理。

### 面试简答版

经典 RLHF 先用人工示范做 SFT，得到会基本遵循指令的初始策略；再对同一 Prompt 的多个模型回答做人类排序，用 Bradley–Terry 损失训练输出标量的 Reward Model；最后复制 SFT 模型为可训练 Actor 和冻结 Reference，Actor 在线采样，RM 给序列奖励，Critic 估计 value，PPO 最大化优势，同时用相对 Reference 的 KL 惩罚限制分布漂移。SFT 提供起点，RM 把偏好变成代理奖励，PPO 优化该奖励；主要风险是 RM 偏差、分布外 reward hacking 和 KL 失衡。
