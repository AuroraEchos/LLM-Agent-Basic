## 我的答案

DAPO（Decoupled Clip and Dynamic sAmpling Policy Optimization）不是简单替换 GRPO 的一个公式，而是一套面向长链推理 RL 的训练 recipe。其技术报告提出四项核心改进：**Clip-Higher、Dynamic Sampling、Token-Level Policy Gradient Loss 和 Overlong Reward Shaping**，分别针对探索坍缩、无效采样、长度归一化偏差和过长截断噪声。可参考 [DAPO 官方项目](https://dapo-sia.github.io/) 与 [技术报告](https://openreview.net/pdf?id=2a36EMSSTp)。

### 一、Clip-Higher：缓解 entropy collapse

GRPO/PPO 的 token importance ratio 为：

\[
\rho_{i,t}(\theta)=
\frac{\pi_\theta(o_{i,t}|q,o_{i,<t})}
{\pi_{old}(o_{i,t}|q,o_{i,<t})}
\]

传统对称裁剪把它限制在 \([1-\epsilon,1+\epsilon]\)。DAPO 将上下界解耦：

\[
\operatorname{clip}(\rho,1-\epsilon_{low},1+\epsilon_{high}),
\qquad \epsilon_{high}>\epsilon_{low}
\]

低概率但获得正 advantage 的探索 token 若要显著提高概率，需要较大的相对增长；较小的统一上界会过早截断这部分梯度，使策略越来越集中在少数高概率模式。提高正向上界给“好但原先罕见”的 token 更大增长空间，从而提升多样性、减缓 entropy collapse。

它不是普通 entropy bonus：entropy bonus 不区分好坏地鼓励分散，而 Clip-Higher 仍只通过 advantage 放宽有价值动作的提升幅度。上界也不能无限增大，否则 old-policy mismatch 和更新不稳定会加剧。

### 二、Dynamic Sampling：去掉全对/全错的无效组

GRPO 对同一 prompt 采样一组回答并标准化 reward：

\[
\hat A_i=\frac{r_i-\bar r}{\operatorname{std}(r)+\epsilon}
\]

若一组全部答对或全部答错，组内 reward 方差为零，几乎没有相对学习信号，却已经消耗了昂贵 rollout。Dynamic Sampling 会过滤这类 accuracy 为 0 或 1 的组并继续采样，直到 batch 中保留固定数量的**有有效梯度 prompt**。

这提高了每次更新的有效样本率，也避免不同 step 因无信号组数量波动导致有效 batch size 不稳定。不过它会把训练分布偏向当前中等难度题，因此必须记录原始难度分布、过滤率与重采样成本；全错难题不能永久丢弃，可通过课程学习、更强探索或过程奖励重新引入。

### 三、Token-Level Policy Gradient Loss：修正长 CoT 的样本级平均

一种常见 response-level 聚合先对每条回答内部取均值，再对回答取均值：

\[
\mathcal L_{sample}=\frac1B\sum_{i=1}^{B}
\frac1{|o_i|}\sum_{t=1}^{|o_i|}\ell_{i,t}
\]

这样每条回答总权重相同，长回答中的单个 token 权重更小；batch 内长度差异很大时，会改变 long-CoT 的优化贡献。DAPO 改成按所有有效 token 统一归一化：

\[
\mathcal L_{token}=
\frac{1}{\sum_i|o_i|}\sum_{i=1}^{B}\sum_{t=1}^{|o_i|}\ell_{i,t}
\]

于是每个有效 token 权重一致，长回答按 token 数贡献更多梯度，对长链推理训练尤其关键。它也可能增强长度增长倾向，所以必须和长度预算、Overlong Reward Shaping 及长度切片指标一起使用。

### 四、Overlong Reward Shaping：消除最大长度附近的奖励悬崖

若超过最大生成长度才突然给零分或重罚，两个几乎相同的回答可能因是否跨过边界获得完全不同 reward。被截断的回答还可能本来即将答对，这会产生高噪声优势并让训练不稳定。

DAPO 在最大长度之前设置缓冲区，对接近上限的回答逐渐施加软惩罚，可抽象为：

\[
R'=R_{task}+R_{len}(L),\qquad
R_{len}(L)=
\begin{cases}
0,&L\le L_{safe}\\
-\lambda\dfrac{L-L_{safe}}{L_{max}-L_{safe}},&L_{safe}<L\le L_{max}
\end{cases}
\]

这样模型会逐步学会在预算内结束，而不是在硬边界遭遇突变 reward。实现中要区分自然 EOS 与被截断，并确保长度分不能让错误短答胜过正确长答。

### 五、四项改进与问题的对应

| GRPO/长 CoT 问题 | DAPO 改进 | 核心作用 |
|---|---|---|
| 低概率优质动作难以提升、entropy collapse | Clip-Higher | 放宽正向 ratio 上界，保留探索多样性 |
| 全对/全错组无相对 advantage，浪费 rollout | Dynamic Sampling | 重采样并固定有效 prompt 数 |
| 逐回答平均稀释长序列 token 的梯度 | Token-Level PG Loss | 对 batch 内所有有效 token 统一归一化 |
| 最大长度硬截断造成 reward cliff 和噪声 | Overlong Reward Shaping | 在上限前平滑惩罚，促使预算内结束 |

### 六、工程上如何验证

应逐项做消融，而不能只比较最终分数。至少记录 entropy、不同概率 token 的 clip fraction、有效 group 比例、重采样次数、回答长度分位数、截断率、自然 EOS 率、reward 方差和 pass@1。同时固定 rollout-token 预算，否则 Dynamic Sampling 或更长回答带来的额外计算会让对比失真。

### 面试简答版

DAPO 针对长 CoT 的 GRPO 训练提出四项配套改进。Clip-Higher 将 clip 上下界解耦并增大正向上界，让低概率但高优势的探索 token 有更大提升空间，缓解 entropy collapse；Dynamic Sampling 过滤全对或全错的无信号组并补采，稳定有效 batch；Token-Level PG Loss 不再先对每条回答平均，而是对 batch 全部有效 token 统一归一化，修正长回答 token 被稀释的问题；Overlong Reward Shaping 在最大长度前逐渐惩罚，消除硬截断的 reward cliff。四者分别解决探索、采样效率、长序列 loss 权重和长度奖励噪声。
