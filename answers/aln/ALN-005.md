## 我的答案

Generalized Advantage Estimation（GAE）用不同跨度的 TD residual 加权求和，在低方差的短期 bootstrap 与低偏差的长期 Monte Carlo return 之间连续折中。原始方法见 [GAE 论文](https://arxiv.org/abs/1506.02438)。

### 一、TD Residual

\[
\delta_t=r_t+\gamma V(s_{t+1})-V(s_t)
\]

如果 value 估计准确，\(\delta_t\) 近似表示当前动作带来的超预期收益。

### 二、GAE 公式

\[
\hat A_t^{GAE(\gamma,\lambda)}
=\sum_{l=0}^{T-t-1}(\gamma\lambda)^l\delta_{t+l}
\]

可从序列末端递推：

\[
\hat A_t=\delta_t+\gamma\lambda(1-d_t)\hat A_{t+1}
\]

其中 \(d_t=1\) 表示真正终止，防止跨 EOS 或 packed sample 传播。Critic 的回归 target 常取：

\[
\hat R_t=\hat A_t+V(s_t)
\]

计算 advantage 时使用 rollout 阶段保存的 value，之后再更新 Critic，避免目标在同一轮内无控制漂移。

### 三、\(\gamma\)：时间折扣

\[
G_t=\sum_{l=0}^{T-t-1}\gamma^lr_{t+l}
\]

- \(\gamma<1\)：远期 reward 指数衰减，更重近期回报，有效 horizon 变短；
- \(\gamma=1\)：有限 episode 中所有未来 reward 不按距离折扣，较符合整条回答最终质量；
- 过小会使开头 token 几乎感受不到终端 RM reward，过大则更依赖长程且噪声较高的 value/return。

LLM 对齐中 episode 有限且终端 reward 重要，常使用 1 或接近 1，但仍要与长度、dense KL 和 reward 定义一起调。

### 四、\(\lambda\)：Bias–Variance 折中

- \(\lambda=0\)：\(\hat A_t=\delta_t\)，只用一步 TD，方差低但 Critic 不准时偏差大；
- \(\lambda\to1\)：接近多步/Monte Carlo advantage，较少依赖中间 bootstrap，但终端 reward 噪声会传播整条序列，方差更高；
- 中间值指数混合不同 n-step estimate，是实践中的常见折中。

严格说，bias 还受 Critic 误差、有限 horizon 和 \(\gamma\) 影响，不能把“lambda 越大偏差越小”当成所有场景的绝对结论。

### 五、LLM PPO 中 Reward 的放置

对 T 个 response token：

- 每 token 可有 KL reward：
  \[
  r_t^{KL}=-\beta(\log\pi_\theta-\log\pi_{ref})
  \]
- 最后一个有效 token 再加 RM、规则或任务 reward；
- EOS 缺失、超长截断、格式错误可加 penalty，但要防止与长度偏好混淆；
- padding、prompt token 不参与 response advantage，packed 样本之间必须 reset。

GAE 从末端向前把终端质量与沿途 KL 组合成每 token advantage。

### 六、数值例子

若 \(\delta_1=0.2,\delta_2=-0.1,\delta_3=1.0\)，取 \(\gamma=1,\lambda=0.9\)：

\[
\hat A_3=1.0
\]

\[
\hat A_2=-0.1+0.9\times1.0=0.8
\]

\[
\hat A_1=0.2+0.9\times0.8=0.92
\]

最终奖励会按 \(\gamma\lambda\) 向前传播。

### 七、工程注意事项

- 区分 EOS termination 与 `max_length` 截断，后者是否 bootstrap 取决于环境定义；
- advantage whitening 只在有效 response token 上做，并检查不同长度/任务混合后的权重；
- value loss、value clipping 和 explained variance 用来判断 Critic 是否跟得上；
- \(\gamma,\lambda\) 与 reward scale、KL 系数、回答长度共同调节；
- 稀疏终端 reward 下 credit assignment 仍然粗糙，GAE 不会自动识别具体哪个推理步骤正确。

### 面试简答版

GAE 先计算 TD residual \(\delta_t=r_t+\gamma V(s_{t+1})-V(s_t)\)，再令 \(\hat A_t=\sum_l(\gamma\lambda)^l\delta_{t+l}\)，可从序列末端递推。\(\gamma\) 决定远期 reward 的折扣；LLM 有限回答中为让终端 RM reward 传到前部，常取 1 或接近 1。\(\lambda=0\) 接近一步 TD，低方差但依赖 Critic；\(\lambda\to1\) 接近 Monte Carlo，偏差较小但方差高。实现要在 EOS/样本边界 reset，只处理有效 response token，并正确组合逐 token KL 与终端 reward。
