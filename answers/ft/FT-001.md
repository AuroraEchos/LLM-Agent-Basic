> **问题：** 预训练、Continued Pretraining、SFT 和偏好对齐的训练目标分别是什么？

## 我的答案

这四个阶段不是四种完全独立的模型，而是用不同数据和监督信号逐步塑造能力与行为。核心区别在于：**预训练和 Continued Pretraining 主要学习“文本分布”，SFT 学习“按指令作答”，偏好对齐学习“多个可行回答中人更喜欢哪个”**。

### 一、预训练：获得通用语言与世界建模能力

Decoder-Only LLM 通常在大规模通用语料上做 Next-Token Prediction：

\[
\mathcal L_{PT}=-\sum_{t=1}^{T}\log p_\theta(x_t\mid x_{<t})
\]

它让模型学习语言、知识、代码、推理模式等基础能力。训练数据通常是网页、书籍、代码等自然文本，不要求每条样本都写成 instruction-response。这个阶段 token 量最大、成本最高，决定模型能力上限的大部分。

### 二、Continued Pretraining：改变知识或领域分布

Continued Pretraining（CPT）从已有基座模型继续使用语言模型目标训练，目标函数通常仍是 Next-Token Prediction，变化主要在数据分布，例如法律、金融、医学、代码或新语言语料。

它适合：

- 注入大量领域术语、文体与知识；
- 让通用模型适应新语言或新数据分布；
- 在后续 SFT 前建立领域底座。

风险是领域数据过窄或学习率过大时发生灾难性遗忘。通常会混入一定比例通用数据，并同时评估领域能力和通用能力。CPT 教模型“更懂领域文本”，但不自动保证它更会遵循用户指令。

### 三、SFT：学习指令遵循和目标输出格式

Supervised Fine-Tuning 使用人工或合成的示范数据，如 `(system, user, assistant)`，用交叉熵最大化参考回答概率：

\[
\mathcal L_{SFT}=-\sum_t m_t\log p_\theta(y_t\mid x,y_{<t})
\]

其中 \(m_t\) 是 Loss Mask，通常只在 assistant 回复、工具调用等希望模型生成的 token 上取 1，system/user/tool result 作为条件但不计算损失。

SFT 主要教会模型：

- 理解指令和角色；
- 按要求回答、拒答、调用工具；
- 遵循 JSON、对话模板、风格与领域任务格式。

它本质上是对示范答案的行为克隆。单个问题可能有多个好答案，但 SFT 通常只把数据中的一个参考答案当作目标，不能显式表达“回答 A 比 B 好多少”。

### 四、偏好对齐：在可行回答中优化偏好

偏好数据通常是同一 Prompt 下的 `chosen` 与 `rejected`，或更细的排序/评分。目标是提高帮助性、真实性、安全性、风格等人类偏好。

典型路线有：

- **RLHF**：先训练 Reward Model，再通过 PPO 等强化学习最大化奖励，同时用 KL 约束模型不要偏离参考策略太远；
- **DPO/IPO 等直接偏好优化**：不显式训练独立 reward 并在线采样，直接从偏好对优化策略相对参考模型的概率；
- **RLAIF/规则反馈**：偏好信号来自 AI judge、规则或可验证奖励。

以 DPO 的常见形式为例：

\[
\mathcal L_{DPO}=-\log\sigma\left(\beta\left[
\log\frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)}-
\log\frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)}
\right]\right)
\]

其中 \(y_w\) 是偏好回答，\(y_l\) 是较差回答。偏好对齐能塑造排序和行为边界，但也可能出现 reward hacking、过度拒答、长度偏好和能力退化。

### 五、阶段关系与常见顺序

```text
通用预训练 → 领域 CPT → SFT → 偏好对齐
基础能力     领域适应    会按指令做  更符合偏好
```

顺序不是绝对的，也可在对齐后继续迭代 SFT，或混合多种 loss。但每次切换都要注意数据格式、学习率、参考模型版本和遗忘问题。不能指望少量 SFT 凭空创造预训练中完全没有的广泛知识，也不能只靠偏好优化修复基础能力不足。

### 面试简答版

预训练在大规模通用文本上做 Next-Token Prediction，主要获得语言、知识和推理基础；Continued Pretraining 通常沿用同一目标，但把数据分布转向某个领域或语言，主要做领域适应；SFT 用 instruction-response 示范最大化 assistant 目标 token 的概率，教角色、格式、工具调用和指令遵循；偏好对齐则用 chosen/rejected、奖励模型或可验证奖励，在多个可行回答中提高更受偏好的回答概率。常见顺序是预训练、CPT、SFT、偏好对齐，但各阶段都要防止遗忘、分布偏移和过度优化。
