## 我的答案

QLoRA 的整体思路是：用 4-bit 保存冻结的基座权重，计算时按块反量化到 BF16/FP16，只训练高精度 LoRA adapter。NF4、Double Quantization 和 Paged Optimizer 分别优化**权重表示、量化元数据和训练峰值显存**。原始定义可参考 [QLoRA 论文](https://arxiv.org/abs/2305.14314)。

### 一、NF4：适配近似正态权重的 4-bit 数据类型

预训练权重经过适当归一化后常近似零均值正态分布。普通 INT4 的量化点按数值间距设计，而 NormalFloat 4-bit（NF4）依据标准正态分布的分位区间构造非均匀 codebook，使各区间大致具有相近概率质量，把有限的 16 个码点更多放在高概率区域。

对一个 block，可抽象为：

\[
q_i=Q_{NF4}\left(\frac{w_i}{c}\right),
\qquad
\hat w_i=c\cdot D_{NF4}(q_i)
\]

其中 \(c\) 是 block 的量化常数，\(q_i\) 是 4-bit code，`D` 根据 NF4 codebook 查表。NF4 优化的是冻结权重的存储精度，不意味着激活、LoRA 参数和矩阵乘都以 4-bit 完成；计算通常会反量化到 BF16 等 compute dtype。

### 二、Double Quantization：连量化常数也量化

分组量化除每个权重的 4-bit code 外，还需为每个 block 保存 scale/quantization constant。group 越小，常数数量越多，元数据占比越明显。

Double Quantization 把第一层量化所需的常数集合 \(c\) 再做第二次量化：

\[
c\approx c_2\cdot D(q_c)
\]

这样减少 scale 元数据的平均 bits-per-parameter。它不是把已经 4-bit 的权重再压成 2-bit，也不是把模型连续量化两次获得更低权重精度；被二次压缩的是第一层量化常数。论文报告其可进一步节省约 0.37 bit/parameter，具体值取决于 block 配置。

### 三、Paged Optimizer：处理短时显存峰值

长序列、gradient checkpointing 和不均匀 batch 可能在某些步骤形成临时显存峰值。Paged Optimizer 利用 NVIDIA Unified Memory 的分页机制，使优化器状态在显存压力出现时可在 CPU RAM 与 GPU 之间迁移，避免一次峰值直接 OOM。

它解决的是**峰值容错与内存搬运**，不是减少前向权重到 4-bit 的核心机制，也不保证更快：发生 page migration 会增加 PCIe/NVLink 传输与延迟。QLoRA 中优化器状态主要对应可训练 adapter，规模虽然小于全参训练，但大模型、长序列和 checkpointing 仍可能出现瞬态压力。

### 四、完整前向与反向

单个量化线性层可概括为：

\[
y=X_{bf16}\cdot \operatorname{Dequant}(W_{NF4})
+X_{bf16}BA
\]

- `W_NF4` 冻结，不为其保存梯度和 Adam 状态；
- 反向会穿过反量化与 base matmul，求出输入和 LoRA 路径所需梯度，但不更新量化 base；
- A、B 通常用 BF16/FP16 或 FP32 优化器状态训练；
- activation 显存仍随 batch、层数和序列长度增长，QLoRA 并非让全部训练内存缩成四分之一。

### 五、工程边界

- NF4 适合近似正态的权重，并非所有激活或异常分布张量都天然最优；
- compute dtype、量化 block size、是否 double quant 和 kernel 支持会影响速度与质量；
- Paged Optimizer 频繁换页说明容量规划过紧，可能造成严重抖动；
- 应分别记录权重、activation、LoRA 参数、optimizer、workspace 的显存，而不是把节省全部归因于 NF4；
- 训练完成后的 base+adapter 部署、合并和重新量化策略需单独评估。

### 面试简答版

NF4 是针对近似正态预训练权重设计的非均匀 4-bit codebook，用 16 个码点更有效表示高概率区域；Double Quantization 进一步量化每个权重 block 的 scale/常数，减少量化元数据，不是把权重再次降位；Paged Optimizer 利用 Unified Memory 在显存峰值时分页迁移优化器状态，主要防 OOM，但换页会变慢。QLoRA 的冻结 base 以 NF4 保存，计算时反量化到 BF16/FP16，真正训练的是高精度 LoRA，activation 并不会自动变成 4-bit。
