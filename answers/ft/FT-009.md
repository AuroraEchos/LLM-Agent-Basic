> **问题：** LoRA 的 Rank、Alpha、Dropout 和 Target Modules 如何选择？

## 我的答案

这四个超参数分别控制**容量、增量尺度、正则化和作用范围**。不存在脱离模型、数据与任务的固定最优值，应先给出合理基线，再通过参数量可比的消融选择。

### 一、Rank \(r\)：低秩更新的容量

\[
\Delta W=BA,\qquad N=r(d_{in}+d_{out})
\]

rank 越大，可表达的更新子空间越丰富，参数、优化器状态、通信和额外计算也线性增加。

- 简单风格/格式适配、数据少：较小 rank 往往足够；
- 多任务、复杂领域迁移或 target module 较少：可能需要更大 rank；
- rank 增大后验证指标不再提升，说明瓶颈可能在数据、module 覆盖或 base 能力，而不是容量；
- 高 rank 加小数据更容易过拟合，不能把训练 loss 更低当作必然更好。

工程上可从 `r=8/16` 等中小值起步，测试 4、8、16、32、64 的学习曲线；这里是搜索起点，不是通用答案。

### 二、Alpha：控制 LoRA 分支尺度

标准 LoRA 常用：

\[
y=W_0x+\frac{\alpha}{r}BAx
\]

实际强度由 \(\alpha/r\) 决定。若改变 rank 但 alpha 不变，缩放也改变；若保持 \(\alpha/r\) 大致稳定，更容易比较容量本身。alpha 太小可能适配不足，太大可能训练不稳、过度覆盖基座能力。

它和学习率不是同一概念：学习率控制每步更新，alpha 控制 LoRA 分支进入前向的尺度，两者相互影响。某些变体使用 \(\alpha/\sqrt r\) 做 rank-stabilized scaling，使用时要明确实现，不能把不同库中的 `alpha` 数字直接比较。

### 三、Dropout：只在 LoRA 路径正则化

LoRA dropout 通常作用于进入低秩分支的输入：

\[
y=W_0x+\frac{\alpha}{r}BA\,\operatorname{Dropout}(x)
\]

小数据、重复多、过拟合明显时可用少量 dropout；大规模高质量数据或本身正则充分时可为 0。dropout 太大会破坏有限的 adapter 信号。是否需要应看训练—验证 gap，而不是因为“微调一定要正则化”机械设置。

### 四、Target Modules：决定更新发生在哪里

常见候选包括：

- Attention：`q_proj`、`k_proj`、`v_proj`、`o_proj`；
- FFN：`gate_proj`、`up_proj`、`down_proj`；
- 有时还包括 embedding、LM head 或特定多模态 projector。

只加 Q/V 参数少、是经典基线；对现代 LLM，给所有主要 linear layer 加 LoRA 往往容量更强，但显存、训练时间和 adapter 大小增加。module 名称随模型实现变化，必须打印实际匹配层；若配置错导致 0 个或少量层命中，训练可能“正常跑完”却学不到东西。

### 五、如何做公平实验

1. 固定 base、数据顺序、token budget、模板、学习率调度和评测。
2. 先比较 module 集合：Q/V、Q/K/V/O、Attention+FFN。
3. 再在最有希望的集合上搜索 rank 与 alpha；不要一次改四个变量。
4. 同时报训练 loss、验证切片、通用能力遗忘、可训练参数、峰值显存和 tokens/s。
5. 做等参数量对照：例如“少 module 高 rank”与“多 module 低 rank”，分清收益来自覆盖范围还是参数更多。
6. 数据少时使用多随机种子或 bootstrap，避免把波动当超参数收益。

### 面试简答版

Rank 控制低秩更新容量，参数量为 \(r(d_{in}+d_{out})\)，越大不一定越好；Alpha 通过标准缩放 \(\alpha/r\) 控制 LoRA 分支强度，和学习率有关但不等价；Dropout 是 adapter 路径的正则，小数据过拟合时才需要重点调；Target Modules 决定更新 Attention、FFN 或其他线性层。我的做法是从中小 rank、稳定缩放和低 dropout 建基线，先消融 Q/V、QKVO、Attention+FFN，再做等参数量的 rank/alpha 搜索，并同时看质量、遗忘、显存和吞吐。
