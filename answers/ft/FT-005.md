## 我的答案

SFT 数据并非越多越好，真正要优化的是**有效监督信号**：答案正确、指令清晰、覆盖目标分布、难度适合模型，而且没有大量重复或相互矛盾。数量只有在质量和边际信息量可接受时才有价值。

### 一、四个维度分别解决什么

#### 1. 质量：决定梯度方向是否正确

高质量至少包括事实和推理正确、回答与指令一致、格式可执行、风格自然、拒答边界合理、无隐私/版权问题。错误答案、不可验证的幻觉和模板污染会直接教坏模型。

应通过规则、执行器、单元测试、事实核验、模型评审加抽样人工复核过滤，并记录来源和修改链路。对代码可执行测试，对数学可验证最终答案与过程，对工具调用可校验 schema 和真实执行结果。

#### 2. 数量：提高覆盖并降低估计方差

数据太少容易记忆训练样本和过拟合格式；数据增加能覆盖更多表达方式。但大量同模板改写或低质量合成数据的边际收益很低，还会放大偏差。要做语义去重、模板聚类，并画随 token 数变化的验证集学习曲线。

#### 3. 多样性：决定泛化边界

多样性应覆盖任务、领域、语言、长度、语气、格式、多轮状态、工具成功/失败路径、安全边界和不同用户表达。它不是随机加入与业务无关的数据；应围绕目标流量保留核心分布，同时用一定比例的通用数据防遗忘。

#### 4. 难度：提供有信息量的学习信号

样本太简单，基座模型已能答对，梯度和新增能力有限；太难且答案噪声高，模型只会模仿表面或产生不稳定梯度。高价值样本通常位于模型当前能力边界附近，或覆盖业务中的关键失败模式。

### 二、一个实用的数据配比方法

1. 先建立分层评测集和线上流量画像，定义每个能力桶的目标权重。
2. 用基座模型跑数据，按正确率、置信度、judge 分歧和执行结果估计难度。
3. 删除错误、泄漏、重复、不可追溯和极低价值样本。
4. 对稀缺但重要的能力适度上采样，对大量同质简单样本降采样。
5. 混入通用指令数据，防止领域 SFT 造成通用能力和安全行为退化。
6. 通过小规模消融比较“加数据”“换高质量数据”“改采样权重”的边际收益。

混合分布可写为：

\[
p_{train}(x)=\sum_{k=1}^{K}w_kp_k(x),\qquad \sum_kw_k=1
\]

权重 \(w_k\) 不应只等于原始样本占比，而应综合线上重要性、稀缺度、质量和模型短板。训练中还可以按阶段调整权重。

### 三、Curriculum 与 Hard Example Mining

- 初期用格式规范、答案可靠的中等难度数据建立稳定行为；
- 中后期增加长上下文、多约束、多轮工具调用和模型易错样本；
- 通过线上 bad case、对抗生成和不确定性采样持续挖掘 hard examples；
- 困难样本必须提高验证强度，不能把“模型答不出”误当成“参考答案一定正确”。

Curriculum 不是永远从易到难；现代大模型也常采用混合采样。关键是防止最难样本在早期以高噪声主导优化，并保留对简单常见请求的稳定表现。

### 四、常见反例

- 一味追求百万条数据，却有大量模板化同义改写；
- 只保留“完美长答案”，使模型对任何问题都过度冗长；
- 安全拒答样本比例过大，导致正常问题也拒绝；
- 合成数据全由同一 teacher 和同一 Prompt 产生，风格单一且错误相关；
- 训练集覆盖很广，但验证集只测一个平均分，掩盖关键能力回退；
- 为困难推理上采样，却没有控制长答案因 token 多而自然获得更大 loss 权重。

### 五、如何验收

除总体指标外，应按任务、长度、语言、难度、来源和安全类型切片；同时看训练集记忆、通用能力遗忘、格式/工具成功率和线上业务指标。用固定 token budget 比较不同数据混合，才能证明收益来自质量与配比，而不是单纯训练更久。

### 面试简答版

SFT 数据要优化有效监督，而不是盲目堆数量。质量保证梯度方向正确，数量提高覆盖，多样性决定泛化边界，难度应靠近模型当前能力边界。我的做法是先按线上目标建立能力桶和分层评测，过滤错误、泄漏和语义重复，再对稀缺关键能力与 hard case 上采样，并混入通用数据防遗忘。困难样本要用执行器或人工加强验证。最后在固定 token budget 下做数据混合消融，并按任务、长度、语言、难度和安全切片验收。
