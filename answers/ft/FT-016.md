## 我的答案

标准 LoRA 的设计很简洁，但它固定了每层 rank、使用统一缩放和常见随机/零初始化，并让 A、B 采用相同优化方式。不同变体并不是在解决同一个问题，大致可以分为：**rank 预算分配、权重参数化、优化尺度、初始化与有效 rank 扩展**。

### 一、AdaLoRA：固定总预算不应平均分给每层

标准 LoRA 常给所有 target matrix 相同 rank，但不同层、不同投影对任务的重要性不同。AdaLoRA 将增量写成近似 SVD 形式，并根据重要性动态剪除不重要的奇异值，把有限 rank 预算从不重要矩阵转移到重要矩阵。

其目标可直观表示为：

\[
\min_{\{\Delta W_i\}}\mathcal L,
\qquad
\sum_i r_i\le R_{total}
\]

标准 LoRA 预先固定每个 \(r_i\)，AdaLoRA 则在训练中学习非均匀 \(r_i\)。它在预算非常紧时可能更有效，但引入重要性估计、warmup、预算调度和剪枝超参数，训练和复现比固定 rank 更复杂。参见 [AdaLoRA 论文](https://arxiv.org/abs/2303.10512)。

### 二、DoRA：把权重大小和方向分开适配

DoRA 认为全参微调与 LoRA 的权重更新模式存在差异，因此将每个权重向量分解为 magnitude 与 direction：

\[
W=m\frac{V}{\|V\|}
\]

训练时显式学习 magnitude \(m\)，并用 LoRA 低秩更新方向 \(V=W_0+BA\)。这样低成本地增加了对权重尺度变化的表达能力，试图缩小 LoRA 与全参微调之间的能力差距。部署前可重新组合权重，但训练前向、归一化和量化兼容性更复杂，不能仅凭论文平均结果默认必胜。参见 [DoRA 论文](https://arxiv.org/abs/2402.09353)。

### 三、LoRA+：A、B 不一定该用相同学习率

由于 A、B 的形状、初始化与梯度动力学不同，标准 LoRA 对两者使用同一学习率可能使宽模型中的特征学习不足。LoRA+ 使用不同学习率：

\[
\eta_B=\lambda\eta_A
\]

它不改变低秩前向结构，而是改优化器 parameter group，目标是在相似参数与计算预算下更快、更充分地训练。新增风险是学习率比率 \(\lambda\) 也要调，并需确认训练框架没有把两个 group 错误合并。参见 [LoRA+ 论文](https://arxiv.org/abs/2402.12354)。

### 四、rsLoRA：高 rank 下避免缩放信号衰减

标准 LoRA 常用：

\[
s=\frac{\alpha}{r}
\]

当 rank 增大时，这个缩放可能让 adapter 激活或梯度随 rank 衰减，导致“加了 rank 却学不动”。Rank-Stabilized LoRA 改为：

\[
s=\frac{\alpha}{\sqrt r}
\]

使不同 rank 下的更新尺度更稳定，从而让高 rank 的额外容量更可能被利用。它解决的是 rank-scaling，不代表高 rank 对所有小数据任务都更好。参见 [rsLoRA 论文](https://arxiv.org/abs/2312.03732)。

### 五、PiSSA：随机子空间初始化可能收敛慢

标准 LoRA 以随机 A 和零 B 起步。PiSSA 用原权重的主奇异值/奇异向量初始化可训练低秩部分，把剩余部分放入冻结 residual：

\[
W=W_{principal}+W_{residual}
\]

训练从已有主成分而非随机子空间开始，目标是更快收敛，并在量化场景下降低初始近似误差。代价是初始化需要 SVD 或近似 SVD，权重分解、保存、转换和与标准 LoRA 的兼容路径更复杂。参见 [PiSSA 论文](https://arxiv.org/abs/2404.02948)。

### 六、其他常见改进方向

- **ReLoRA**：周期性把低秩更新合并并重启 adapter，让多次低秩更新累积成更高有效 rank，更多用于低秩训练/预训练。
- **VeRA 等共享/随机基方法**：进一步减少每任务可训练参数，代价是表达限制更强。
- **LoftQ 等量化初始化方法**：联合考虑量化误差和 LoRA 初始化，让 adapter 更好补偿低比特 base。
- **动态 rank/稀疏 LoRA**：按层、样本或训练阶段调整容量，但会增加 kernel 与服务复杂度。

### 七、怎样选择

先用 vanilla LoRA 建立可靠基线，再依据诊断选变体：参数预算太紧且层间重要性差异大，测 AdaLoRA；LoRA 与全参差距明显，测 DoRA；优化收敛慢，测 LoRA+；需要较高 rank，测 rsLoRA；初始化与量化误差突出，测 PiSSA/LoftQ。

消融必须固定数据、token budget、target modules 和可训练参数；同时报告收敛速度、最终指标、显存、训练吞吐、merge 误差、框架支持和部署路径。多个变体有时可组合，但它们的缩放、初始化假设可能冲突，不能把开关全部打开后再归因。

### 面试简答版

AdaLoRA 解决固定 rank 均匀分配浪费预算的问题，按重要性在层间动态分配奇异值；DoRA 把权重 magnitude 与 direction 分开，用 LoRA 更新方向，试图缩小与全参微调的表达差距；LoRA+ 为 A、B 使用不同学习率，改善优化动力学；rsLoRA 用 \(\alpha/\sqrt r\) 替代 \(\alpha/r\)，避免高 rank 下信号衰减；PiSSA 用原权重主奇异子空间初始化，改善收敛和量化误差。它们解决的瓶颈不同，应先诊断再做同预算消融，而不是默认新变体一定更好。
