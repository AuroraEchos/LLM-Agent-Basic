> **问题：** LoRA 的低秩假设是什么，前向计算与参数量如何推导？

## 我的答案

LoRA 的低秩假设不是“预训练权重 \(W\) 本身低秩”，而是：**针对某个下游任务，模型所需的权重更新 \(\Delta W\) 具有较低的内在秩，可以由两个小矩阵近似表达。**

### 一、从全量更新到低秩更新

设一个线性层权重为：

\[
W_0\in\mathbb R^{d_{out}\times d_{in}}
\]

全量微调直接学习同形状的 \(\Delta W\)，前向为：

\[
y=(W_0+\Delta W)x
\]

LoRA 冻结 \(W_0\)，把更新参数化为：

\[
\Delta W=BA,
\quad A\in\mathbb R^{r\times d_{in}},
\quad B\in\mathbb R^{d_{out}\times r},
\quad r\ll \min(d_{in},d_{out})
\]

因为 \(\operatorname{rank}(BA)\le r\)，更新被限制在低秩子空间。加入常见缩放后：

\[
y=W_0x+\frac{\alpha}{r}BAx
\]

实现时一般先算 \(Ax\) 将维度压到 \(r\)，再算 \(B(Ax)\) 恢复到 \(d_{out}\)，无需显式构造完整 \(\Delta W\)。

### 二、参数量推导

全量训练该线性层需要：

\[
N_{full}=d_{out}d_{in}
\]

LoRA 需要：

\[
N_{LoRA}=rd_{in}+d_{out}r=r(d_{in}+d_{out})
\]

参数比例为：

\[
\frac{N_{LoRA}}{N_{full}}=
\frac{r(d_{in}+d_{out})}{d_{in}d_{out}}
\]

若是 \(4096\times4096\) 的线性层，\(r=8\)：

\[
N_{full}=16{,}777{,}216
\]

\[
N_{LoRA}=8(4096+4096)=65{,}536
\]

仅为原矩阵的约 \(0.39\%\)。实际全模型比例还取决于给多少层、哪些 module 加 LoRA，以及是否训练 bias、embedding 或 LM head。

### 三、初始化为什么通常一边为零

常见做法是随机初始化 \(A\)、将 \(B\) 初始化为零，或反过来。这样训练开始时：

\[
BA=0
\]

模型输出与原基座完全一致，同时非零的一侧能让另一侧在第一步获得梯度。如果 A、B 都初始化为零，两侧初始梯度也可能都为零，无法打破对称开始学习。

### 四、计算与显存

LoRA 的额外前向乘加量与 \(r(d_{in}+d_{out})\) 成正比，远小于完整矩阵乘，但训练时还要保存 adapter 路径所需激活。它显著减少：

- 可训练参数；
- 参数梯度；
- Adam 一阶、二阶优化器状态；
- 多卡之间需要同步的可训练梯度。

它不消除冻结 base 的前向计算，也不必然解决长序列 activation/KV 显存。

### 五、训练后如何推理

可以保持两条分支，运行时按任务加载不同 A、B；也可以合并：

\[
W_{merged}=W_0+\frac{\alpha}{r}BA
\]

合并后前向恢复成普通线性层，没有 LoRA 分支额外延迟，但难以在同一个权重实例上快速切换 adapter。若 base 是 4-bit，合并通常涉及先反量化再加增量，并决定是否重新量化，可能引入新的误差。

### 面试简答版

LoRA 假设的是下游任务所需的权重更新 \(\Delta W\) 低秩，而不是原权重低秩。对 \(W_0\in\mathbb R^{d_{out}\times d_{in}}\)，令 \(\Delta W=BA\)，其中 \(A\in\mathbb R^{r\times d_{in}}\)、\(B\in\mathbb R^{d_{out}\times r}\)，前向为 \(W_0x+\alpha/r\cdot BAx\)。全量参数是 \(d_{out}d_{in}\)，LoRA 参数是 \(r(d_{in}+d_{out})\)。常将一侧零初始化，使初始增量为零；训练后可以动态挂 adapter，也可 merge 到 base 消除额外推理分支。
