## 我的答案

多任务 SFT 不能简单把所有文件拼起来随机抽样，否则**样本多、文本长或答案长的数据源会自然主导梯度**。需要分别控制采样概率、token 级损失贡献和训练阶段，并按任务切片持续观察。

### 一、先定义任务桶和目标分布

将数据按真实目标拆成可解释的桶，例如：通用问答、代码、数学、工具调用、拒答、多轮、长上下文、不同语言。对第 \(k\) 个桶记录：

- 样本数 \(n_k\)、input/target token 数与长度分布；
- 来源、质量、重复率和许可证；
- 线上重要性、稀缺度、当前模型短板；
- 独立 validation 指标与最低保留门槛。

训练混合分布为：

\[
p_{train}(x)=\sum_{k=1}^{K}q_kp_k(x),
\qquad \sum_kq_k=1
\]

其中 \(q_k\) 应由业务目标和验证反馈决定，而不必等于自然数据占比 \(n_k/\sum n_k\)。

### 二、常见采样方法

#### 按数据量采样

\[
q_k=\frac{n_k}{\sum_jn_j}
\]

实现简单，但大来源会淹没小而关键的数据，通常只适合各来源规模与目标重要性本来就一致的情况。

#### Temperature Sampling

\[
q_k=\frac{n_k^\alpha}{\sum_jn_j^\alpha}
\]

当 \(0<\alpha<1\) 时会压平分布，提高小数据源比例；\(\alpha=1\) 退化为按规模采样；\(\alpha=0\) 近似各桶均匀。小桶被过度上采样会快速重复和过拟合，因此还要设最大 repeat 次数或质量门槛。

#### 配额/分层 Batch

直接规定每个窗口或 batch 的任务比例，确保关键任务不会长时间缺席。它比纯随机采样更可控，但不同长度样本混在一个 batch 可能增加 padding，可结合 length bucket 和跨若干 step 的配额。

### 三、采样均衡不等于梯度均衡

若 loss 对所有 target token 求平均，一个长代码样本即使只抽到一次，也可能贡献数千个监督 token。可以选择：

1. **Token-average**：每个 target token 等权，适合成本和目标本来按 token 定义的场景；
2. **Sample-average**：先对每样本 target token 求平均，再对样本平均；
3. **Task-average**：先在任务内归一化，再按任务权重组合：

\[
\mathcal L=\sum_k\lambda_k
\frac{1}{|B_k|}\sum_{i\in B_k}\mathcal L_i
\]

4. 对工具 JSON、final answer、安全边界等关键区域设置有限的 token weight。

采样概率 \(q_k\) 与 loss 权重 \(\lambda_k\) 都会改变目标函数，不能无意中同时对同一小桶“双重上采样”。应统计每桶实际被看到的样本数、target tokens 和加权 loss 占比。

### 四、处理任务冲突

不同任务可能产生冲突梯度，例如“简洁回答”和“详细推理”、“尽量帮助”和“安全拒答”。可采用：

- 明确 system/用户偏好条件，让行为差异成为条件化任务，而不是互相矛盾标签；
- 清理同一 Prompt 的冲突答案或显式加入场景标签；
- 分阶段 curriculum：先建立通用格式，再增加难任务与工具轨迹，最后做平衡回放；
- 监控每任务梯度范数/余弦相似度，必要时采用 loss reweighting 或多任务梯度冲突方法；
- 为安全、格式、通用能力设置 floor，不能仅最大化加权平均分。

### 五、动态调权与防止追指标

先用静态混合跑基线，再根据 held-out 切片调整。某任务验证已饱和而重复率高，可降低比例；关键任务落后则提高高质量 hard case，而不是无限复制旧样本。动态调权只使用 Validation，不能根据 Test 反复优化。

每次混合实验要固定总训练 target tokens。否则提高某任务比例同时延长训练，会无法区分收益来自数据混合还是更多计算。

### 六、验收

- 每个任务独立指标、样本长度和难度切片；
- 通用能力、安全、格式和多语言回归；
- 实际采样/target-token/weighted-loss 占比是否符合配置；
- 小数据源重复次数与记忆风险；
- 综合分数之外的最低门槛和 Pareto 前沿。

### 面试简答版

我会先按任务、语言、格式和来源分桶，采样概率不直接等于数据量，可用 \(q_k\propto n_k^\alpha\) 的 temperature sampling 或窗口配额保护小而关键的任务。同时区分样本占比和 target-token loss 占比：长代码/长推理会在 token average 下主导，可改为先按样本或任务归一化。训练中记录每桶实际样本、target tokens、加权 loss 和验证指标，设置通用、安全、格式的最低门槛；所有混合消融固定总 token budget，避免把多训练当成配比收益。
