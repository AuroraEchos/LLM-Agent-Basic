> **问题：** Speculative Decoding 的 Draft、Verification、Acceptance 和 Residual Sampling 流程是什么？

## 我的答案

Speculative Decoding 用便宜的 draft model $q$ 串行提出多个候选 token，再让昂贵的 target model $p$ 一次并行验证。正确的随机采样版本通过 rejection sampling 与 residual distribution 修正，保证最终输出仍严格服从 target 分布，而不是“target 觉得差不多就接受”。

[原始 Speculative Decoding 论文](https://arxiv.org/abs/2211.17192)的一个 round 可分为四步。

### 1. Draft：小模型提出 $\gamma$ 个 token

给定已确认前缀 $x_{\le t}$，draft 自回归采样：

$$
\tilde x_{t+i}\sim q_i(\cdot)
=q(\cdot\mid x_{\le t},\tilde x_{t+1:t+i-1}),
\quad i=1,\ldots,\gamma
$$

必须保存每一步 proposal distribution $q_i$ 或至少能计算被提议 token 的概率，并为可能的 residual sampling 保留完整/可重构分布。Draft 虽小，$\gamma$ 步仍是串行的。

### 2. Verification：大模型并行打分

将“确认前缀 + $\gamma$ 个 draft tokens”一次送入 target。Teacher forcing 使 target 能并行得到：

$$
p_i(\cdot)=p(\cdot\mid x_{\le t},\tilde x_{t+1:t+i-1})
$$

以及所有候选都接受后下一位置的 $p_{\gamma+1}$。这一步同时建立候选路径的 target KV；最终未接受的 suffix 要回滚/释放。

### 3. Acceptance：按概率比逐个接受

从第一个 draft token 开始，依次采独立均匀随机数 $u_i\sim U(0,1)$。接受候选 $\tilde x_i$ 的概率为：

$$
a_i=\min\left(1,
\frac{p_i(\tilde x_i)}{q_i(\tilde x_i)}
\right)
$$

若 $u_i\le a_i$，提交该 token 并检查下一个；一旦第 $i$ 个被拒绝，后续 draft tokens 全部作废，因为它们的条件前缀已不再成立。

若 $q_i(\tilde x_i)\le p_i(\tilde x_i)$，候选必然接受；draft 在 target 更偏好的位置通常接受率高。

### 4. Residual Sampling：拒绝时补一个正确 token

首次拒绝第 $i$ 个候选后，从 target 与 draft 的正差分布采样：

$$
r_i(x)=
\frac{[p_i(x)-q_i(x)]_+}
{\sum_v[p_i(v)-q_i(v)]_+}
$$

其中 $[z]_+=\max(z,0)$。采到的 residual token 作为本轮最后一个确认 token，然后开始下一 round。

如果 $\gamma$ 个候选全部接受，则再从 target 已计算好的：

$$
x_{t+\gamma+1}\sim p_{\gamma+1}
$$

采一个额外 token。于是一次 target verification 最多提交 $\gamma+1$ 个输出，至少提交一个纠正/额外 token，算法能持续前进。

### Greedy 版本

若目标是完全复现 target greedy，可让 draft 提议若干 argmax，并从前往后接受与 target argmax 相同的最长前缀；首次不同处提交 target argmax。此时不需要概率 residual，但这是确定性 greedy 的特例，不能用它代替随机 sampling 的精确修正规则。

### KV Cache 与停止条件

- Draft 和 target 各自维护 cache；
- target verification 后只保留确认 token 对应 KV，拒绝 suffix 回滚；
- Draft cache 也要对齐到最终确认前缀，必要时用纠正 token推进；
- 候选中出现 EOS 时，只有按顺序被接受才真正停止；
- grammar/top-p/temperature 等处理必须让 $p_i,q_i$ 表示各自**实际 proposal/target sampling distribution**，否则概率比不正确；
- $p,q$ 的 tokenization 必须兼容，通常共享词表最简单。

### 面试简答版

Draft model 先自回归采 $\gamma$ 个候选并保存每步分布 $q_i$；target 一次 teacher-forcing forward 并行得到对应 $p_i$。候选按顺序以 $\min(1,p_i(x_i)/q_i(x_i))$ 接受，首次拒绝后丢掉其余 suffix，并从 $[p_i-q_i]_+$ 归一化的 residual distribution 采一个纠正 token；若全部接受，再从 target 的下一位置分布多采一个。最后只提交确认路径并回滚 KV。这个接受/残差流程才能在加速时保持 target sampling 分布。
