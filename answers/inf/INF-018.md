## 我的答案

Beam Search 的三个问题互相关联：累计 log probability 天然偏短，需要长度归一化；完成 beam 与未完成 beam 并存时，需要安全的停止判据；多个 beam 又容易选到几乎相同的前缀，失去搜索多样性。

### 长度惩罚

原始序列分数：

$$
s(y)=\sum_{t=1}^{|y|}\log p(y_t\mid x,y_{<t})
$$

每项通常不大于 0，序列越长累计越负，因此偏好早出 EOS。常见归一化：

$$
s_{norm}(y)=\frac{s(y)}{|y|^\alpha}
$$

或 GNMT 风格：

$$
\operatorname{lp}(y)=\left(\frac{5+|y|}{6}\right)^\alpha,qquad
s_{norm}=s/\operatorname{lp}(y)
$$

$\alpha$ 越大通常越鼓励较长输出，但具体方向还取决于框架分数定义。还可用加性长度 reward。参数必须按任务校准：翻译有参考长度，摘要偏好不同，开放聊天很难由单一序列概率决定。

Min length 可在阈值前 mask EOS，但设置过大只会强迫模型继续胡写；max length 是安全上限，不是质量优化。

### 正确管理完成 beam

当候选生成 EOS 时，将完整 hypothesis 连同最终 normalized score 放入 finished set，而不是继续扩展。活跃集合保留未完成前缀。每个样本应分别维护 beam 状态、parent index 和 KV 重排。

不能因为“当前有一个 finished beam”就立即停止：其他未完成 beam 后续可能得到更高归一化分数。常见停止策略：

- 达到预定数量的 finished hypotheses 后保守停止；
- `early_stopping=true` 一类启发式：足够多完成 beam 就停，快但可能错过更好序列；
- 用当前最佳未完成前缀可达到的分数上界，与最差保留 finished score 比较，只有不可能超越时才安全停止；
- 所有活跃 beam 都 EOS 或达到 max length。

上界必须与长度惩罚公式一致。因为未来 log probability 不会增加原始累计分数，但长度归一化可能让负分“变好”，不能只比较当前 raw score。

### Beam Collapse

Beam collapse 是 K 个 beam 虽形式上不同，却共享几乎相同的前缀或只差标点/同义 token。原因是模型分布过尖、每步 top candidates高度相似，且标准 beam 只优化概率不奖励差异。增大 K 只会保存更多近重复，成本上升而覆盖不变。

缓解方法：

- Diverse Beam Search：将 beam 分组，对已被其他组选择的 token/特征加 diversity penalty；
- no-repeat n-gram 或软 repetition penalty，但防止误伤固定术语；
- stochastic beam / beam sampling，引入受控随机性；
- 对候选做 lexical/semantic 去重，再补充下一候选；
- 多个不同 prompt、temperature sampling 后用 reranker/verifier；
- 任务约束下强制覆盖不同实体、槽位或解题路径。

对于开放式生成，“多样采样 + 验证”通常比大 beam 更自然；beam 的高概率偏好会导致安全但平庸的文本。

### 工程开销

Beam width $K$ 近似把 decode batch、KV Cache、logits top-k 和 parent reorder 扩大 K 倍。共享 prompt KV 可 copy-on-write，但分叉后的 cache 仍各自增长。完成 beam 应及时停止计算和回收其活跃 slot，同时保留输出 token/score。

批处理中每个样本完成时间不同，要避免某个样本的 beam 与另一个样本混排；length、EOS 和 score 都按样本维护。

### 评估

同时报告 oracle@K（候选中最好）、top-1、候选互异率、平均长度、EOS/截断率和单位延迟/显存。若 oracle@K 提升而 reranker 选不出来，问题在选择器；若候选都相同，问题在搜索多样性。

### 面试简答版

Beam 的原始累计 log-prob 偏短，常除以 $|y|^\alpha$ 或 GNMT length penalty，并按任务调 $\alpha$。EOS hypothesis 进入 finished set，不能有一个完成就停；应等足够候选完成，或用与长度归一化一致的上界证明所有未完成 beam 都不可能超过当前结果。Beam collapse 是多个 beam 几乎相同，可用 diverse beam、n-gram约束、stochastic beam 或多样采样+reranker缓解。Beam width 会近似放大 KV、decode 和排序成本，开放对话不一定因更大 beam 变好。
