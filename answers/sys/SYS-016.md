## 我的答案

企业 MCP 平台应把 MCP Server 视为可执行能力和新的供应链入口，而不只是一个工具列表。平台要提供统一的**注册发现、身份与策略代理、调用审计、版本兼容和紧急熔断**；协议发现工具不等于调用者已获业务授权。

### 架构

```text
Agent Hosts → MCP Gateway / Policy Enforcement Point → MCP Servers
                   │                                  │
       Registry / Auth / Approval / Rate Limit        └→ SaaS / DB / Internal API
                   │
        Audit / Risk / Version / Health Control Plane
```

MCP Host 只连接企业网关，网关按租户和用户返回允许的 server/tool 视图，代理远程调用并统一限流、超时、出站控制和遥测。对本地 stdio server，则通过签名包、受控 launcher 和沙箱运行，禁止 Agent 从任意路径启动未知二进制。

### 注册与准入

每个 server 需要 owner、业务用途、传输端点、制品/镜像 digest、源码与供应方、数据分级、地域、SLO、依赖和下线日期。每个 tool 保存稳定 ID、语义版本、输入/输出 JSON Schema、读/写/外发风险、幂等性、权限 scopes、数据源/sink、成本、超时和审批规则。

自动检查 Schema、名称冲突、镜像/SBOM/漏洞、秘密、许可证和契约测试；高风险工具由安全、数据 owner 和业务 owner 审批后才进入 catalog。描述文本本身是不可信供应链内容，不能借工具描述修改 Host 的系统策略。

### 身份、权限与审批

认证从企业 IdP/OIDC 获取真实 user、tenant、group 和 workload identity。远程 MCP 可使用 OAuth 授权，但令牌必须短期、最小 scope、绑定目标 resource/audience；禁止把某 server 的 token 透传给另一个 server，也不把 token 暴露给模型上下文。

调用时策略引擎按以下信息重新判断：

$$
allow=Policy(subject, tool, resource, args, context, risk)
$$

工具可见不代表可执行。参数要经 Schema、资源归属、行列级 ACL 和业务范围校验；读取工资、外发文件、删除、发布等进行 step-up auth 或人工确认。确认页面显示工具、目标、关键参数和影响，批准绑定参数 digest、用户和有效期，防止批准后换参。

### 审计与观测

审计事件包含 trace/call id、主体、Host/server/tool 与版本、参数的脱敏摘要、授权/审批及理由、数据分类、结果状态、延迟、费用和副作用 ID。秘密、token 和敏感返回不进入普通日志；高风险审计采用追加式、防篡改存储和独立访问控制。

监控 server/tool 可用性、P95、错误、Schema 失败、授权拒绝、调用量/成本、异常出站、人工推翻和未使用工具。支持按 server、tool、版本、租户实时 kill switch，并保留只读/模拟降级。

### 版本治理

使用不可变 artifact 和 SemVer/显式兼容等级。破坏性 Schema 或语义变化发布新 major/tool ID；非破坏字段也要做旧客户端契约测试。Host 在会话/工作流中固定版本，注册表支持 `deprecated→sunset→disabled`，提前统计消费者、通知迁移并可双跑 shadow。

新版本先测试租户和只读流量，再按稳定 cohort 灰度；比较工具成功、结果语义、安全、P95 和成本。配置原子回滚到旧 server+tool 版本。发现漏洞时可撤销签名、令牌和目录可见性，不能等待所有 Agent 更新 Prompt。

### 面试简答版

企业 MCP 平台我会分成注册治理控制面和统一调用网关。注册时记录 owner、制品 digest、Schema、数据流、风险、scope、幂等性与 SLO，并经过供应链和契约检查。调用时从企业身份得到 subject/tenant，网关按“主体—工具—资源—参数”重新授权，OAuth token 短期且绑定目标 audience，绝不透传或放进模型；高风险参数审批绑定 digest。审计记录版本、授权理由和副作用的脱敏事件，并支持 tool 级限流和 kill switch。版本采用不可变制品、兼容测试、弃用窗口、稳定灰度与原子回滚。
