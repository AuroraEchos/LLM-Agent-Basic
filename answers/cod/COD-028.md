## 我的答案

维护一个存**索引**的双端队列，使对应值从队头到队尾单调不增。队头永远是当前窗口最大值。

```python
from collections import deque

def max_sliding_window(nums, k):
    if k <= 0 or k > len(nums):
        raise ValueError("k must be in [1, len(nums)]")
    q = deque()                 # indices，nums[q] 单调不增
    result = []

    for i, x in enumerate(nums):
        # 1) 删除已经离开窗口 [i-k+1, i] 的索引。
        while q and q[0] <= i - k:
            q.popleft()
        # 2) 队尾较小/相等值不可能再成为未来最大值。
        while q and nums[q[-1]] <= x:
            q.pop()
        q.append(i)
        # 3) 第一个完整窗口形成后输出队头。
        if i >= k - 1:
            result.append(nums[q[0]])
    return result
```

为什么可以弹掉队尾较小元素：新元素比它更大且过期更晚，在任何同时包含二者的未来窗口中，旧小元素都不可能成为最大值。使用 `<=` 会保留较新的相等值，使用 `<` 保留较旧相等值，两者答案都对，但过期逻辑必须一致。

每个索引最多入队一次、从队头或队尾出队一次，摊还时间 O(n)，队列空间 O(k)。暴力每个窗口求 max 是 O(nk)；堆可做到 O(n log n/k)，但需要惰性删除过期索引，单调队列更贴合固定窗口极值。

### 面试简答版

双端队列保存索引，并让对应值单调递减：新索引到来先删队头过期索引，再删掉队尾所有不大于新值的索引，最后入队；窗口形成后队头就是最大值。较小旧值可删，因为新值更大且更晚过期。每个索引最多进出一次，所以 O(n) 时间、O(k) 空间。
