## 我的答案

下面给一个易读版本：prefill 时一次写入 prompt K/V；decode 时只投影新增 token，并与缓存拼接。生产系统应预分配连续/page buffer，避免每步 `torch.cat` 的 $O(T)$ 拷贝。

```python
import math
import torch
from torch import nn

class KVCache:
    def __init__(self):
        self.k = self.v = None

    @property
    def length(self):
        return 0 if self.k is None else self.k.size(-2)

    def append(self, k, v):
        if k.shape != v.shape:
            raise ValueError("k/v shape mismatch")
        self.k = k if self.k is None else torch.cat([self.k, k], dim=-2)
        self.v = v if self.v is None else torch.cat([self.v, v], dim=-2)
        return self.k, self.v

    def clear(self):
        self.k = self.v = None


class CachedSelfAttention(nn.Module):
    def __init__(self, d_model, num_heads):
        super().__init__()
        if d_model % num_heads:
            raise ValueError("d_model % num_heads must be 0")
        self.h, self.dh = num_heads, d_model // num_heads
        self.qkv = nn.Linear(d_model, 3 * d_model, bias=False)
        self.out = nn.Linear(d_model, d_model, bias=False)
        self.cache = KVCache()

    def _heads(self, x):
        B, T, _ = x.shape
        return x.view(B, T, self.h, self.dh).transpose(1, 2)

    def clear_cache(self):
        self.cache.clear()

    @torch.no_grad()
    def forward(self, x, mode):
        """mode 为 'prefill' 或 'decode'; x: [B,Tnew,D]。"""
        if mode not in {"prefill", "decode"}:
            raise ValueError("unknown mode")
        if mode == "prefill":
            self.clear_cache()
        elif self.cache.k is None:
            raise RuntimeError("decode requires an existing cache")

        q, k_new, v_new = map(self._heads, self.qkv(x).chunk(3, dim=-1))
        past = self.cache.length
        k, v = self.cache.append(k_new, v_new)
        Tq, Tk = q.size(-2), k.size(-2)
        scores = q @ k.transpose(-2, -1) / math.sqrt(self.dh)

        # query 的全局位置是 past+i，可看到 key 位置 <= past+i。
        q_pos = past + torch.arange(Tq, device=x.device)[:, None]
        k_pos = torch.arange(Tk, device=x.device)[None, :]
        allowed = (k_pos <= q_pos)[None, None]
        scores = scores.masked_fill(~allowed, torch.finfo(scores.dtype).min)
        p = torch.softmax(scores.float(), dim=-1).to(x.dtype)
        y = (p @ v).transpose(1, 2).contiguous().view(x.size(0), Tq, -1)
        return self.out(y)
```

验证方式：同一权重、`eval()` 下，比较“整段 causal forward”与“prefill 前缀 + 逐 token decode”对应位置输出，应在容差内一致。实际服务还必须处理：batch 中不同长度和 padding、RoPE 的绝对 position offset、GQA 的 KV 头数、最大容量/淘汰、请求隔离、beam reorder、取消后释放显存，以及不能跨用户复用未授权 cache。

静态预分配版本会维护 `write_pos`，写入 `k[:,:,pos:pos+n]`，返回有效 slice；PagedAttention 则通过 block table 避免连续大块和碎片。清理时释放引用只是逻辑正确性，显存 allocator 未必立即归还给 OS。

### 面试简答版

Prefill 一次计算 prompt 的 Q/K/V 并缓存 K/V；decode 每步只计算新 token 的 Q/K/V，把新 K/V 追加后让 Q 关注全部历史。因果 mask 要用全局位置 `past+i`，不能对 `[Tnew,Ttotal]` 直接普通 `tril`。面试手写可用 `cat`，生产应预分配或分页，并处理 position offset、不同 batch 长度、beam reorder、请求隔离和取消清理。
