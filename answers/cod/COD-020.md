## 我的答案

显存至少分为权重/训练状态、激活和 KV Cache。下面把不可精确的激活保存量做成显式系数，而不是藏在公式中。

```python
def bytes_for(elements, bits):
    return elements * bits / 8

def memory_estimate(*, total_params, layers, d_model, q_heads, kv_heads,
                    batch, seq_len, weight_bits=16, activation_bits=16,
                    kv_bits=16, training=False,
                    saved_activation_factor=8.0):
    if d_model % q_heads or q_heads % kv_heads:
        raise ValueError("invalid head config")
    dh = d_model // q_heads

    weights = bytes_for(total_params, weight_bits)
    # 每层、每 token 缓存 K 和 V；GQA 使用 kv_heads 而不是 q_heads。
    kv_elements = batch * seq_len * layers * 2 * kv_heads * dh
    kv_cache = bytes_for(kv_elements, kv_bits)

    # 粗估训练保存的 residual/QKV/FFN 等；checkpoint/FlashAttention 会改变系数。
    activation_elements = (batch * seq_len * layers * d_model
                           * saved_activation_factor)
    activations = bytes_for(activation_elements, activation_bits)

    result = {"weights": weights, "kv_cache": kv_cache,
              "saved_activations_rough": activations}
    if training:
        # 典型 mixed precision Adam：grad FP32 4B，master weight 4B，m/v 8B。
        result.update({
            "gradients_fp32": total_params * 4,
            "master_weights_fp32": total_params * 4,
            "adam_m_v_fp32": total_params * 8,
        })
    result["total"] = sum(result.values())
    return result

def gib(x):
    return x / 1024**3
```

KV Cache 的核心公式是：

$$M_{KV}=B\times L\times n_{layer}\times2\times n_{kv}\times d_h\times bytes$$

所以 GQA/MQA、KV 量化直接降低它；Tensor Parallel/Context Parallel/PagedAttention 则改变每卡分片与管理方式。注意最大窗口只是容量，实际 cache 还受并发序列长度分布、block 碎片和 prefix sharing 影响。

训练显存不能只说“Adam 每参数 16 bytes”：具体取决于 BF16/FP32 master、gradient dtype、ZeRO/FSDP 分片、量化 optimizer、LoRA 和是否冻结 base。激活更依赖 attention 实现、`d_ff`、MoE token dispatch、checkpoint 粒度与反向保存张量；上述 `saved_activation_factor` 只能用一次真实 profile 校准。

最后还要预留 CUDA context、allocator fragmentation、临时 GEMM workspace、通信 buffer 和 logits。容量规划应报告理论分解和峰值 profile 两套数字，并保留余量。

### 面试简答版

权重是 `参数量×每参数字节`；KV Cache 是 `B×L×layers×2×Hkv×Dh×字节`；训练还要加 gradient、master weight、Adam m/v 和保存激活。激活无法只由参数量精确推出，要把 residual/QKV/FFN 保存系数、checkpoint 和 FlashAttention 写清并用 profile 校准。还要考虑并行分片、分页碎片、通信/临时 workspace 和安全余量。
