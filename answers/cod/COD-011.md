## 我的答案

下面给 batch=1 的清晰版本。`step_fn(ids)` 返回下一 token logits；beam 保存累计 log-prob，长度惩罚只用于跨候选比较。

```python
from dataclasses import dataclass
import torch
import torch.nn.functional as F

@dataclass
class Beam:
    ids: torch.Tensor       # [L]
    logp: float
    finished: bool

def beam_search(step_fn, prompt, eos_id, beam_size=4, max_new_tokens=64,
                length_alpha=0.6):
    """教学实现：单样本、无 KV cache。"""
    prompt = prompt.clone()
    prompt_len = prompt.numel()
    beams = [Beam(prompt, 0.0, False)]

    def length_penalty(b):
        new_len = max(1, b.ids.numel() - prompt_len)
        return ((5.0 + new_len) / 6.0) ** length_alpha

    def rank_score(b):
        return b.logp / length_penalty(b)

    for _ in range(max_new_tokens):
        candidates = []
        for b in beams:
            if b.finished:
                candidates.append(b)  # finished beam 不再扩展
                continue
            logits = step_fn(b.ids[None, :])[0, -1].float()
            values, indices = torch.topk(F.log_softmax(logits, -1), beam_size)
            for lp, tok in zip(values.tolist(), indices.tolist()):
                ids = torch.cat([b.ids, b.ids.new_tensor([tok])])
                candidates.append(Beam(ids, b.logp + lp, tok == eos_id))

        beams = sorted(candidates, key=rank_score, reverse=True)[:beam_size]
        if all(b.finished for b in beams):
            break

    # 若到预算仍未 EOS，也返回当前最佳 alive beam。
    return max(beams, key=rank_score).ids
```

累计概率必须用 log-space：序列分数是 $\sum_t\log p(y_t)$，避免概率连乘下溢。直接使用累计 log-prob 会偏爱短序列，因此常用：

$$score(y)=\frac{\log P(y\mid x)}{((5+|y|)/6)^\alpha}$$

`alpha=0` 无惩罚，增大后相对鼓励长序列。具体公式是超参数，不同库可能用 $|y|^\alpha$。

“所有保留 beam 都 EOS”是正确但不够激进的 early stop。更强实现会比较最佳 finished score 与所有 alive beam 的乐观上界，只有 finished 已不可能被超越才停止。批量生产还要做 padding/beam index、KV Cache reorder、no-repeat/最小长度约束，并避免每个 beam 单独 forward。

### 面试简答版

Beam Search 每步把每个未完成 beam 扩展 Top-K token，用累计 log-prob 评分，再全局保留 K 条；EOS beam 冻结，全部完成或达到 token 预算就停。累计 log-prob 偏短，因此除以长度惩罚。生产实现还要批量 forward、按父 beam 重排 KV Cache，并用 finished 分数和 alive 上界做更安全的提前停止。
