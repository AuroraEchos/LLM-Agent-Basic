## 我的答案

网络 chunk 边界既不保证落在 UTF-8 字符边界，也不保证落在 JSON/SSE 消息边界。因此不能对每个 bytes chunk 单独 `.decode()` 或 `json.loads()`；要分两层增量缓冲。

下面以常见 SSE/NDJSON 的“每行一个 JSON，SSE 行可带 `data:`”为协议。JSON 字符串内真正的换行会被转义，因此换行可作为 frame delimiter。

```python
import asyncio
import codecs
import inspect
import json

async def iter_stream_json(byte_stream, cancel_event=None):
    decoder = codecs.getincrementaldecoder("utf-8")(errors="strict")
    text_buffer = ""

    async def parse_line(line):
        line = line.strip()
        if not line or line.startswith(":"):       # 空行/SSE comment
            return None
        if line.startswith("data:"):
            line = line[5:].lstrip()
        if line == "[DONE]":
            return "DONE"
        return json.loads(line)

    try:
        async for chunk in byte_stream:
            if cancel_event is not None and cancel_event.is_set():
                raise asyncio.CancelledError
            text_buffer += decoder.decode(chunk, final=False)

            while "\n" in text_buffer:
                line, text_buffer = text_buffer.split("\n", 1)
                value = await parse_line(line.rstrip("\r"))
                if value == "DONE":
                    return
                if value is not None:
                    yield value

        # EOF：strict decoder 会发现残缺 UTF-8；再处理无换行的最后一帧。
        text_buffer += decoder.decode(b"", final=True)
        if text_buffer.strip():
            value = await parse_line(text_buffer)
            if value not in (None, "DONE"):
                yield value
    finally:
        # 取消、解析异常和正常结束都关闭上游 HTTP body/生成器。
        close = getattr(byte_stream, "aclose", None)
        if close is not None:
            result = close()
            if inspect.isawaitable(result):
                await result
```

协议必须先确定：SSE 是空行分隔 event，可能有多行 `data:`；上面是常见的单行 JSON 变体。若服务发送任意拼接的 JSON 值，应在 UTF-8 解码后用 `json.JSONDecoder().raw_decode` 从 buffer 头循环解析，不能靠数花括号，因为字符串内部也可能有括号和转义。

取消不仅是停止本地 `async for`：还要关闭 response body、通知上游取消推理、释放 semaphore/KV Cache，并让 `CancelledError` 继续传播；不要用宽泛 `except Exception` 吞掉。还要设置 read/idle/total timeout、最大 frame/buffer 大小和 JSON schema 校验，防止无分隔数据导致内存无界增长。

### 面试简答版

流式解析要有两层状态：incremental UTF-8 decoder 处理一个字符跨 bytes chunk，文本 buffer 再按协议边界拼出完整 SSE/NDJSON frame，之后才 `json.loads`。EOF 要 flush decoder 并检测残缺字符；取消或异常要在 finally 关闭上游流、释放并发/KV资源并传播取消。还要限制 buffer、设置超时，不能假设网络 chunk 就是一条 JSON。
