## 我的答案

下面的快速排序用随机 pivot + 三路划分，重复元素多时比普通二路划分稳定；“三路”指性能稳定，不代表排序算法稳定。

```python
import random

def quicksort(a):
    def sort(lo, hi):
        if lo >= hi:
            return
        pivot = a[random.randint(lo, hi)]
        lt, i, gt = lo, lo, hi
        # [lo,lt)<pivot, [lt,i)==pivot, (gt,hi]>pivot
        while i <= gt:
            if a[i] < pivot:
                a[lt], a[i] = a[i], a[lt]
                lt += 1; i += 1
            elif a[i] > pivot:
                a[i], a[gt] = a[gt], a[i]
                gt -= 1
            else:
                i += 1
        sort(lo, lt - 1)
        sort(gt + 1, hi)

    sort(0, len(a) - 1)
    return a

def merge_sort(a):
    if len(a) <= 1:
        return list(a)
    mid = len(a) // 2
    left, right = merge_sort(a[:mid]), merge_sort(a[mid:])
    out, i, j = [], 0, 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:      # 相等时取左侧，保证稳定性
            out.append(left[i]); i += 1
        else:
            out.append(right[j]); j += 1
    out.extend(left[i:]); out.extend(right[j:])
    return out
```

| 算法 | 平均时间 | 最坏时间 | 额外空间 | 稳定性 |
|---|---:|---:|---:|---|
| 快排 | O(n log n) | O(n²) | 平均递归 O(log n) | 通常不稳定 |
| 归并 | O(n log n) | O(n log n) | 数组版 O(n) | 可稳定 |

随机 pivot 降低遇到固定恶意顺序的概率，三路划分让大量重复值一次结束；但仍有理论 O(n²) 和递归栈风险。归并的稳定性来自相等时优先左半边，若写成 `<` 就会破坏稳定。数组上快排 cache locality 好，链表/外部排序更适合归并；生产优先使用语言标准库的成熟排序。

### 面试简答版

快排选 pivot 后原地划分并递归两侧，平均 O(n log n)、最坏 O(n²)、通常不稳定；随机 pivot 和三路划分可改善有序/重复数据。归并排序递归分半，再线性合并，时间始终 O(n log n)、数组额外空间 O(n)；相等时先取左侧即可保持稳定。选择取决于内存、稳定性和数据介质。
