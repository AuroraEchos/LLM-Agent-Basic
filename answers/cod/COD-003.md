## 我的答案

Cross-Attention 中 Q 来自目标序列，K/V 来自 memory，因此 `Tq` 与 `Tk` 可以不同。Causal mask 的含义也要由调用方明确：decoder self-attention 常用三角 mask，普通 encoder-decoder cross-attention 通常只需 memory padding mask。

```python
import math
import torch
from torch import nn

class Attention(nn.Module):
    def __init__(self, d_model, num_heads, dropout=0.0):
        super().__init__()
        if d_model % num_heads:
            raise ValueError("d_model % num_heads must be 0")
        self.h, self.dh = num_heads, d_model // num_heads
        self.q_proj = nn.Linear(d_model, d_model)
        self.k_proj = nn.Linear(d_model, d_model)
        self.v_proj = nn.Linear(d_model, d_model)
        self.o_proj = nn.Linear(d_model, d_model)
        self.dropout = dropout

    def _heads(self, x):
        B, T, _ = x.shape
        return x.reshape(B, T, self.h, self.dh).transpose(1, 2)

    def forward(self, query, memory=None, memory_padding_mask=None,
                attn_mask=None, causal=False):
        """
        query: [B,Tq,D]; memory: [B,Tk,D]，None 时为 self-attention
        memory_padding_mask: [B,Tk]，True=有效
        attn_mask: 可广播到 [B,H,Tq,Tk]，True=允许
        """
        memory = query if memory is None else memory
        B, Tq, _ = query.shape
        Tk = memory.size(1)
        q = self._heads(self.q_proj(query))
        k = self._heads(self.k_proj(memory))
        v = self._heads(self.v_proj(memory))
        scores = q @ k.transpose(-2, -1) / math.sqrt(self.dh)

        allowed = torch.ones(B, 1, Tq, Tk, dtype=torch.bool,
                             device=query.device)
        if memory_padding_mask is not None:
            allowed &= memory_padding_mask[:, None, None, :].bool()
        if attn_mask is not None:
            allowed &= attn_mask.to(query.device).bool()
        if causal:
            # 这里只适合从相同起点对齐的 Tq/Tk；增量 decode 需加入 past offset。
            qi = torch.arange(Tq, device=query.device)[:, None]
            kj = torch.arange(Tk, device=query.device)[None, :]
            allowed &= (kj <= qi)[None, None]

        scores = scores.masked_fill(~allowed, torch.finfo(scores.dtype).min)
        p = torch.softmax(scores.float(), dim=-1).to(query.dtype)
        p = p.masked_fill(~allowed, 0.0)
        p = torch.where(allowed.any(-1, keepdim=True), p, torch.zeros_like(p))
        p = torch.dropout(p, self.dropout, self.training)
        y = p @ v
        y = y.transpose(1, 2).contiguous().view(B, Tq, self.h * self.dh)
        return self.o_proj(y)
```

如果是 cross-attention 的“对齐因果”场景，必须定义 query 位置与 memory 位置的对应关系，不能机械套 `tril(Tq,Tk)`。训练时 target padding query 通常由外层 loss mask 处理；这里的 `memory_padding_mask` 只屏蔽 K/V。

### 面试简答版

Cross-Attention 的 Q 是 `[B,H,Tq,Dh]`，K/V 是 `[B,H,Tk,Dh]`，所以 score 是 `[B,H,Tq,Tk]`。padding mask 屏蔽 memory 的 key 维，通用 attention mask 再屏蔽任意 Q-K 对；causal 只有在位置对齐语义明确时才能生成。最常见错误是默认 `Tq=Tk`、把 query padding 当 key padding，以及增量解码忘记 past offset。
