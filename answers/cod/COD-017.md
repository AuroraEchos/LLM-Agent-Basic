## 我的答案

LayerNorm 同时去均值和按方差缩放；RMSNorm 不去均值，只按均方根缩放：

$$LN(x)=\gamma\frac{x-\mu}{\sqrt{\sigma^2+\epsilon}}+\beta,qquad
RMSNorm(x)=\gamma\frac{x}{\sqrt{mean(x^2)+\epsilon}}$$

```python
import torch
from torch import nn

class MyLayerNorm(nn.Module):
    def __init__(self, dim, eps=1e-5, bias=True):
        super().__init__()
        self.weight = nn.Parameter(torch.ones(dim))
        self.bias = nn.Parameter(torch.zeros(dim)) if bias else None
        self.eps = eps

    def forward(self, x):
        dtype = x.dtype
        z = x.float()
        mean = z.mean(dim=-1, keepdim=True)
        var = (z - mean).square().mean(dim=-1, keepdim=True)  # biased var
        y = (z - mean) * torch.rsqrt(var + self.eps)
        y = y.to(dtype) * self.weight
        return y if self.bias is None else y + self.bias

class MyRMSNorm(nn.Module):
    def __init__(self, dim, eps=1e-6):
        super().__init__()
        self.weight = nn.Parameter(torch.ones(dim))
        self.eps = eps

    def forward(self, x):
        dtype = x.dtype
        z = x.float()
        y = z * torch.rsqrt(z.square().mean(dim=-1, keepdim=True) + self.eps)
        return y.to(dtype) * self.weight
```

与框架验证：

```python
x = torch.randn(2, 3, 16, dtype=torch.float32, requires_grad=True)
mine = MyLayerNorm(16)
ref = nn.LayerNorm(16, eps=mine.eps)
ref.load_state_dict(mine.state_dict())
torch.testing.assert_close(mine(x), ref(x), rtol=1e-5, atol=1e-6)

rms = MyRMSNorm(16)
ref_rms = nn.RMSNorm(16, eps=rms.eps)
ref_rms.weight.data.copy_(rms.weight.data)
torch.testing.assert_close(rms(x), ref_rms(x), rtol=1e-5, atol=1e-6)
```

PyTorch LayerNorm 用 `unbiased=False` 的方差，因此不能调用默认 `torch.var` 后忘记参数。低精度输入通常在 FP32 中求统计量，再转回原 dtype。RMSNorm 少了均值和 bias，计算略简洁，但二者不是随意可互换层，checkpoint 必须按训练架构使用。

### 面试简答版

LayerNorm 在最后一维计算均值和 biased variance，做去中心化、缩放并乘 gamma 加 beta；RMSNorm 不减均值，只除以 `sqrt(mean(x²)+eps)` 并乘 gamma。手写时统计量用 FP32，重点核对 eps、归一化维度和 `unbiased=False`，再复制参数与 PyTorch 实现比较前向和梯度。
