## 我的答案

数据流很大、K 很小时用大小为 K 的最小堆；内存数组且追求平均线性时间，可用 Quickselect。

```python
import heapq
import random

def topk_heap(nums, k):
    if not 0 <= k <= len(nums):
        raise ValueError("invalid k")
    heap = []
    for x in nums:
        if len(heap) < k:
            heapq.heappush(heap, x)
        elif k and x > heap[0]:
            heapq.heapreplace(heap, x)
    return sorted(heap, reverse=True)

def topk_quickselect(nums, k):
    """返回未保证顺序的最大 K 个；复制输入，避免修改调用方。"""
    if not 0 <= k <= len(nums):
        raise ValueError("invalid k")
    if k == 0:
        return []
    a = list(nums)

    def partition(lo, hi, pivot_idx):
        pivot = a[pivot_idx]
        a[pivot_idx], a[hi] = a[hi], a[pivot_idx]
        store = lo
        for i in range(lo, hi):
            if a[i] > pivot:          # 大元素放左侧
                a[store], a[i] = a[i], a[store]
                store += 1
        a[store], a[hi] = a[hi], a[store]
        return store

    lo, hi, target = 0, len(a) - 1, k - 1
    while lo <= hi:
        p = partition(lo, hi, random.randint(lo, hi))
        if p == target:
            break
        if p < target:
            lo = p + 1
        else:
            hi = p - 1
    return a[:k]
```

堆遍历每个元素，时间 $O(n\log k)$、额外空间 $O(k)$，还能在线处理流；若最终要排序再加 $O(k\log k)$。Quickselect 类似快速排序只递归/迭代一侧，随机 pivot 期望 $O(n)$、原地额外空间 O(1)，但最坏 $O(n^2)$，且返回 Top-K 内部无序；排序输出仍要 $O(k\log k)$。

重复元素没有问题：Top-K 通常按元素个数返回；若题目要第 K 个**不同值**，必须先去重，会改变空间与语义。工程中数组可直接用 `torch.topk`/`numpy.partition`，面试仍要能解释选择依据。

### 面试简答版

K 小或数据流式时维护 K 大小的最小堆，堆顶是当前第 K 大，复杂度 O(n log k)、空间 O(k)。数组在内存时可随机 pivot 做 Quickselect，把大元素分到左边，只处理包含第 K 位的一侧，期望 O(n)、最坏 O(n²)，结果内部无序。若要有序输出，两者都还需 O(k log k)。
