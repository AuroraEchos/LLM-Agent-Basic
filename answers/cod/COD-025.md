## 我的答案

设 `dp[i][j]` 为 `a[:i]` 与 `b[:j]` 的 LCS 长度：字符相等时取左上角 +1，否则取上方和左方最大值。

```python
def lcs(a, b):
    """返回一条 LCS；O(mn) 时间和空间。"""
    m, n = len(a), len(b)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

    # 从右下角回溯一条解；LCS 可能不唯一。
    out, i, j = [], m, n
    while i and j:
        if a[i - 1] == b[j - 1]:
            out.append(a[i - 1]); i -= 1; j -= 1
        elif dp[i - 1][j] >= dp[i][j - 1]:
            i -= 1
        else:
            j -= 1
    return "".join(reversed(out))
```

若只需要长度，当前行只依赖上一行和当前行左侧，可压成一维，并让 `b` 是较短字符串：

```python
def lcs_length(a, b):
    if len(a) < len(b):
        a, b = b, a
    dp = [0] * (len(b) + 1)
    for ca in a:
        prev_diag = 0
        for j, cb in enumerate(b, start=1):
            old_up = dp[j]
            if ca == cb:
                dp[j] = prev_diag + 1
            else:
                dp[j] = max(dp[j], dp[j - 1])
            prev_diag = old_up
    return dp[-1]
```

时间都是 O(mn)；完整表空间 O(mn)，滚动数组空间 O(min(m,n))。一维更新必须从左到右并保存覆盖前的左上角 `prev_diag`；若只机械写 `dp[j-1]+1`，拿到的是本行值而不是上一行左上值。

若既要恢复序列又要低空间，可用 Hirschberg 分治，在 O(mn) 时间、O(min(m,n)) 额外空间恢复一条 LCS，但实现更复杂。

### 面试简答版

`dp[i][j]` 表示两个前缀的 LCS 长度；字符相等取 `dp[i-1][j-1]+1`，否则取上、左最大。完整表 O(mn) 时间空间并可回溯序列；只求长度时保留一行，把较短串放列上，空间降到 O(min(m,n))。一维更新要保存被覆盖前的左上角值。
