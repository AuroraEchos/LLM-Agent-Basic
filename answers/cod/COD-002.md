## 我的答案

关键是始终标出 shape。输入 `[B,T,D]` 投影后拆成 `[B,H,T,Dh]`，其中 `Dh=D/H`，Attention 后再还原。

```python
import math
import torch
from torch import nn

class MultiHeadSelfAttention(nn.Module):
    def __init__(self, d_model, num_heads, dropout=0.0, bias=True):
        super().__init__()
        if d_model % num_heads:
            raise ValueError("d_model must be divisible by num_heads")
        self.h = num_heads
        self.dh = d_model // num_heads
        self.qkv = nn.Linear(d_model, 3 * d_model, bias=bias)
        self.out = nn.Linear(d_model, d_model, bias=bias)
        self.dropout = dropout

    def _split(self, x):                 # [B,T,D]
        B, T, _ = x.shape
        return x.view(B, T, self.h, self.dh).transpose(1, 2)
                                            # [B,H,T,Dh]

    def forward(self, x, padding_mask=None, causal=False):
        """padding_mask: [B,T]，True 表示有效 token。"""
        B, T, _ = x.shape
        q, k, v = self.qkv(x).chunk(3, dim=-1)
        q, k, v = map(self._split, (q, k, v))

        scores = q @ k.transpose(-2, -1) / math.sqrt(self.dh)
        allowed = torch.ones(B, 1, T, T, dtype=torch.bool, device=x.device)
        if padding_mask is not None:
            valid = padding_mask.to(torch.bool)
            allowed &= valid[:, None, None, :]       # 屏蔽 padding key
        if causal:
            allowed &= torch.ones(T, T, dtype=torch.bool,
                                  device=x.device).tril()[None, None]

        scores = scores.masked_fill(~allowed, torch.finfo(scores.dtype).min)
        attn = torch.softmax(scores.float(), dim=-1).to(x.dtype)
        attn = attn.masked_fill(~allowed, 0.0)
        attn = torch.dropout(attn, self.dropout, self.training)
        y = attn @ v                              # [B,H,T,Dh]
        y = y.transpose(1, 2).contiguous().view(B, T, self.h * self.dh)
        y = self.out(y)                           # [B,T,D]

        if padding_mask is not None:
            y = y * padding_mask[:, :, None].to(y.dtype)  # padding query 置零
        return y
```

`transpose` 后张量通常不连续，因此 `view` 前要 `.contiguous()`，或直接用 `reshape`。padding key 必须屏蔽，否则有效 token 会读取 padding；padding query 是否置零取决于外层 residual 约定，这里显式置零。参数量若 Q/K/V/O 都有 bias，大约为 $4D^2+4D$，头数改变不会改变主投影参数量。

可用 `nn.MultiheadAttention(..., batch_first=True)` 复制权重后，在 dropout=0、eval 模式下比较输出和梯度；测试还应覆盖 `B=1`、`T=1`、causal、padding 以及全 padding 的非法/降级约定。

### 面试简答版

我把 `[B,T,D]` 的 Q/K/V reshape、transpose 成 `[B,H,T,Dh]`，计算 `[B,H,T,T]` 的缩放点积注意力，再 transpose+contiguous 合回 `[B,T,D]` 并做输出投影。容易错的是 `D%H`、转置后的连续性、padding key 与 query 的区别，以及 causal/padding mask 广播方向。
