## 我的答案

估算必须先声明架构和 FLOPs 口径。下面按 decoder-only、SwiGLU、无 bias、multiply-add=2 FLOPs；支持 MHA/GQA 和简单 MoE，不计 Norm/RoPE/Router 等小项。

```python
from dataclasses import dataclass

@dataclass
class Config:
    layers: int
    d_model: int
    d_ff: int
    vocab: int
    q_heads: int
    kv_heads: int
    experts: int = 1
    top_k: int = 1
    shared_experts: int = 0
    tie_embeddings: bool = True

def parameter_counts(c):
    dh = c.d_model // c.q_heads
    if c.d_model % c.q_heads or c.q_heads % c.kv_heads:
        raise ValueError("invalid head config")
    # Q/O: 2D²；K/V: 2*D*(Hkv*Dh)
    attn = 2 * c.d_model**2 + 2 * c.d_model * c.kv_heads * dh
    one_ffn = 3 * c.d_model * c.d_ff
    norms = 2 * c.d_model                         # 每层两个 RMSNorm
    total_layer = attn + c.experts * one_ffn + norms
    active_layer = attn + (c.top_k + c.shared_experts) * one_ffn + norms
    embedding = c.vocab * c.d_model
    output = 0 if c.tie_embeddings else c.vocab * c.d_model
    final_norm = c.d_model
    return {
        "total": embedding + output + c.layers * total_layer + final_norm,
        "active_non_embedding": c.layers * active_layer + c.vocab * c.d_model,
    }

def flops(c, batch, seq_len=1, mode="prefill", context_len=None):
    """返回一次 forward；training 另给约 3x forward。"""
    p = parameter_counts(c)["active_non_embedding"]
    if mode == "prefill":
        # 线性层约 2*active_params*tokens；QK^T 与 AV 合计约 4BL²D/layer
        forward = 2 * p * batch * seq_len
        forward += 4 * c.layers * batch * seq_len**2 * c.d_model
    elif mode == "decode":
        if context_len is None:
            raise ValueError("decode requires context_len")
        forward = 2 * p * batch
        forward += 4 * c.layers * batch * context_len * c.d_model
    else:
        raise ValueError("mode must be prefill/decode")
    return {"inference_forward": forward, "training_rough": 3 * forward}
```

这里 `active_non_embedding` 包含输出 logits 矩阵的计算，但 embedding lookup 只做查表；因此仍是便于容量规划的近似。经典训练粗估 $6N_{active}T$ 来自 forward 约 $2NT$、反向对权重和激活约再 $4NT$，Attention 的 $L^2$ 核心需额外加上。causal kernel 实际可能只算下三角，checkpoint/recompute 又会增加训练 FLOPs。

报告时应给 batch、序列长度、是否只算非 embedding、MHA/GQA、MoE Top-K、训练还是 prefill/decode，以及硬件利用率。FLOPs 不等于延迟，内存带宽、KV Cache 和通信可能主导。

### 面试简答版

decoder 层参数可拆为 Attention：`2D² + 2D*Hkv*Dh`，SwiGLU expert：`3D*F`，再乘层数和专家数；激活参数只算 Top-K+shared experts。线性层前向约 `2*N_active*tokens` FLOPs，训练粗略约 3 倍前向；prefill 还要加每层约 `4*B*L²*D` 的 QK/AV，decode 加 `4*B*context*D`。所有数字必须带架构与口径。
