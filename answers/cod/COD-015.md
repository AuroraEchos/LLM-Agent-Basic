## 我的答案

BM25 对 query 词 $t$ 和文档 $d$ 的典型打分是：

$$\sum_{t\in q}IDF(t)\cdot
\frac{tf(t,d)(k_1+1)}{tf(t,d)+k_1(1-b+b|d|/avgdl)}$$

```python
import math
from collections import Counter

class BM25:
    def __init__(self, tokenized_docs, k1=1.5, b=0.75):
        if not tokenized_docs:
            raise ValueError("corpus is empty")
        self.docs = tokenized_docs
        self.k1, self.b = k1, b
        self.tf = [Counter(doc) for doc in tokenized_docs]
        self.lengths = [len(doc) for doc in tokenized_docs]
        self.avgdl = sum(self.lengths) / len(self.lengths)
        self.N = len(self.docs)

        df = Counter()
        for counts in self.tf:
            df.update(counts.keys())
        # Robertson/Sparck Jones 的常见非负平滑变体
        self.idf = {
            term: math.log(1.0 + (self.N - n + 0.5) / (n + 0.5))
            for term, n in df.items()
        }

    def score(self, query_tokens, doc_idx):
        counts, dl = self.tf[doc_idx], self.lengths[doc_idx]
        norm = 1.0 - self.b + self.b * dl / max(self.avgdl, 1e-12)
        total = 0.0
        for term, qf in Counter(query_tokens).items():
            tf = counts.get(term, 0)
            if not tf:
                continue
            tf_weight = tf * (self.k1 + 1.0) / (tf + self.k1 * norm)
            total += qf * self.idf.get(term, 0.0) * tf_weight
        return total

    def search(self, query_tokens, k=5):
        scored = [(i, self.score(query_tokens, i)) for i in range(self.N)]
        return sorted(scored, key=lambda x: (-x[1], x[0]))[:min(k, self.N)]
```

`IDF` 让罕见词贡献更大；TF 分式会饱和，词出现 20 次不会是 1 次的 20 倍；`b` 控制文档长度归一化，`b=0` 不归一化、`b=1` 完全按长度校正；`k1` 越大，TF 饱和越慢。这里把 query 重复次数 `qf` 作为线性权重，很多搜索实现会忽略或另设 `k3`。

真正倒排索引不会扫描所有文档，而是为每个 term 遍历 posting list 并累加分数。中文还依赖分词/字粒度、大小写和同义词策略；BM25 分数不跨 query 校准，和向量分数混合时通常用 rank fusion 或单独归一化/学习排序。

### 面试简答版

BM25 是 `IDF × 饱和后的 TF × 文档长度归一化`。IDF 提高罕见词权重，`k1` 控制词频多快饱和，`b` 控制长文档惩罚。手写版可逐文档 Counter 打分，生产用倒排表只访问包含 query term 的文档；中文分词和混合检索的分数校准同样重要。
