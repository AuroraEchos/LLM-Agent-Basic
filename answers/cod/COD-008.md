## 我的答案

LoRA 冻结原权重 $W\in\mathbb R^{d_{out}\times d_{in}}$，只训练低秩更新：

$$W'=W+\frac{\alpha}{r}BA,quad
A\in\mathbb R^{r\times d_{in}},\ B\in\mathbb R^{d_{out}\times r}$$

```python
import torch
import torch.nn.functional as F
from torch import nn

class LoRALinear(nn.Module):
    def __init__(self, in_features, out_features, rank=8, alpha=16,
                 dropout=0.0, bias=True):
        super().__init__()
        if rank <= 0:
            raise ValueError("rank must be positive")
        self.weight = nn.Parameter(torch.empty(out_features, in_features))
        self.bias = nn.Parameter(torch.zeros(out_features)) if bias else None
        self.A = nn.Parameter(torch.empty(rank, in_features))
        self.B = nn.Parameter(torch.zeros(out_features, rank))
        self.scale = alpha / rank
        self.dropout = nn.Dropout(dropout)
        self.merged = False
        nn.init.kaiming_uniform_(self.weight, a=5 ** 0.5)
        nn.init.kaiming_uniform_(self.A, a=5 ** 0.5)
        # B=0，保证初始化时 LoRA 分支输出为 0。

    def delta_weight(self):
        return (self.B @ self.A) * self.scale

    def forward(self, x):
        y = F.linear(x, self.weight, self.bias)
        if not self.merged:
            y = y + F.linear(F.linear(self.dropout(x), self.A), self.B) * self.scale
        return y

    @torch.no_grad()
    def merge(self):
        if not self.merged:
            self.weight.add_(self.delta_weight().to(self.weight.dtype))
            self.merged = True

    @torch.no_grad()
    def unmerge(self):
        if self.merged:
            self.weight.sub_(self.delta_weight().to(self.weight.dtype))
            self.merged = False
```

训练时通常把 `weight/bias.requires_grad_(False)`，只优化 A/B；上面保留可配置空间，调用方可冻结。参数增量为 $r(d_{in}+d_{out})$，远小于 $d_{in}d_{out}$。

验证时在 `eval()` 下记录未合并输出，`merge()` 后应一致，`unmerge()` 后再次一致。不要反复在 FP16/BF16 权重上 merge/unmerge：舍入误差会累积；生产可保存 FP32 base/delta 或从原 checkpoint 重建。merged 状态还需进入保存/加载协议，adapter 与 base 的版本、target modules、rank 和 scaling 必须匹配。

### 面试简答版

LoRA 用 `BA * alpha/r` 表示低秩权重增量，A 随机初始化、B 初始化为零，使起始输出等于 base。训练前向是 `Wx + B(Ax)*scale`；部署可把 delta 加进 W，合并后不能再重复计算 LoRA 分支，并支持减去 delta 取消合并。重点是矩阵 shape、冻结 base、防止重复 merge，以及低精度反复合并的误差。
