## 我的答案

最优常用方法是最小堆：堆中只放每条链表当前头节点，弹出最小节点后再放入它的后继。

```python
from dataclasses import dataclass
import heapq
import itertools

@dataclass
class ListNode:
    val: int
    next: "ListNode | None" = None

def merge_k_lists(lists):
    heap = []
    tie = itertools.count()
    for node in lists:
        if node is not None:
            # tie 防止 val 相同时 Python 尝试比较 ListNode。
            heapq.heappush(heap, (node.val, next(tie), node))

    dummy = tail = ListNode(0)
    while heap:
        _, _, node = heapq.heappop(heap)
        nxt = node.next
        tail.next = node
        tail = node
        if nxt is not None:
            heapq.heappush(heap, (nxt.val, next(tie), nxt))
    tail.next = None
    return dummy.next
```

设总节点数 N、链表数 K，堆最多 K 个元素，因此时间 $O(N\log K)$、额外空间 $O(K)$；代码复用原节点，若不允许修改输入则需创建新节点。

其他解法：

- 依次把结果与下一条链表合并，最坏 $O(NK)$，因为早期结果被反复扫描；
- 分治两两合并，每个节点经历约 $\log K$ 层，时间 $O(N\log K)$，递归/辅助数组约 O(log K)/O(K)，通常 cache 友好；
- 每次线性扫描 K 个头取最小，时间 $O(NK)$，只在 K 极小时简单可用。

边界要测空 `lists`、全部 `None`、K=1、重复值、负数和长短极不均。若链表可能有环，题目原假设已被破坏，需要先校验或限定输入。

### 面试简答版

把 K 条链表的非空头节点放最小堆，每次弹最小节点接到结果尾部，再把它的 next 入堆。堆大小最多 K，所以 N 个总节点时间 O(N log K)、空间 O(K)。Python 堆遇到相同值时要加递增 tie-breaker，避免比较节点对象。分治两两合并也能达到 O(N log K)。
