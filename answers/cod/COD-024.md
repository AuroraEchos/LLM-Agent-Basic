## 我的答案

层序遍历本质是 BFS。队列在每轮开始时的长度就是当前层节点数，处理恰好这些节点即可分层。

```python
from collections import deque
from dataclasses import dataclass

@dataclass
class TreeNode:
    val: int
    left: "TreeNode | None" = None
    right: "TreeNode | None" = None

def level_order(root):
    if root is None:
        return []
    result = []
    queue = deque([root])
    while queue:
        level = []
        for _ in range(len(queue)):
            node = queue.popleft()
            level.append(node.val)
            if node.left is not None:
                queue.append(node.left)
            if node.right is not None:
                queue.append(node.right)
        result.append(level)
    return result
```

每个节点入队、出队一次，时间 O(N)。队列最多保存树最宽一层，空间 O(W)，最坏 O(N)。不能用 Python `list.pop(0)` 代替 `deque.popleft()`，因为前者每次搬移后续元素，是 O(N)。

若只需平铺顺序，不用记录 `level`；若要求 zigzag，可在奇数层反转输出或双端插入，但节点入队顺序仍可保持一致。深度优先也能按 depth 写入二维数组，但递归深度在极端链状树可能溢出；BFS 更直接表达层序。

### 面试简答版

用 deque 做 BFS：每轮先读取当前 queue 长度，这个长度就是本层节点数；弹出这些节点、记录值并把左右孩子入队，然后得到下一层。每个节点访问一次，时间 O(N)，空间 O(树的最大宽度)。Python 要用 `popleft()`，不能用 O(N) 的 `list.pop(0)`。
