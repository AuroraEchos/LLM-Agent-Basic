## 我的答案

三种解码都从最后一步 logits `[B,V]` 选 token。Greedy 取最大值；Top-K 只在最大 K 个中采样；Top-P 取累计概率刚超过 $p$ 的最小前缀。

```python
import torch

def sample_next(logits, strategy="greedy", temperature=1.0,
                top_k=None, top_p=None, generator=None):
    """logits: [B,V]，返回 [B] token ids。"""
    if logits.ndim != 2:
        raise ValueError("expected [batch, vocab] logits")
    if strategy == "greedy":
        return logits.argmax(dim=-1)
    if temperature <= 0:
        raise ValueError("temperature must be > 0 for sampling")

    x = logits.float() / temperature
    if top_k is not None:
        k = min(max(int(top_k), 1), x.size(-1))
        threshold = torch.topk(x, k, dim=-1).values[..., -1, None]
        x = x.masked_fill(x < threshold, -torch.inf)

    if top_p is not None:
        if not 0.0 < top_p <= 1.0:
            raise ValueError("top_p must be in (0, 1]")
        sorted_x, sorted_idx = torch.sort(x, descending=True, dim=-1)
        sorted_p = torch.softmax(sorted_x, dim=-1)
        remove = sorted_p.cumsum(dim=-1) > top_p
        # 保留第一个使累计概率越过 p 的 token，也始终保留最高概率项。
        remove[..., 1:] = remove[..., :-1].clone()
        remove[..., 0] = False
        sorted_x = sorted_x.masked_fill(remove, -torch.inf)
        x = torch.full_like(x, -torch.inf).scatter(-1, sorted_idx, sorted_x)

    probs = torch.softmax(x, dim=-1)
    if not torch.isfinite(probs).all() or (probs.sum(-1) == 0).any():
        raise ValueError("invalid filtered distribution")
    return torch.multinomial(probs, 1, generator=generator).squeeze(-1)
```

Top-K 控制候选数量但不适应分布尖锐程度；Top-P 控制概率质量，尖锐分布候选少、平坦分布候选多。二者可以顺序组合。Temperature `<1` 让分布更尖，`>1` 更随机；temperature=0 通常作为 greedy 的产品约定，不应真的做除零。

采样前还可能应用 repetition penalty、禁词、最小长度等 logits processors；为了复现要记录模型版本、prompt、seed、temperature、K/P 和处理器顺序。批量生成中每条序列 EOS 后应停止采样或只填 pad。

### 面试简答版

Greedy 直接 argmax；Top-K 把 K 名以外 logits 置 `-inf`；Top-P 先按概率降序，保留累计质量达到 p 的最小前缀，再归一化采样。Top-P 的移位一步很关键，要保留第一个让累计概率越过阈值的 token。Temperature 在过滤前缩放 logits，复现还要固定 seed 和所有 logits processor 顺序。
