## 我的答案

下面约定布尔 `mask=True` 表示该位置**允许被关注**，并支持能广播到 `[B, H, Tq, Tk]` 的形状。实现时用 FP32 做 softmax，避免低精度下溢/溢出。

```python
import math
import torch

def scaled_dot_product_attention(q, k, v, mask=None, dropout_p=0.0,
                                 training=False):
    """
    q: [B, H, Tq, Dh]
    k: [B, H, Tk, Dh]
    v: [B, H, Tk, Dv]
    mask: bool，可广播到 [B, H, Tq, Tk]，True=keep
    """
    if q.size(-1) != k.size(-1):
        raise ValueError("q/k head_dim must match")

    scores = q @ k.transpose(-2, -1) / math.sqrt(q.size(-1))
    allowed = None
    if mask is not None:
        allowed = mask.to(device=scores.device, dtype=torch.bool)
        scores = scores.masked_fill(~allowed, torch.finfo(scores.dtype).min)

    probs = torch.softmax(scores.float(), dim=-1).to(q.dtype)
    if allowed is not None:
        # 若某一行全被 mask，softmax 本身会给出无意义分布；显式置零。
        probs = probs.masked_fill(~allowed, 0.0)
        probs = torch.where(
            allowed.any(dim=-1, keepdim=True), probs, torch.zeros_like(probs)
        )
    probs = torch.dropout(probs, dropout_p, training) if dropout_p else probs
    return probs @ v, probs
```

构造 causal mask：

```python
T = 4
causal = torch.ones(T, T, dtype=torch.bool).tril()[None, None, :, :]
out, attn = scaled_dot_product_attention(q, k, v, causal)
```

缩放 $1/\sqrt{d_h}$ 的原因是：若 Q、K 各分量方差约为 1，点积方差随 $d_h$ 增大；不缩放会让 softmax 过早饱和、梯度变小。时间复杂度为 $O(BHT_qT_kd_h)$，显式 `scores/probs` 内存为 $O(BHT_qT_k)$；生产中通常用 `torch.nn.functional.scaled_dot_product_attention`/FlashAttention，避免完整物化注意力矩阵。

要特别说明库的 mask 语义并不统一：本题代码是 `True=keep`，而某些 `nn.MultiheadAttention` 布尔 mask 用 `True=block`，接口切换时必须测试。

### 面试简答版

先算 $QK^T/\sqrt{d_h}$，把不允许位置填成 dtype 最小值，用 FP32 softmax，再乘 V。我会明确规定 bool mask 的方向和可广播 shape，并处理“整行全 mask”避免得到无意义分布。手写实现会物化 $T^2$ 矩阵，生产环境改用 PyTorch SDPA/FlashAttention，但手写题重点是缩放、mask、shape 和数值稳定。
