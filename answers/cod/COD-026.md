## 我的答案

把每个陆地格子看成图节点，上下左右相邻为边；每发现一个未访问陆地，就把它的整个连通分量遍历掉，答案加一。

```python
def num_islands_dfs(grid):
    if not grid or not grid[0]:
        return 0
    rows, cols = len(grid), len(grid[0])
    if any(len(row) != cols for row in grid):
        raise ValueError("grid must be rectangular")
    seen = set()
    islands = 0

    for r in range(rows):
        for c in range(cols):
            if grid[r][c] != "1" or (r, c) in seen:
                continue
            islands += 1
            stack = [(r, c)]
            seen.add((r, c))
            while stack:
                x, y = stack.pop()
                for nx, ny in ((x-1,y), (x+1,y), (x,y-1), (x,y+1)):
                    if (0 <= nx < rows and 0 <= ny < cols
                            and grid[nx][ny] == "1"
                            and (nx, ny) not in seen):
                        seen.add((nx, ny))  # 入栈时标记，避免重复入栈
                        stack.append((nx, ny))
    return islands
```

DFS 可用栈，BFS 只需把栈换成 `deque`；二者时间都是 O(RC)、visited 最坏 O(RC)。递归 DFS 代码短，但一个巨大岛可能超过 Python 递归深度；迭代更稳。若允许修改输入，可把访问过的 `'1'` 原地改 `'0'`，省去 visited 集合，但会破坏调用方数据。

并查集适合动态连通或并行构建：为每个陆地格建 parent，遍历时只与上/左陆地 union，初始岛数为陆地数；每次合并两个不同 root 就减一。复杂度 O(RC·α(RC))，但 parent/rank 数组和索引代码更多。对于一次静态计数，DFS/BFS 通常更简单；若不断把水变陆地并询问岛数，并查集优势明显。删除陆地则普通并查集不擅长。

还要确认邻接定义：本题是四连通；若对角也算相邻，要改为八个方向。

### 面试简答版

扫描网格，每遇到一个未访问陆地，岛数加一，再用迭代 DFS/BFS 标记整个四连通分量。时间 O(RC)，额外空间最坏 O(RC)；入栈/入队时就标记，避免重复。静态题 DFS/BFS 最直接，动态新增陆地和多次查询可用并查集，近似线性，但删除操作不适合普通 DSU。
