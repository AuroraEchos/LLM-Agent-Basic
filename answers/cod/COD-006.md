## 我的答案

普通 softmax 若直接计算 $e^{x_i}$ 会溢出。Online Softmax 在流式读取元素时维护当前最大值 $m$ 和归一化分母 $d=\sum e^{x_i-m}$：

$$m' = \max(m,x),\qquad d'=d\,e^{m-m'}+e^{x-m'}$$

```python
import torch

def online_softmax(x):
    """沿最后一维计算；教学实现，支持任意前缀 batch shape。"""
    if x.size(-1) == 0:
        raise ValueError("softmax dimension cannot be empty")
    work = x.float()
    m = torch.full_like(work[..., 0], -torch.inf)
    d = torch.zeros_like(m)

    for j in range(work.size(-1)):
        xj = work[..., j]
        m_new = torch.maximum(m, xj)
        d = d * torch.exp(m - m_new) + torch.exp(xj - m_new)
        m = m_new

    return (torch.exp(work - m.unsqueeze(-1)) / d.unsqueeze(-1)).to(x.dtype)


x = torch.randn(3, 100, dtype=torch.float32) * 50
torch.testing.assert_close(online_softmax(x), torch.softmax(x, -1))
```

这段为了返回所有概率需要第二遍访问 `x`，但第一遍只保留 $m,d$，额外状态是 $O(1)$（每个 batch row）。若输入按 block 到达，可把单个 $x$ 换成块的局部最大值和局部指数和，用同一公式合并。

FlashAttention 还会维护未归一化输出累加器 $o=\sum e^{s_i-m}v_i$：最大值更新时把旧的 $d,o$ 同时乘 $e^{m-m'}$，加入当前 block，最后输出 $o/d$。这样无需物化完整 $T\times T$ score/probability 矩阵。

边界上，全为 `-inf` 时 softmax 没有数学定义，会得到 NaN；Attention 中整行被 mask 应在上层显式输出零，而不是期待 softmax 猜测语义。生产实现还需处理 `+inf`、NaN 策略和低精度累加。

### 面试简答版

Online Softmax 流式维护最大值 `m` 和缩放后的分母 `d`。新元素到来时先令 `m'=max(m,x)`，再把旧分母乘 `exp(m-m')` 后加 `exp(x-m')`，因此不会直接计算巨大指数。FlashAttention 同理维护加权 V 的累加器，按 block 合并，从而不物化完整注意力矩阵；全 mask 行需要上层单独处理。
