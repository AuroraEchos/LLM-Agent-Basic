## 我的答案

下面实现经典 word-level BPE。`</w>` 是词尾标记，保证 merge 不跨越词边界；真实 GPT 类 tokenizer 的预分词和 byte encoding 更复杂，但核心迭代相同。

```python
import re
from collections import Counter

EOW = "</w>"

def word_symbols(word):
    return tuple(list(word) + [EOW])

def pair_counts(vocab):
    counts = Counter()
    for symbols, freq in vocab.items():
        for pair in zip(symbols, symbols[1:]):
            counts[pair] += freq
    return counts

def merge_pair(symbols, pair):
    out, i = [], 0
    merged = "".join(pair)
    while i < len(symbols):
        if i + 1 < len(symbols) and (symbols[i], symbols[i + 1]) == pair:
            out.append(merged)
            i += 2
        else:
            out.append(symbols[i])
            i += 1
    return tuple(out)

def train_bpe(texts, num_merges):
    word_freq = Counter(w for text in texts for w in re.findall(r"\S+", text))
    vocab = Counter({word_symbols(w): n for w, n in word_freq.items()})
    merges = []
    for _ in range(num_merges):
        counts = pair_counts(vocab)
        if not counts:
            break
        # 相同频次时固定字典序，保证可复现。
        best = min(counts, key=lambda p: (-counts[p], p))
        new_vocab = Counter()
        for symbols, freq in vocab.items():
            new_vocab[merge_pair(symbols, best)] += freq
        vocab = new_vocab
        merges.append(best)
    return merges

def encode_word(word, merges):
    symbols = word_symbols(word)
    ranks = {pair: i for i, pair in enumerate(merges)}
    while len(symbols) > 1:
        candidates = set(zip(symbols, symbols[1:]))
        pair = min(candidates, key=lambda p: ranks.get(p, float("inf")))
        if pair not in ranks:
            break
        symbols = merge_pair(symbols, pair)
    return list(symbols)

def encode(text, merges):
    # 教学版把空白作为独立 token 保留，因此绝不会跨词 merge。
    out = []
    for piece in re.findall(r"\s+|\S+", text):
        out.extend([piece] if piece.isspace() else encode_word(piece, merges))
    return out
```

训练时每轮统计相邻 symbol pair 的加权频次，合并最高频 pair 并记录顺序；编码时反复应用当前可用 pair 中训练 rank 最小者。若只按字符串替换，很容易重叠合并或跨词边界。

生产 tokenizer 通常先把 Unicode 转为 bytes 或规范化，再用更细致正则预分词，并固定 special tokens。必须版本化 normalization、pre-tokenizer、merge ranks 和 vocabulary；否则同一文本的 token ids 改变会令训练/服务不一致。

### 面试简答版

BPE 从字符加词尾标记开始，每轮统计所有词内部相邻 pair 的加权频次，合并最高频 pair并记录 merge rank；编码时只在一个词内部反复应用 rank 最靠前的可用 pair。词尾标记或明确预分词边界能防止跨词合并。工程上还要固定 Unicode/byte 规范化、special tokens、vocab 和 merges 版本。
