## 我的答案

Grounding 是把语言中的实体、短语或指令绑定到视觉空间。Bounding Box 给出区域范围，Point Prediction 给出一个代表性点；后者输出更短、标注更便宜，但不能表达目标大小和形状。

### 输出表示

常见 box 表示为 $(x_{min},y_{min},x_{max},y_{max})$ 或 $(c_x,c_y,w,h)$。为了跨分辨率，先归一化：

$$
\tilde x=\frac{x}{W},\qquad \tilde y=\frac{y}{H}
$$

实现路线有三类：

1. **连续回归 head**：文本/对象 query cross-attend 视觉特征，MLP 输出 $[0,1]^4$ box 或 $[0,1]^2$ point；精度连续，但需要专用 head 和 loss。
2. **离散坐标 token**：将 $[0,1]$ 量化到 $K$ 个 bin，如 `<loc_0>...<loc_999>`，让 decoder 生成“短语+坐标”序列。统一语言接口、易多轮输出，但有量化误差、格式和坐标顺序问题。
3. **检测/分割工具协同**：VLM理解指令，专用 detector/segmenter 输出 box/mask；可复用强定位模型，系统更可验证，但需处理类别开放性和组件错误传播。

Point 可以直接生成坐标，也可以从 attention/heatmap 取峰值或在 mask 内选中心。细长/环形物体的几何中心可能落在物体外，因此训练定义应明确“任一物体内部点”还是“中心点”。

### 模型与训练

数据包括 object detection、referring expression comprehension/generation、phrase grounding、pointing、OCR/文档 bbox、区域 caption 和多轮指代。每条样本保存原图尺寸、预处理变换、对象/短语、多个合法区域、遮挡/截断和置信度。

连续 box 常用：

$$
\mathcal L_{box}=\lambda_1\|b-\hat b\|_1+lambda_2\mathcal L_{GIoU}(b,\hat b)
$$

再加类别/短语对齐 loss。多个对象的 set prediction 可用 Hungarian matching，避免预测顺序任意造成重复监督。离散 token 模型使用 next-token loss，但可额外加入坐标一致、格式约束或检测辅助 loss。

对“左边穿红衣的人”等短语，文本 query 必须与视觉 patch 交互；只用全局 CLIP embedding 很难定位。高分辨率、二维位置和多尺度特征对小目标关键。

### 坐标变换的工程陷阱

模型通常看到的是 resize、pad、crop 或 tile 后图像。输出坐标必须经过逆变换映射回原图：先去 padding，再乘缩放，最后加 crop/tile offset，并 clip 到合法范围。映射元数据若丢失，即使模型预测正确也会框错。

多图要返回 `image_id + box`，文档返回 `document_version + page + bbox`，视频返回 `time range/frame id + box/track`。结构化 Schema 约束坐标数量、顺序和范围，不能靠解析自由文本猜测。

### 评估

- box 用 IoU、Accuracy@IoU≥0.5、mAP/Recall@k；小目标单独切片；
- point 用 pointing game/point-in-mask accuracy、归一化距离；
- phrase grounding还要测短语—区域绑定、重复对象和多个合法目标；
- free-form 输出需同时评语言正确和坐标，不能只看其中一项。

负样本同样重要：目标不存在时应输出 `not_found`，不能总给一个框。测试 resize/长宽比、tile 边界、遮挡、相似多个对象、否定和关系指令；高风险场景由 detector/人复核。

### 面试简答版

Grounding 把文本短语绑定到图像区域。坐标一般归一化到 $[0,1]$，可以用专用 head 连续回归 box/point，也可以量化成 `<loc_*>` token 由 LLM 自回归生成，或让 VLM调用检测/分割工具。box 训练常用 L1+GIoU，多目标用 Hungarian matching；point 要明确是中心还是物体内任一点。工程上最易错的是 resize/pad/crop/tile 的逆坐标映射，多图还必须带 image ID。评测用 IoU/mAP、point-in-mask、短语绑定和不存在目标的拒识，并单测小目标与多个相似对象。
