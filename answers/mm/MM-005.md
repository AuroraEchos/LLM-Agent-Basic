## 我的答案

不同论文对阶段名称并不统一，我会按目标区分三层：**学会各模态表示与跨模态统计关系、把视觉信息接入语言空间、学会按照人类指令完成具体任务。**数据质量和配比随阶段逐渐从“规模优先”转向“行为与难例优先”。

### 1. 多模态预训练

目标是获得广泛的视觉/音频/视频与语言表示。数据以大规模弱标注为主：

- 图片—alt text、标题、网页邻近文本；视频—字幕/ASR/时间片描述；音频—转写与事件标签；
- 也可加入纯图像自监督/掩码重建、纯文本语料，维持单模态能力；
- 目标包括图文对比、image-text matching、masked modeling、caption generation 等。

这个阶段重规模和覆盖，但必须做版权/许可、PII/敏感内容、图文相关性、语言识别、去重和 benchmark contamination 治理。弱文本常只描述图像一部分，不能假设 caption 是完整真值。

### 2. 对齐预训练 / Connector 训练

目标是让预训练 vision encoder 的表示能被 LLM 理解，常冻结一端或两端，训练 projector/Q-Former。需要比 Web alt-text 更直接、干净的配对数据：

- 图像—高质量 caption、区域—短语、OCR—文字、物体/属性/关系描述；
- 图表/表格—结构化描述，文档页—转写与布局，多图—明确索引的对照描述；
- 可加入合成 dense caption，但需质量筛选、来源标记和与真实数据混合。

此阶段通常用 caption/自回归损失、对比/匹配或 grounding 目标，使视觉 token 进入语言表示空间。数据要覆盖未来任务所需的分辨率和视觉 token 方案，否则 projector 只学到粗粒度语义。

### 3. 多模态指令微调

目标是让模型理解“用户想做什么”并以合适格式回答。数据是 `(多模态输入, 多轮指令, 高质量回答/工具轨迹)`：

- VQA、OCR、文档/图表、计数、空间关系、比较、多图推理、视频时序；
- grounding/坐标、结构化 JSON、拒答/澄清、证据引用和工具使用；
- 多轮对话中保持图片指代一致，包含无答案、模糊图、遮挡和错误前提；
- 安全、隐私、公平、过度拒答的对抗与困难良性样本；
- pairwise preference 或人类反馈可进一步优化 helpfulness 与安全行为。

不能只用强模型合成长推理数据：teacher 可能看错图并把幻觉放大。合成数据应保存 teacher/prompt/provenance，经规则、视觉验证器和人工抽检；答案长度与模板需去偏。

### 数据配比与验证

训练中混入一定纯文本指令数据，降低语言能力遗忘；不同模态/任务按质量、难度和业务价值加权，而非简单按样本数。相同图片、视频片段和模板应 group-level 切分，防止训练/评测泄漏。

每阶段都做消融：冻结/解冻哪些模块、真实/合成比例、分辨率、connector token 数和数据源贡献。评测既看通用视觉问答，也看 OCR、空间、计数、幻觉、引用、安全和纯文本回退；发现问题后应修对应阶段，而不是一律增加指令数据。

### 面试简答版

多模态预训练用大规模弱标注图文、视频字幕、音频转写和单模态数据，通过对比、匹配、掩码或生成目标学广泛表示；对齐预训练使用更干净的 caption、区域短语、OCR、图表/文档配对，常冻结 vision tower 和 LLM 来训练 projector/Q-Former；指令微调则需要多轮 VQA、OCR、空间/计数、多图视频、grounding、工具、安全和无答案数据，学习按指令行为。规模从前到后下降、质量和难例密度上升。所有阶段都要许可、去重、污染治理、合成数据验证，并保留纯文本数据防遗忘。
