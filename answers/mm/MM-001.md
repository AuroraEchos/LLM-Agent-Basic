> **问题：** 典型 Vision-Language Model 的 Vision Encoder、Projector 和 LLM 如何连接？

> **分类：** 多模态大模型

> **来源：** [INTERVIEW_QUESTIONS_AGENT_HARNESS_EXPANDED.md](../../INTERVIEW_QUESTIONS_AGENT_HARNESS_EXPANDED.md)

## 我的答案

典型 VLM 可以理解为把视觉编码器产生的连续视觉特征，经过连接器转换成 LLM 能消费的“视觉 token”，再与文本 token 一起进行自回归生成：

$$
I\xrightarrow{E_v}Z_v\in\mathbb{R}^{N_v\times d_v}
\xrightarrow{P}H_v\in\mathbb{R}^{N'_v\times d_{llm}}
\xrightarrow{LLM}P(y\mid I,x)
$$

其中 $E_v$ 是 Vision Encoder，$P$ 是 Projector/Connector，$N'_v$ 是否等于 $N_v$ 取决于连接器是否压缩 token。

### 三个组件的职责

**Vision Encoder** 通常是预训练 ViT/CLIP vision tower。图像经 resize/分块后形成 patch tokens，编码器提取局部和全局语义。高分辨率模型可能切 tile、动态分辨率或多尺度编码，并保留二维位置。输出可以去掉 `[CLS]` 只用 patch feature，也可结合全局 token。

**Projector/Connector** 解决两个不匹配：视觉维度 $d_v$ 与词嵌入维度 $d_{llm}$ 不同，视觉特征分布与 LLM 的语言表示空间也不同。最简单是线性层或两层 MLP逐 token 映射；Q-Former/Resampler 用少量可学习 query 对视觉 token cross-attend，从而同时对齐和压缩；更深方案在 LLM 多层插入 cross-attention。

**LLM** 负责理解指令、跨 token 推理和生成文本。以 decoder-only 拼接方案为例：

```text
<bos> 用户文本 <image_start> v1 v2 ... vN <image_end> 问题 → 答案
```

图像 token 不是离散词表 ID，而是直接放入 LLM embedding sequence 的连续向量。需要正确构造 position id、attention mask 和 label mask：输入图片/问题位置通常不计算语言生成 loss，只对目标回答 token 计算交叉熵。

### 两种主要连接方式

1. **Token 拼接 / early fusion**：投影后的视觉 token 与文本 embedding 拼接后进入 LLM self-attention。架构简单、可复用原生 causal LLM，但视觉 token 占上下文并使注意力成本增加。
2. **Cross-attention / gated fusion**：LLM 文本状态在部分层 cross-attend 视觉记忆。视觉 token 不必全部占用文本序列，可灵活多图/视频，但需修改 LLM 层，训练和 serving 更复杂。

### 常见训练阶段

通常先冻结 vision tower 与 LLM，仅训练 projector，使图像特征进入 LLM 表示空间；随后用多模态指令数据训练 projector 与 LLM（全部或 LoRA），必要时解冻视觉编码器后几层。学习目标可含自回归语言损失、对比/匹配、grounding 等。分阶段冻结能保留预训练能力、降低成本，但只训练小 projector 可能形成信息瓶颈。

### 工程边界

- 视觉 token 数直接影响 prefill、KV Cache 和上下文预算；高分辨率不能只粗暴增加 tile。
- resize/crop 可能损失小字和长宽比；OCR、图表、文档要单独评测坐标与细粒度能力。
- 视觉编码器“看到特征”不代表 LLM 能忠实使用；需要针对 hallucination、计数、空间、文字和多图绑定做端到端评测。
- 多图必须有清晰的图片边界和位置标识，避免问题指代错图。

### 面试简答版

典型 VLM 是 `Vision Encoder → Projector/Connector → LLM`。视觉编码器把图像变成 $N_v\times d_v$ 的 patch 特征，projector 将其映射为 LLM 维度，或用 Q-Former 等压缩成固定数量视觉 token；随后把视觉 token 与文本 embedding 拼接进 decoder-only LLM，或者由 LLM cross-attend 视觉记忆。训练常先冻结两端只学 connector，再做多模态指令微调。关键工程取舍是视觉 token 数、分辨率、上下文/延迟，以及 connector 是否丢失 OCR、空间和细粒度信息。
