> **问题：** Early Fusion、Late Fusion 与统一 Token 建模有何差异？
>
> **分类：** 多模态大模型
>
> **来源：** [INTERVIEW_QUESTIONS_AGENT_HARNESS_EXPANDED.md](../../INTERVIEW_QUESTIONS_AGENT_HARNESS_EXPANDED.md)

## 我的答案

这三种说法关注融合发生的层级。Early Fusion 在较早的特征/token 层做联合建模，Late Fusion 先由各模态独立决策再合并，统一 Token 建模则更进一步，把不同模态都变成一个 Transformer 可处理的序列符号/连续 token。统一 token 常是一种 early fusion，但它强调共享接口和生成目标。

### Early Fusion

各模态先经过浅层 encoder/embedding，随后拼接或 cross-attention，在多层网络中共同推理：

$$
H=F([E_t(x_t);E_v(x_v);E_a(x_a)])
$$

优点是能学习细粒度交互，如“这句话对应图中哪个区域”“声音发生时画面是什么”；适合 VQA、视听事件和跨模态推理。缺点是序列长、计算高，要求模态时间/位置对齐；缺失模态、噪声或一模态占主导会影响整体，预计算缓存也较难。

典型形式包括视觉 token 与文本 embedding 直接拼接、单流 Transformer，或早期多层 cross-attention。

### Late Fusion

每个模态独立编码甚至独立预测，最后融合 embedding、logits 或专家结论：

$$
p(y)=\sum_m w_m p_m(y\mid x_m)
$$

权重可固定、学习或由 gating 根据质量动态分配。优点是模块化、易复用单模态模型、可并行/缓存、某模态缺失时容易降级；每个分支可独立解释和部署。缺点是早期细粒度关系已经丢失，最终分数融合很难回答区域/时间绑定问题。

适合多传感器分类、检索 rerank、多个独立证据或 ensemble，也常作为安全可靠的 baseline。

### 统一 Token 建模

把图像 patch/离散视觉码、音频帧、视频 token、坐标和文本都映射到共享维度，加入 modality/position/time embedding，使用一个 Transformer 和统一序列目标：

```text
<image> v1 ... vn </image> <audio> a1 ... am </audio> <text> ...
```

连续视觉 token 可直接插 embedding；离散 tokenizer/VQ code 则可与文本一起 autoregressive 生成。优势是接口统一、容易扩展 in-context 与任意模态到模态生成，跨模态交互深；局限是 tokenizer/压缩会丢信息，不同模态 token 率差异巨大，长视频/音频会淹没文本，训练数据与算力要求高，还可能出现模态竞争和单模态能力退化。

### 选型与混合

实际系统常混合：模态专用 encoder 先提取高质量表示，Q-Former/resampler 压缩后在 LLM early fusion，最终再与结构化工具结果 late fusion。选择依据包括是否需要细粒度对齐、模态是否经常缺失、能否离线缓存、token/延迟预算和数据规模。

评测不能只看总体准确率，要做 modality ablation、缺失/损坏模态、时间错位、反事实替换和不同 token budget。若去掉图像性能不变，所谓融合可能只利用语言偏差；若一个噪声模态使全局崩溃，说明缺少可靠 gating。

### 面试简答版

Early Fusion 在特征或 token 层较早拼接/cross-attend，细粒度图文/视听关系强，但序列长、对对齐和算力要求高；Late Fusion 让各模态独立编码/预测，最后融合 embedding 或 logits，模块化、可缓存且易处理缺失模态，但难学区域和时间级交互。统一 Token 建模把图像、音频、视频、坐标和文本映射为共享序列，由同一 Transformer 建模或生成，它属于更统一的早融合接口，但有 token 爆炸和模态竞争。生产常用专用 encoder+压缩 early fusion，再与工具结果 late fusion。
