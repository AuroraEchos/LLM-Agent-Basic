> **问题：** Tensor Parallel 中 Column Parallel 与 Row Parallel Linear 如何通信？
>
> **分类：** 分布式训练与 AI Infra
>
> **来源：** [INTERVIEW_QUESTIONS_AGENT_HARNESS_EXPANDED.md](../../INTERVIEW_QUESTIONS_AGENT_HARNESS_EXPANDED.md)
<!-- AUTO-QUESTION:END -->

## 我的答案

设线性层 $Y=XW^T$，$X\in\mathbb R^{B\times d_{in}}$，$W\in\mathbb R^{d_{out}\times d_{in}}$，TP size 为 $P$。

### Column Parallel Linear

沿输出维切权重：

$$W=[W_1;W_2;\ldots;W_P],\qquad Y_i=XW_i^T$$

每个 rank 都拿完整 X，计算自己的一段输出 $Y_i\in\mathbb R^{B\times d_{out}/P}$。前向若下一层能消费分片，就不通信；若调用方要完整 Y，则 All-Gather。反向时每个 rank 得到自己输出梯度并算局部权重梯度，但输入梯度是各 shard 贡献之和，需 All-Reduce（或与 SP 组合成 Reduce-Scatter）。

### Row Parallel Linear

沿输入维切权重和输入：

$$W=[W_1,W_2,\ldots,W_P],\quad X=[X_1,X_2,\ldots,X_P]$$

每个 rank 计算 partial output $Y_i=X_iW_i^T$，完整输出是 $Y=\sum_iY_i$，因此前向要 All-Reduce；bias 只能在归约后加一次。反向每个 rank 可直接得到自己的输入梯度 shard，权重梯度本地计算。

Megatron 的典型配对是：MLP 第一层/Attention QKV 用 Column Parallel，激活保持分片；第二层/Attention output projection 用 Row Parallel，把 partial outputs 求和。这样两层之间不必 All-Gather，一个 Transformer 子块只在合适边界做 collective。

实现可能用 All-Reduce，也可能用 Reduce-Scatter + 后续 All-Gather 把通信与 Sequence Parallel 融合；所以回答“Column 一定前向无通信、Row 一定 All-Reduce”要加上“当输入/输出布局按上述约定时”。还要避免把数学上的 W 列切分与框架 `nn.Linear.weight=[out,in]` 的存储轴名称混淆。

### 面试简答版

Column Parallel 按输出神经元切 `weight[out,in]`，输入复制、输出分片；前向可不通信，反向输入梯度需求和。Row Parallel 按输入维切权重，输入也分片，各卡得到完整输出的部分和，前向需 All-Reduce，bias 归约后只加一次。Megatron 用 Column→激活分片→Row 配对，避免中间 All-Gather；SP 下 collective 可改写为 Reduce-Scatter/All-Gather。
