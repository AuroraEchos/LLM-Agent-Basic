> **问题：** Continued Pretraining、Domain-Adaptive Pretraining 和 SFT 的目标有什么区别？
>
> **分类：** Tokenizer、数据与预训练

## 我的答案

三者都从已有模型继续训练，但优化目标和数据形式不同：

- **Continued Pretraining（CPT）**：继续使用语言建模目标，扩充知识、语言、时间范围或总体能力；
- **Domain-Adaptive Pretraining（DAPT）**：CPT 的领域化子类，用目标领域的无标注文本适配术语和分布；
- **Supervised Fine-Tuning（SFT）**：在输入—目标回答样本上训练模型按指令产生期望行为。

可以简化理解为：CPT/DAPT 主要改变模型“熟悉什么分布、掌握什么内容”，SFT 主要改变“用户这样提问时应该怎样回答”。

### Continued Pretraining

数据通常是大规模原始文档、代码或多语言文本，目标仍是 next-token prediction：

$$
\mathcal{L}_{\text{CPT}}=-\sum_t\log p_\theta(x_t\mid x_{<t})
$$

典型用途包括：

- 为基础模型补充新时间段知识；
- 增强低资源语言、代码、数学或长上下文；
- 在通用模型上继续扩大预训练 token；
- 修改词表后让新增 token 学到表示。

CPT 数据规模通常大，学习率低于从零预训练但高于部分后训练设置，训练时应混入通用 replay 并监控灾难性遗忘。它不会自动把文档知识变成良好的问答行为：模型可能会续写医学论文，却不会按医生助手格式回答。

### Domain-Adaptive Pretraining

DAPT 使用金融、医疗、法律、企业内部文档等目标领域的**无标注或弱标注语料**继续语言模型训练，本质上是范围更窄、目标更明确的 CPT。

它擅长：

- 学习专业词汇、缩写和文体；
- 建模领域事实与共现关系；
- 适应代码库、文档格式或组织语言分布；
- 在标注数据稀缺时利用大量无标注文本。

风险是领域数据小且重复，容易记忆；窄域训练比例过高还会损害通用能力。可使用领域/通用混合、较小学习率、较短训练、分层去重和新旧领域验证集缓解。

有时还会在 DAPT 后做 Task-Adaptive Pretraining：使用与目标任务更接近的无标注文本进一步适配，再进入 SFT。

### Supervised Fine-Tuning

SFT 数据通常是：

```text
system + user + context  →  assistant response / tool call
```

训练仍可用 token-level cross entropy，但一般只对 assistant 目标 token 计算 Loss：

$$
\mathcal{L}_{\text{SFT}}
=-\sum_t m_t\log p_\theta(y_t\mid x,y_{<t})
$$

$m_t$ 是 loss mask，prompt token 通常为 0，期望回答为 1。SFT 主要学习遵循指令、输出结构、角色边界、拒答方式和工具协议。

它的数据量通常远小于 CPT，却要求标签和格式高质量。少量错误示范会直接教坏行为。SFT 也能注入知识，但不适合把大量文档逐条改成问答来替代预训练或检索：覆盖低、成本高，而且模型可能只记答案模板。

### 关键区别

| 维度 | CPT | DAPT | SFT |
|---|---|---|---|
| 核心目标 | 扩展/更新基础分布 | 适配特定领域分布 | 学会指令到回答的行为映射 |
| 数据 | 大规模通用或新增原文 | 领域无标注文档 | 输入—目标输出示范 |
| Loss | 全文 next-token | 全文 next-token | 通常仅目标回答 token |
| 主要收益 | 知识、语言和基础能力 | 术语、领域知识和文体 | 指令遵循、格式和策略 |
| 主要风险 | 成本、遗忘、数据污染 | 窄域过拟合、隐私记忆 | 模板偏置、错误标签、alignment tax |

### 如何组合

构建领域助手的常见顺序是：

```text
通用基础模型
→ DAPT/CPT：学习领域文档分布
→ SFT：学习问答、引用和工具调用
→ 偏好/安全对齐（可选）
→ RAG 与评测
```

不是每步都必需。如果领域词汇和 Loss 与通用文本相近，直接 SFT 或 RAG 可能更便宜；如果知识频繁更新或必须给出处，优先把动态事实放在 RAG/工具中，不必每次 CPT。若模型连领域文本都难以建模，只有 SFT 往往治标不治本。

### 如何判断该用哪个

- 目标是吸收大量无标注文档、新语言或新代码：CPT/DAPT；
- 目标是固定回答格式、工具 schema 和交互策略：SFT；
- 目标是精确、可更新、可撤回的私有知识：通常 RAG 优先，再视需要 DAPT；
- 两者都有：先 DAPT 建表示，再 SFT 教行为，并保留通用数据防遗忘。

评估时要分开测 base perplexity、领域任务、通用能力、指令遵循和记忆/泄漏，不能只看最终聊天观感。

### 面试简答版

CPT 是在已有模型上继续做 next-token 预训练，用于扩充知识、语言或时间分布；DAPT 是 CPT 的领域化形式，用大量无标注领域文本学习术语、事实共现和文体；SFT 则用“输入—期望回答/工具调用”示范，通常只对回答 token 算 Loss，主要教指令遵循和输出行为。领域助手常先 DAPT、再 SFT，但动态且需引用的知识更适合 RAG。CPT/DAPT 要防通用能力遗忘和隐私记忆，SFT 要防错误标签和模板偏置，三者应分别用领域 Loss、通用基准与行为评测验证。
