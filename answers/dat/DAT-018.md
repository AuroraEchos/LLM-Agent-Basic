## 我的答案

Curriculum Learning（课程学习）是让训练数据的分布或难度随训练进程有计划地变化，而不是从第一步到最后一步都从同一静态混合中 i.i.d. 采样。直觉是先学习稳定的基础模式，再逐步引入更长、更难、更专业或噪声更高的数据。

它在大模型预训练中不是只有“简单题到难题”一种形式，还包括序列长度、数据质量、领域、语言、任务结构和采样权重的 schedule。

### 基本形式

设样本 $x$ 的难度为 $d(x)$，训练进度为 $t\in[0,1]$，当前允许的最大难度为 $c(t)$。一种硬课程是：

$$
x\text{ 可被采样}\iff d(x)\le c(t)
$$

更平滑的做法是使用随时间变化的采样概率：

$$
p_t(x)\propto p_0(x)\,w(d(x),t)
$$

早期提高简单/高质量样本权重，后期逐渐恢复目标分布。若最后始终不回到目标分布，模型优化的就是另一个目标，可能产生分布偏置。

### “难度”如何定义

可使用以下信号或其组合：

- 文档长度、句法复杂度、公式/代码密度；
- 小型参考模型的 Loss 或 perplexity；
- 数据质量、噪声和解析置信度；
- 任务所需推理步数、答案长度或执行难度；
- 语言资源量和领域专业程度；
- 当前模型的 Loss、梯度或学习进展。

高 Loss 不一定代表“有价值的难题”，也可能是乱码、错误标签或分布外噪声；低 Loss 也可能只是重复样本。因此难度必须与质量和重复度分开建模。

### 大模型中的常见应用

#### Sequence Length Curriculum

先用较短序列训练，再逐步升到目标上下文长度。短序列初期计算更便宜、batch 可更大，能快速学习词法和局部模式；后期长序列学习跨段依赖和位置泛化。

但要保证最终阶段有足够的长序列 token。若长上下文只在最后短暂出现，模型可能“支持这个位置长度”却不会有效利用远距离信息。改变长度时还要检查 batch token 数、学习率和位置编码配置是否突变。

#### Quality Curriculum

早期使用结构清晰、低噪声数据稳定优化，再逐步加入多样的网页、口语和长尾文本。也可以反过来在训练末期提高高质量数据比例，做 annealing/quality upsampling，以改善最终模型状态。

两种策略目的不同：前者强调优化稳定，后者类似在广泛预训练后用高价值分布收尾。哪种更好必须实验，不能把“高质量永远放最后”当成定律。

#### Domain / Capability Curriculum

先通用预训练，再提高代码、数学、特定语言或目标业务数据占比；或按基础语法、标准库、复杂项目逐级加入代码数据。为防止领域阶段遗忘通用能力，应持续混入 replay 数据，并监控旧基准。

#### 动态自适应课程

根据各数据桶的验证 Loss、学习速度或梯度贡献调整采样：欠拟合且仍有收益的桶提高权重，已饱和或开始过拟合的桶降低权重。这比固定 schedule 灵活，但会让系统更复杂，也可能因噪声指标不断震荡，需要平滑、上下限和延迟反馈。

### 为什么可能有效

- 训练早期梯度由可学习、低噪声模式主导，减少异常样本干扰；
- 在固定 FLOPs 下，短序列和易样本可加快基础能力形成；
- 避免小模型状态过早承受超长依赖或极专业分布；
- 后期集中有限算力补目标能力；
- 可将数据的边际价值与模型当前能力匹配。

但深度网络训练路径依赖，课程也可能把模型锁在次优区域；而大规模随机混合本身已提供从高频简单模式到低频复杂模式的隐式课程。因此课程学习并非必然优于良好的静态混合。

### 风险与对照实验

1. **定义错难度**：高 perplexity 噪声被当作高级样本；
2. **分布切换过猛**：Loss、梯度尺度和优化器状态突然改变；
3. **遗忘**：最后的窄域阶段损害通用和多语言能力；
4. **长度能力不足**：长序列 token 总量太少；
5. **公平性偏差**：低资源语言因参考模型 Loss 高而被长期推迟；
6. **混淆算力收益**：短序列 run 更快，但总训练 token/FLOPs 未对齐，错误归因给 curriculum。

评估时至少比较：静态随机混合、同总 token/同 FLOPs 的课程策略、打乱课程顺序的对照，并追踪各阶段所有领域的 held-out Loss。还要记录每类数据实际被看过多少 token，而不是只写采样配置。

### 面试简答版

Curriculum Learning 是让数据分布随训练进度变化，可按样本难度、质量、领域或序列长度安排。例如先短序列和高质量通用文本，逐步增加长上下文、代码数学和长尾数据，或根据各桶学习进展动态调权。它可能提高早期优化稳定性和单位算力收益，但高 Loss 可能只是噪声，阶段切换也会造成分布突变与灾难性遗忘。因此需要平滑 schedule、通用 replay、足够的最终长序列训练，并与同 token、同 FLOPs 的静态混合和打乱顺序对照，不能默认“由易到难”一定更好。
