## 我的答案

三者不是简单的“质量优先”排序，而是在固定训练 FLOPs 和 token 预算下求一个组合最优：

- **数量**决定模型见过多少模式，并支撑规模化训练；
- **质量**决定每个 token 提供多少有效学习信号；
- **多样性**决定覆盖哪些语言、领域、文体和能力，影响泛化边界。

大量重复或垃圾 token 的边际价值很低；只保留少量“教科书式高质量文本”又会导致知识覆盖窄、语言风格单一和长尾能力缺失。

### 用“有效 token”理解权衡

可以把数据源 $i$ 的原始 token 数记为 $N_i$，平均质量权重记为 $q_i$，重复和高度相关造成的有效性折扣记为 $r_i\in[0,1]$，粗略写成：

$$
N_{\text{eff}}=\sum_i N_i q_i r_i
$$

这不是精确的训练定律，但说明 1 万亿个 token 不等于 1 万亿个独立、高价值 token。重复副本会让 $r_i$ 下降，乱码和模板页使 $q_i$ 下降；而小众语言即使样本少，也可能因扩展覆盖边界而具有额外价值。

模型规模与训练 token 通常需要共同增长。若数据量不足却反复多 epoch 训练，记忆和过拟合风险上升；若数据无限但质量极差，增加 token 只是在消耗算力。最终应以验证 Loss 和目标任务质量随训练 FLOPs 的曲线判断，而不是只比较磁盘 TB。

### 质量不只是“语言流畅”

预训练数据质量至少包括：

- 正确性和事实可靠性；
- 信息密度、连贯性与可读性；
- 解析完整、低模板噪声和低重复；
- 来源与许可可追溯；
- 不含不应训练的隐私、秘密和高风险内容；
- 对目标能力有学习价值，例如代码可执行、数学推导完整。

质量分类器本身有偏见。若把“像百科或正式英文”当成唯一高质量标准，会误删口语、方言、论坛中的实践经验、创意写作和低资源语言。因此更稳妥的是按语言/领域校准、多档打分和加权采样，而不是一个全局硬阈值。

### 多样性也有多个维度

多样性不仅是语言比例，还包括来源、主题、时间、难度、文体、观点、代码语言、任务格式和文档长度。即便有大量英文网页，如果都来自少数 SEO 站点，实际多样性仍很低。

多样性有两个作用：一是覆盖产品真正需要的长尾；二是减少模型把某个来源的风格或偏见当成世界本身。但盲目追求均匀也不合理：把所有微小领域配成相同比例，会严重偏离真实使用分布并反复上采样小语料。

### 实际决策框架

#### 1. 先守硬底线

许可、隐私、秘密、明显恶意或不可解析内容不因“数量稀缺”而放宽。随后做精确/近似去重和 benchmark 去污染，避免重复数量虚高。

#### 2. 分层而不是二元过滤

将语料按语言、领域和质量档分桶。例如高质量教育文本可高权重使用，中等质量论坛保留多样性但降低权重，明显垃圾删除。这样比单一阈值更容易控制偏差。

#### 3. 设置覆盖下限与重复上限

对目标语言、代码、数学、长文本等设最低 token 预算；对小语料设最大 epoch 或最大重复次数，防止上采样导致记忆。高资源通用网页则可降采样，把算力让给边际收益更高的数据。

#### 4. 用模型反馈更新混合比例

在小规模 proxy model 或训练早期比较各数据桶的 held-out Loss、学习速度和下游收益。可关注每增加一单位训练 token 带来的验证收益：

$$
u_i\approx-\frac{\Delta L_{\text{target}}}{\Delta N_i}
$$

当某一桶已饱和，边际收益会下降；当某种语言明显欠拟合，应提高其比例。这个过程要同时检查其他任务是否退化，不能只优化单一总分。

#### 5. 保留通用回放与后期高质量阶段

领域继续预训练时混入一定比例通用数据，可减轻灾难性遗忘。训练后期适当提高高质量、推理密集数据占比有时能改善最终能力，但分布突变也可能导致能力偏移，应通过消融确认。

### 评价不能只用平均分

应同时跟踪：

- 每个语言/领域的 held-out Loss 和下游任务；
- 事实性、代码可执行率、数学正确率与长文本能力；
- 记忆率、重复生成、隐私泄漏和 benchmark 污染；
- 不同来源、文体和低资源切片的最差表现；
- 单位训练 FLOP、单位原始 byte 的收益。

如果提高“质量”后平均分上升，却让方言、代码或特定文化内容显著退化，这不是无条件更优，而是数据目标发生了改变。

### 面试简答版

我把质量、数量和多样性看成固定算力下的 Pareto 优化：数量提供覆盖和规模，质量提高单位 token 的有效信号，多样性决定长尾泛化。先执行许可、隐私、去重和污染等硬约束，再按语言、领域和质量分桶，用分层权重而不是统一阈值；给关键低资源域设置覆盖下限，同时限制小语料的重复 epoch。最终用各领域 held-out Loss、下游质量、记忆率和单位 FLOP 的边际收益迭代混合比例。只追求 TB 数会浪费算力，只保留“百科式高质量”又会造成覆盖和风格偏置。
